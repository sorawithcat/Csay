# Csay 形式化规范 v1.1（EBNF + 词法）

> 配套 `语言规范.md`。

## 0. 记法

EBNF 元符号与语言符号无关，语言终结符一律加引号。

| 元符号 | 含义 |
|---|---|
| `::=` | 定义为 |
| `\|` | 选择一 |
| `[ X ]` | 0 或 1 次 |
| `{ X }` | 0 或多次 |
| `( X )` | 分组 |
| `"若"` | 终结符（token） |
| `《名》` | 词法类别（见第 1 节） |

---

## 1. 词法

### 1.1 Token 类别

| 类别 | 记法 | 规则 |
|---|---|---|
| 保留字 | `"类"` 等 | 54 个，见 6.3 |
| 标识符 | `《名》` | 见 1.2 |
| 整数 | `《整》` | `[0-9]+` |
| 浮点 | `《浮》` | `[0-9]+ "." [0-9]+` |
| 文本 | `《文》` | 见 1.4 |
| 运算符 | — | 见 1.5 |
| 注释 / 空白 | — | 丢弃 |

### 1.2 标识符

```
《名》 ::= 起始 { 后续 }
起始  ::= 汉字 | 字母 | "_"
后续  ::= 汉字 | 字母 | 数字 | "_"
汉字  ::= U+4E00–U+9FFF | U+3400–U+4DBF
```

**保留字必须左右不紧邻标识符字符**，否则整体按标识符处理：

| 源码 | 结果 |
|---|---|
| `整数 年龄` | `整数` `年龄` |
| `整数年龄` | 标识符 `整数年龄`（一个 token） |
| `类点` | 标识符 `类点` |

### 1.3 数字

- 整数：`123`
- 浮点：`3.14`
- 数字字面量写成十进制；科学计数法、十六进制、下划线分隔和类型后缀都写成普通十进制或显式转换
- 负数是单目运算符，不是字面量

`1.` 是词法错误（小数点后必须有数字）。`1.5.2` 报错。

### 1.4 文本

```
《文》 ::= '"' { 普通字符 | 转义 | 插值 } '"'
转义   ::= "\" ( '"' | "\\" | "n" | "t" | "{" | "}" )
插值   ::= "{" 表达式 "}"
```

- 插值需 `$` 前缀：`$"共 {数量} 个"`。无 `$` 的 `{` 是普通字符。
- **插值内不允许嵌套同种引号**：`$"{d["k"]}"` 报错，提示先用变量接收：

```
第 12 行：字符串插值里不能再写双引号
  建议：先取出下标的值
    整数 个数 = 库存["苹果"];
    打印($"苹果 {个数} 个");
```

C# 能解析这种嵌套，但它需要解析器回溯到字符串内部。教学语言不值得为此增加复杂度。

### 1.4.1 字符

```
《字符》 ::= "'" ( 普通字符 | 转义 | "\\u" 四位十六进制 ) "'"
字符转义 ::= "\\" ( "'" | "\\\\" | "n" | "t" | "r" | "0" | "u" )
```

- 字符字面量必须正好一个 UTF-16 码元，例如 `'A'`、`'中'`、`'\n'`。
- `\u` 后必须正好 4 位十六进制数。
- 单引号不再表示文本；文本只使用双引号或中文引号。

### 1.5 运算符与分隔符

```
+  -  *  /  %  ++  --
=  +=  -=  *=  /=  %=
==  !=  <  <=  >  >=
&&  ||  !
?  :
??
?.

.  ,  ;  (  )  [  ]  {  }  <  >
=>
```

`=>` 用于 lambda 表达式，形式为 `(类型 参数, ...) => 表达式` 或 `(类型 参数, ...) => { ... }`。
无位运算、无 `!` 可空修饰；`空` 可用于类、接口、列表、表、数组、委托和异常，文本的空值用空字符串，结构体和值类型不能用 `空`。

### 1.6 注释与空白

- `//` 行注释，`/* */` 块注释（可跨行，不能嵌套）。
- `///` 仍是行注释；编辑器把紧贴声明的连续 `///` 当作文档注释。
- 空白只作分隔，不产生 token。
- 缩进不参与语法。

### 1.7 全角防御

中文输入法混入全角字符是高频事故。下列字符必须单独识别并给替换建议：

| 输入 | 提示 |
|---|---|
| `（` `）` | 请改用半角 `(` `)` |
| `｛` `｝` | 请改用半角 `{` `}` |
| `，` `；` `：` | 代码区使用半角标点，请改用 `,` `;` `:` |
| `＝` `＋` `－` `＊` `／` | 请改用半角 |
| `＜` `＞` `！` | 请改用半角 |
| `　`（全角空格） | 不能作分隔符，请改用半角空格 |
| `。` | 语句以 `;` 结束，不需要句号 |
| `“ ”` | 字符串请用半角 `"` |

## 2. 编译单元

```
编译单元 ::= { 引指令 } { 顶层项 }
顶层项   ::= 顶层声明 | 顶层语句
顶层声明 ::= 命名空间声明 | 类型声明 | 函数声明
函数声明 ::= 类型 《名》 "(" [ 参数表 ] ")" 块

引指令   ::= "引" 限定名 ";"
命名空间声明 ::= "命名空间" 限定名 "{" { 类型声明 | 命名空间声明 } "}"
限定名   ::= 《名》 { "." 《名》 }
```

**允许顶层语句**（v1.2，对应 C# 9 的 top-level statements）。顶层语句、函数和类型声明可以按任意顺序交错；类型和函数声明不产生运行时代码，顶层语句仍按书写顺序执行。顶层语句编译时包进隐式 `主()`。`引用`/`输出` 参数允许用在顶层函数、普通方法、构造器、虚拟/覆盖/抽象方法和接口方法上。

## 3. 类型声明

```
类型声明 ::= 类声明 | 结构声明 | 接口声明 | 枚举声明

类声明   ::= { 修饰符 } "类" 《名》 [ ":" 基列表 ] "{" { 类成员 } "}"
结构声明 ::= { 修饰符 } "结构" 《名》 [ ":" 基列表 ] "{" { 类成员 } "}"
接口声明 ::= { 修饰符 } "接口" 《名》 [ ":" 基列表 ] "{" { 接口成员 } "}"

基列表   ::= 类型名 { "," 类型名 }
修饰符   ::= "公开" | "私有" | "保护" | "内部"
           | "静态" | "只读" | "抽象" | "虚拟" | "覆盖" | "常"
```

`:` 后为父类或接口——编译器按名字解析到的类型类别决定是继承还是实现（与 C# 一致）。父类必须写在最前。

### 3.1 类成员

```
类成员 ::= 字段声明 | 方法声明 | 构造器声明 | 属性声明

字段声明 ::= { 修饰符 } 类型 《名》 [ "=" 表达式 ] ";"

方法声明 ::= { 修饰符 } 类型 《名》 "(" [ 参数表 ] ")" ( 块 | "=>" 表达式 ";" )
参数表   ::= 参数 { "," 参数 }
参数     ::= [ "引用" | "输出" ] 类型 《名》 [ "=" 表达式 ]

构造器声明 ::= { 修饰符 } 《名》 "(" [ 参数表 ] ")" [ ":" "基" "(" [ 实参表 ] ")" ] ( 块 | "=>" 表达式 ";" )

属性声明 ::= { 修饰符 } 类型 《名》 ( "{" { 访问器 } "}" | "=>" 表达式 ";" )
访问器   ::= "取" 块 | "写" 块
```

构造器 = 名字与所在类型同名且**无返回类型**。歧义消解：`公开 点(` 后面跟 `{` 而非类型，靠「名字后直接是 `(`」判定。表达式体成员用 `=>` 写一个表达式，方法/构造器等价于只有一条语句的块，只读属性等价于只有 `取` 的块。

### 3.2 接口成员

```
接口成员 ::= 类型 《名》 "(" [ 参数表 ] ")" ";"
           | 类型 《名》 "{" "取" ";" [ "写" ";" ] "}"
```

接口成员无实现、无修饰符。

### 3.3 枚举

```
枚举声明 ::= { 修饰符 } "枚举" 《名》 "{" 枚举项 { "," 枚举项 } [ "," ] "}"
枚举项   ::= 《名》 [ "=" 表达式 ]
```

## 4. 类型引用

```
类型 ::= 基础类型
       | 类型名 [ "<" 类型 { "," 类型 } ">" ]
       | 类型 "[" "]"

基础类型 ::= "字节" | "有符号字节" | "短整数" | "无符号短整数"
           | "整数" | "无符号整数" | "长整数" | "无符号长整数"
           | "浮点数" | "长小数" | "文本" | "字符" | "真假" | "无"
类型名   ::= 《名》 [ "." 《名》 ]
```

泛型可用于 `列表<T>`、`表<K,V>`，以及自定义类、结构或接口的类型参数。自定义泛型参数可以带一个或多个名义约束，写作 `<T: 约束类型>` 或 `<T: 约束一 & 约束二>`；类型实参必须同时满足所有约束。约束本身是泛型类型的情况见[未来计划](未来计划.md)。

## 5. 语句

```
块   ::= "{" { 语句 } "}"
语句 ::= 块
       | 变量声明
       | 本地函数
       | 表达式语句
       | 若语句
       | 只要语句
       | 做语句
       | 循环语句
       | 遍历语句
       | 选择语句
       | 返回语句
       | 跳出语句
       | 跳过语句
       | 抛出语句
       | 试语句
       | 区域语句
       | 使用语句
       | ";"                                  // 空语句

变量声明  ::= 类型 《名》 [ "=" 表达式 ] ";"
本地函数  ::= 类型 《名》 "(" [ 参数表 ] ")" 块
表达式语句 ::= 表达式 ";"
```

### 5.1 控制流

```
若语句 ::= "若" "(" 表达式 ")" 块 [ 否则部分 ]
否则部分 ::= "否则" 块
           | "否则若" "(" 表达式 ")" 块 [ 否则部分 ]

只要语句 ::= "只要" "(" 表达式 ")" 块
做语句   ::= "做" 块 "只要" "(" 表达式 ")" ";"

循环语句 ::= "循环" "(" [ 简单声明 ] ";" [ 表达式 ] ";" [ 表达式列表 ] ")" 块
简单声明 ::= 类型 《名》 "=" 表达式
表达式列表 ::= 表达式 { "," 表达式 }

遍历语句 ::= "遍历" "(" [ 类型 ] 《名》 "在" 表达式 ")" 块

选择语句   ::= "选择" "(" 表达式 ")" "{" { 情况子句 } "}"
情况子句 ::= "情况" 表达式 ":" { 语句 }
           | "默认" ":" { 语句 }
```

`否则若` 是单个 token，递归成 else-if 链。写成 `否则 若`（两 token）报错并提示连写。

`遍历` 的类型可省。这是全语言唯一允许省略类型的位置。

### 5.2 跳转与异常

```
返回语句 ::= "返回" [ 表达式 ] ";"
跳出语句 ::= "跳出" ";"
跳过语句 ::= "跳过" ";"
抛出语句 ::= "抛出" 表达式 ";"

试语句 ::= "试" 块 { 捕获子句 } [ "最终" 块 ]

区域语句 ::= "区域" 块
使用语句 ::= "使用" "(" 表达式 ")" 块
捕获子句 ::= "捕获" "(" 类型 《名》 ")" [ "若" 表达式 ] 块
```

`跳出` 只用于循环和 `选择`。`选择` 的分支之间**不允许隐式贯穿**（不存在 C 的 fallthrough），空 `情况` 合并是唯一例外：

```csay
选择 (天) {
    情况 星期.六:      // 空分支，穿透到下一个
    情况 星期.日:
        打印("周末");
        跳出;
    默认:
        打印("工作日");
        跳出;
}
```

## 6. 表达式

### 6.1 EBNF（优先级从低到高）

```
表达式      ::= 赋值式

赋值式      ::= 三元式 [ 赋值符 赋值式 ]                  // 右结合
赋值符      ::= "=" | "+=" | "-=" | "*=" | "/=" | "%="

三元式      ::= 空合并式 [ "?" 表达式 ":" 三元式 ]          // 右结合

空合并式    ::= 或式 { "??" 或式 }                          // 右结合

或式        ::= 与式 { "||" 与式 }
与式        ::= 等值式 { "&&" 等值式 }
等值式      ::= 关系式 { ( "==" | "!=" ) 关系式 }
关系式      ::= 加减式 { ( "<" | "<=" | ">" | ">=" ) 加减式 }
加减式      ::= 乘除式 { ( "+" | "-" ) 乘除式 }
乘除式      ::= 一元式 { ( "*" | "/" | "%" ) 一元式 }

一元式      ::= ( "!" | "-" | "++" | "--" ) 一元式
              | 后缀式

后缀式      ::= 主式 { 后缀 }
后缀        ::= "(" [ 实参表 ] ")"
              | "." 《名》
              | "?." 《名》
              | "[" 表达式 "]"
              | "++"
              | "--"

主式        ::= 《整》 | 《浮》 | 《文》
              | "真" | "假" | "空"
              | "值" | "自" | "基"
              | 《名》
              | "(" 表达式 ")"
              | "新" 类型 "(" [ 实参表 ] ")"
              | 数组字面量

数组字面量  ::= "[" [ 表达式 { "," 表达式 } ] "]"
实参        ::= [ "引用" | "输出" ] 表达式 | 《名》 ":" 表达式
实参表      ::= 实参 { "," 实参 }
```

### 6.2 优先级与结合性

| 级 | 运算符 | 结合 |
|---|---|---|
| 1 | `= += -= *= /= %=` | 右 |
| 2 | `?:` | 右 |
| 3 | `\|\|` | 左 |
| 4 | `&&` | 左 |
| 5 | `==` `!=` | 左 |
| 6 | `<` `<=` `>` `>=` | 左 |
| 7 | `+` `-` | 左 |
| 8 | `*` `/` `%` | 左 |
| 9 | `!` `-` `++` `--`（前缀） | 右 |
| 10 | `()` `[]` `.` `++` `--`（后缀） | 左 |

与 C# 一致。注意 `&&` 优先级高于 `||`——`a || b && c` 等于 `a || (b && c)`，教学时必须强调，这是新手 bug 第一名。

### 6.3 保留字（61 个）与上下文关键字（1 个）

| 类别 | 保留字 |
|---|---|
| 类型 | `字节` `有符号字节` `短整数` `无符号短整数` `整数` `无符号整数` `长整数` `无符号长整数` `浮点数` `长小数` `文本` `字符` `真假` `无` `任意` |
| 访问 | `公开` `私有` `保护` `内部` |
| 修饰 | `静态` `只读` `抽象` `密封` `虚拟` `覆盖` `常` |
| 定义 | `类` `结构` `接口` `枚举` `委托` |
| 自指 | `自` `基` |
| 控制 | `若` `否则` `否则若` `选择` `情况` `默认` `循环` `遍历` `只要` `做` `在` `返回` `跳出` `跳过` `区域` `使用` |
| 异常 | `试` `捕获` `最终` `抛出` |
| 表达式 | `新` `空` `真` `假` |
| 模块 | `引` `命名空间` |
| 属性 | `取` `写` |

**上下文关键字**：`值`。词法层是普通标识符，只有在属性 `写 { }` 块内才解析成"被赋的新值"（对应 C# 的 `value`）。其他位置可以自由当变量名——中文里「值」太常用，做成保留字会逼用户改名。

## 7. 需要前瞻的歧义（实现重点）

| # | 歧义 | 判别方式 |
|---|---|---|
| 1 | `点 p = 新 点(...)` vs `点.方法()` | 看第 2 个 token：`《名》 《名》` → 变量声明；`《名》 "."` → 表达式 |
| 2 | `整数 x = 1;` vs `整数 加倍(整数 甲) { }` | 类型之后是 `《名》 "("` → 本地函数；`《名》 "="` 或 `";"` → 变量声明 |
| 3 | `列表<整数> 分数` vs `a < b` | 类型上下文遇 `《名》 "<"` → 泛型；表达式上下文 → 比较。解析器按所在产生式区分，不需要回溯 |
| 4 | `点(` 是构造器还是方法 | 名字后直接 `(` 且返回值位置无类型 → 构造器 |
| 5 | `[1,2]` vs `a[0]` | 位于主式位置 → 字面量；位于后缀位置 → 索引 |
| 6 | `选择` 内 `情况 X:` 与标签 | `情况` 是保留字，无歧义 |

**只有第 1、2 条需要 2 个 token 前瞻**，其余靠上下文。整文法对 LL(2) 可解析，递归下降无需回溯。

## 8. 边界情况（必须逐条覆盖）

| # | 源 | 规定 |
|---|---|---|
| 1 | `整数年龄 = 1;` | `整数年龄` 是标识符 → 未定义 → 提示加空格 |
| 2 | `否则 若 (x) {}` | 语法错误，提示连写为 `否则若` |
| 3 | `1.` | 词法错误，小数点后缺数字 |
| 4 | `$"{d["k"]}"` | 报错，提示先取变量 |
| 5 | 全角 `（）` `，` `：` | 专门报错 + 替换建议 |
| 6 | `若 (a = b)` | 赋值表达式类型是 `整数`，条件需 `真假` → 类型错误（这正好挡住了 C 的经典 bug） |
| 7 | `a = b = c` | **合法**，右结合，与 C# 一致 |
| 8 | 接口成员带 `{}` 实现 | 报错，接口不能有实现 |
| 9 | `遍历 (人 在 名单)` | 合法，类型由元素推断 |
| 10 | 空列表 `[]` | 合法，但元素类型无法推断 → 必须写成 `列表<整数>()` 或 `整数[] 空 = [];` 前者优先 |
| 11 | `选择` 分支缺 `跳出` | 编译器自动在分支末尾补 `跳出`（v1 隐含行为），不强制手写 |
| 12 | 类名与内置类型同名（`类 整数`） | 报错，保留字不能用作类型名 |
| 13 | 未封闭的 `/*` | 报错到文件末尾，提示未闭合 |

第 11 条需要说明：C# 强制每段 `case` 以 `break` 结束。Csay 自动补 `跳出`，减少一处样板，但**显式写出的 `跳出` 也合法**。这是唯一一处偏离 C# 的语句语义，需要在校验时明确。
