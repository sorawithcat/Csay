# 文件与目录

程序经常需要读写文件、检查路径、遍历目录。Csay 的文件 API 分成两类：一次性读写的便捷函数，以及按行读写的流式句柄。所有路径都相对于程序启动时的工作目录。

## 一次性读写

```csay 写文件再读回来
若 (写文件("build/教程测试.txt", "第一行\n第二行")) {
    打印("写入成功");
}

文本 内容 = 读文件("build/教程测试.txt");
打印(内容);
```

- `写文件(路径, 内容)` 成功返回 `真`，失败返回 `假`，不会抛异常；
- `读文件(路径)` 返回整个文件的文本；文件不存在或读不到时抛出 `文件异常`；
- 写入内容按 UTF-8 保存，不做额外换行处理。

读文件失败可以捕获：

```csay 安全读取
文本 内容;
试 {
    内容 = 读文件("build/没有这个文件.txt");
    打印(内容);
} 捕获 (文件异常 错) {
    打印($"读取失败：{错.信息}");
}
```

## 流式文件

大文件不适合一次读进内存，可以按行处理：

```csay 流式文件
整数 写句柄 = 打开文件("build/流式.txt", "写");
若 (写句柄 >= 0) {
    写文件行(写句柄, "第一行");
    写文件行(写句柄, "第二行");
    关闭文件(写句柄);
}

整数 读句柄 = 打开文件("build/流式.txt", "读");
文本 行 = 读文件行(读句柄);
只要 (!文件末尾(读句柄)) {
    打印(行);
    行 = 读文件行(读句柄);
}
关闭文件(读句柄);
```

- `打开文件(路径, 模式)` 的模式是 `"读"`、`"写"` 或 `"追加"`；成功返回非负句柄，失败返回 `-1`；
- `读文件行(句柄)` 读一行，不包含行尾换行；文件结束时返回空文本，要配合 `文件末尾(句柄)` 判断；
- `写文件行(句柄, 文本)` 写入文本并补一个换行，成功返回 `真`；
- `关闭文件(句柄)` 关闭句柄，忘记关闭会占用系统文件句柄。

文件最后一行没有换行时，`读文件行` 仍会返回这一行；下一次读取才报告文件末尾。

## 目录操作

```csay 目录操作
文本 目录 = "目录示例";
打印(创建目录(目录));                         // 真
打印(写文件(路径合并(目录, "a.txt"), "内容")); // 真
列表<文本> 文件们 = 目录列表(目录);
打印(文件们[0]);                              // a.txt
打印(是目录(目录));                           // 真
打印(是文件(路径合并(目录, "a.txt")));        // 真
打印(文件大小(路径合并(目录, "a.txt")));      // 6（UTF-8 字节数）
打印(删除文件(路径合并(目录, "a.txt")));      // 真
打印(删除目录(目录));                         // 真
```

- `目录列表(路径)` 返回排好序的 `列表<文本>`，不包含 `.` 和 `..`；
- `创建目录(路径)` 创建目录，已存在时返回 `假`；
- `删除目录(路径)` 只能删除空目录，非空时返回 `假`；
- `是目录` / `是文件` 判断路径类型，路径不存在时返回 `假`；
- `文件大小(路径)` 返回字节数，失败返回 `-1`。

## 路径与平台差异

`路径合并` 在 Windows 上用反斜杠，在其他平台用斜杠。需要写跨平台路径时，不要手拼分隔符：

```csay 路径合并
文本 文件 = 路径合并(路径合并("build", "数据"), "记录.txt");
打印(文件);
```

`路径存在` 对文件和目录都返回 `真`。Windows 上支持中文路径。

## 文件函数一览

| 函数 | 作用 |
|---|---|
| `读文件(路径)` | 读整个文件，失败抛 `文件异常` |
| `写文件(路径, 内容)` | 写整个文件，返回真假 |
| `打开文件(路径, 模式)` | 按行打开，模式为读/写/追加 |
| `读文件行(句柄)` | 读一行，不含换行 |
| `写文件行(句柄, 文本)` | 写一行并补换行 |
| `文件末尾(句柄)` | 是否已到文件末尾 |
| `关闭文件(句柄)` | 关闭句柄 |
| `创建目录(路径)` | 创建目录 |
| `删除文件(路径)` | 删除文件 |
| `删除目录(路径)` | 删除空目录 |
| `目录列表(路径)` | 返回排序后的目录项 |
| `是目录(路径)` / `是文件(路径)` | 路径类型判断 |
| `文件大小(路径)` | 文件字节数，失败返回 `-1` |

完整的内建函数清单见[标准库参考](27-标准库参考.md)。

## 小结

- `读文件` 失败抛异常，`写文件` 失败返回假。
- 大文件用 `打开文件` + `读文件行` / `写文件行` 按行处理。
- 目录列表已排序，不包含 `.` 和 `..`。
- 跨平台路径用 `路径合并`，不要手写分隔符。
