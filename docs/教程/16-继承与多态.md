# 继承与多态

继承让一个类复用另一个类的字段和方法，并在此基础上增加或改写行为。

## 继承的写法

```csay 球继承圆
球 甲 = 新 球(2.0)  // 球继承圆
打印(甲.面积())      // 4 倍圆面积
打印(甲.半径())      // 2

公开 类 圆 {
    私有 小数 _半径;

    公开 圆(小数 半径) {
        _半径 = 半径;
    }

    公开 小数 半径() {
        返回 _半径;
    }

    公开 虚拟 小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }
}

公开 类 球 : 圆 {
    公开 球(小数 半径) : 基(半径) { }

    公开 覆盖 小数 面积() {
        返回 4 * 基.面积();
    }
}
```

这段代码有几处关键点：

- `公开 类 球 : 圆` 表示 `球` 继承 `圆`；
- `公开 球(小数 半径) : 基(半径)` 调用父类构造器，`基` 相当于 C# 的 `base`；
- `公开 虚拟 小数 面积()` 在父类里声明这个方法允许被改写；
- `公开 覆盖 小数 面积()` 在子类里改写父类的方法；
- `基.面积()` 调用父类原来的实现，而不是递归调用自己。

`球` 没有重新声明 `_半径` 字段，也没有重新实现 `半径()`，这些直接从 `圆` 继承。

## 虚拟与覆盖

父类方法用 `虚拟` 表示“允许改写”，子类用 `覆盖` 改写。编译器会检查配对：标了 `覆盖` 的方法必须在父类链上找到一个 `虚拟` 方法，否则编译报错。

```csay 虚拟与覆盖
动物 甲 = 新 猫()
动物 乙 = 新 狗()

打印(甲.叫声())  // 喵，按实际对象分派
打印(乙.叫声())  // 汪

公开 类 动物 {
    公开 虚拟 文本 叫声() {
        返回 "某种声音";
    }
}

公开 类 猫 : 动物 {
    公开 覆盖 文本 叫声() {
        返回 "喵";
    }
}

公开 类 狗 : 动物 {
    公开 覆盖 文本 叫声() {
        返回 "汪";
    }
}
```

通过父类变量调用被覆盖的方法，会按实际对象类型分派到子类实现。需要把不同实现装进同一个变量时，接口同样支持动态分派。

## 在子类里访问父类成员

用 `基` 访问父类的字段、方法和属性：

```csay 基
球 甲 = 新 球(2.0)
打印(甲.描述())  // 一个圆，也是一个球

公开 类 圆 {
    私有 小数 _半径;

    公开 圆(小数 半径) {
        _半径 = 半径;
    }

    公开 虚拟 文本 描述() {
        返回 "一个圆";
    }

    公开 虚拟 小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }
}

公开 类 球 : 圆 {
    公开 球(小数 半径) : 基(半径) { }

    公开 覆盖 文本 描述() {
        返回 基.描述() + "，也是一个球";
    }

    公开 覆盖 小数 面积() {
        返回 4 * 基.面积();
    }
}
```

父类的字段如果是 `私有`，子类不能直接访问，只能通过 `公开` 方法或属性。这仍然是封装的一部分。

## 泛型基类

基类带类型参数时，子类在继承列表里把类型参数继续传下去：

```csay 泛型基类
盒子<整数> 盒 = 新 盒子<整数>(4)
打印(盒.取值())  // 4

公开 类 容器<T> {
    公开 T 内容;

    公开 容器(T v) {
        内容 = v
    }

    公开 T 取值() {
        返回 内容
    }
}

公开 类 盒子<T> : 容器<T> {
    公开 盒子(T v) : 基(v) { }
}
```

`盒子<整数>` 的父类是 `容器<整数>`，父类字段和方法里的 `T` 都会变成 `整数`。

## 密封与抽象

`密封` 类不能被继承，用来明确封死继承链；`抽象` 类不能直接 `新`，只能由具体子类实例化。抽象类可以把方法声明为 `抽象`，只写签名、不写方法体，由具体子类用 `覆盖` 实现：

```csay 密封与抽象
圆 甲 = 新 圆();
打印(甲.面积());

公开 抽象 类 形状 {
    公开 形状() { }
    公开 抽象 小数 面积();
}

公开 类 圆 : 形状 {
    公开 圆() { }
    公开 覆盖 小数 面积() { 返回 3.0; }
}

公开 密封 类 身份证 {
    公开 身份证() { }
}
```

写 `新 形状()` 会报“抽象类不能实例化”；写 `类 其他 : 身份证` 会报“密封类不能被继承”；具体子类漏写 `面积` 的 `覆盖` 会报“没有实现抽象方法”。

## 什么时候用继承

继承适合表达“是一种”的关系：

- 猫是一种动物；
- 球是一种圆；
- 管理员是一种用户。

如果只是“有一个”关系，比如汽车有发动机，不应该继承，而应该在类里放一个发动机字段。继承层级越深，代码越难改；能组合解决的就别继承。

## 小结

- 用 `类 子类 : 父类` 继承。
- 子类构造器用 `: 基(...)` 调父类构造器。
- 父类方法用 `虚拟` 开放改写，子类用 `覆盖` 改写；配对错误会编译失败。
- `密封` 类不能被继承，`抽象` 类不能直接实例化。
- `基.` 访问父类实现，不会递归调用自己。
- 继承表达“是一种”，组合表达“有一个”。
