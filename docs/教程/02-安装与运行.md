# 安装与运行

推荐使用 Windows 一键安装包。安装后可直接在任意目录运行 `csay`，不需要配置环境变量。

## 环境要求

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11 | 自带的 TCC 和控制台处理目前是 Windows 版本 |
| Node.js | 22 或更高 | 安装脚本会检测；没有时自动下载便携版 |
| C 编译器 | 不需要单独安装 | 安装包自带 TCC |
| 磁盘 | 约 10 MB | 不含可选的 Node 便携版 |

双击 `安装Csay.bat`，然后打开新的命令行窗口：

```bash
csay 你好.csay
```

这会完成“检查 → 生成 C → 编译 → 运行”四步。默认使用 TCC；也可以加 `--fast` 明确指定。

## 常用命令

| 命令 | 作用 |
|---|---|
| `csay 程序.csay` | 编译并运行 |
| `csay 程序.csay --fast` | 用 TCC 编译（更快，不优化） |
| `csay 程序.csay --check` | 只做语法和名字检查，不生成 exe |
| `csay 程序.csay --build` | 只编译成 exe |
| `csay 程序.csay --rebuild` | 忽略缓存，强制重编 |
| `csay --test [目录]` | 递归运行目录下所有 `.csay` 测试，默认 `tests` |
| `csay --project [目录]` | 编译并运行目录下 `主.csay` 及其 `引` 依赖 |
| `csay 程序.csay --debug` | 生成 `#line` 源码映射，并让 C 编译器带调试信息 |
| `csay 程序.csay --format` | 按规范格式重写源文件（原地） |

安装脚本已经把 `csay` 加入用户 PATH：

```bash
csay 程序.csay
csay 程序.csay --fast
```

如果从源码运行，也可以直接执行 `node src/cli.ts 程序.csay`。

## 用自带的编辑器

不想碰命令行的话，安装后运行 `csay-editor`，或双击开始菜单中的「Csay 编辑器」。它会：

1. 启动一个只监听 `127.0.0.1` 的本地服务；
2. 在浏览器里打开一个深色编辑器；
3. 左侧是工作区文件树，右键文件、文件夹或空白处打开操作菜单；
4. 支持多标签编辑、输入补全、文件筛选、行号、自动缩进和注释切换；输入 `对象.` 时优先补全该对象类型的字段和方法；
5. 大文件按可视区域增量语法高亮，滚动和输入保持流畅；
6. 底部显示问题和运行输出；
7. 按 `F1` 打开的教程页，左侧目录支持按章节和小节搜索。

文件树的右键菜单包括：

| 位置 | 操作 |
|---|---|
| 文件 | 打开、运行、设为项目入口、新建同级文件、重命名、删除、复制路径、在资源管理器中显示 |
| 项目文件 | 编辑项目设置、打包项目、复制路径、在资源管理器中显示 |
| 文件夹 | 新建文件、新建文件夹、打开此文件夹、重命名、删除、复制路径、在资源管理器中显示 |
| 空白处 | 新建文件、新建文件夹、打开文件、打开文件夹、项目设置、打包项目、刷新 |
| 标签页 | 关闭、关闭其他、复制路径 |
| 编辑区 | 转到定义、查找引用、复制 |

编辑区的“转到定义”会跟随 `引` 进入被引文件；“查找引用”会列出当前工作区内的定义和调用，点击结果可跨文件跳转。引用结果显示在独立的“引用”标签页，不会覆盖问题面板。

常用快捷键：

| 快捷键 | 功能 |
|---|---|
| `Ctrl+S` | 保存 |
| `Ctrl+Enter` / `F5` | 编译并运行 |
| `Ctrl+N` | 新建文件 |
| `Ctrl+O` | 打开文件夹 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+/` | 切换行注释 |
| `F12` / `Shift+F12` | 转到定义 / 查找引用 |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进 |
| `F1` | 打开教程 |

在编辑区右键会打开操作菜单：光标停在标识符上时，菜单顶部有“转到定义”和“查找引用”；空白处右键只显示撤销/重做、剪切/复制/粘贴、全选、保存和运行。转到定义跳到另一个文件时，左侧文件树会同步展开并选中目标文件。

示例代码的输出来自编辑器底部的“输出”面板：点击“运行”或按 `Ctrl+Enter` 后显示。

编辑器启动后不会自动新建文件；从左侧文件树右键新建或打开文件。也可以把文件名作为参数：

```bash
编辑器.bat 我的程序.csay
```

关闭启动编辑器的那个命令行窗口，编辑器服务就停止了。

## 项目与打包

编辑器用 `项目.csayproj` 描述一个项目。打开项目目录后，点击顶栏“项目”，在弹出的项目设置里填写名称、入口文件、输出文件名和版本号。入口文件可以点右侧“选择…”从文件对话框挑选，也可以直接填项目目录内的相对路径。入口必须是项目目录内的 `.csay` 文件，保存时会检查文件存在，输出名不含 `.exe`。目录还没有项目文件时，侧栏项目条显示“未配置项目 · 点击设置”，点它即可创建。

项目文件是一个 JSON 文本：

```json
{
  "name": "多文件示例",
  "entry": "主.csay",
  "output": "多文件示例",
  "version": "0.1.0"
}
```

也可以右键 `项目.csayproj`，选择“编辑项目设置”。顶栏的“项目”按钮、侧栏项目条和空白处右键都能打开同一个设置窗口。

点击“打包”会：

1. 编译项目入口及其 `引` 依赖；
2. 把可执行文件、项目文件、全部源文件和 `README.txt` 放进一个目录；
3. 压缩成 `dist/<输出名>-<版本>.zip`。

例如 `examples/多文件` 打包后生成 `dist/多文件示例-0.1.0.zip`，解压后双击 exe 即可运行，源码在 `源码/` 目录。

## 第一个程序

新建一个文件 `你好.csay`，写：

```csay 第一个程序
// 这是注释，编译时会被忽略
打印("你好，世界！");
```

保存后运行：

```bash
csay 你好.csay
```

终端会先打印检查结果，再打印程序输出。第一次编译会生成 `build/你好.exe` 和 `build/你好.c`；源码没改时再次运行会直接复用 exe。

## exe 与双击运行

`build/` 里的 exe 是独立的原生程序，不依赖 Node.js，复制到别的 Windows 电脑上也能运行。

直接双击 exe 时，程序结束会停住并提示“按回车键退出…”，否则窗口会立刻关闭。从命令行或 `csay` 启动时不会停，因为启动脚本设置了 `CSAY_NO_PAUSE=1`。

安装脚本会自动关联 `.csay` 文件，之后双击源码即可编译运行。卸载时会移除关联。

## 测试

测试文件就是普通 `.csay`，用 `断言` 检查结果：条件为假时抛出 `状态异常`，测试进程以非零码退出。

```csay 测试断言
断言(1 + 1 == 2)
断言(文本长度("你好") == 2, "文本长度应为 2")
```

把测试放在 `tests/` 下，运行：

```bash
csay --test tests
```

测试运行器会递归查找 `.csay` 文件，逐个编译运行，最后汇总通过和失败数量。

## 多文件工程

项目目录以 `主.csay` 为入口，其他模块用 `引 模块名;` 引入。例如 `examples/多文件/`：

- `主.csay` 写 `引 工具;`，然后调用 `工具.csay` 里的函数；
- `工具.csay` 只放类型声明和函数，不能有顶层可执行语句。

编译并运行整个工程：

```bash
csay --project examples/多文件
```

只想生成 exe 就加 `--build`。产物是 `build/多文件.exe`，文件名取自项目目录名。`引` 会递归加载依赖，并检查被引文件是否混入了可执行语句。

## 调试信息

加 `--debug` 后，生成的 C 会在每条 Csay 语句前写入 `#line 行号 "源文件"`，并给 C 编译器加 `-g`。这样 C 编译器和调试器报告的行号指回 `.csay` 源码，而不是 `build/*.c`。生成的 C 文件仍保留在 `build/` 下，方便查看。

```bash
csay 程序.csay --debug
```

## 格式化

`--format` 用编译器自己的语法树打印器重写源文件，统一缩进、空格和换行：

```bash
csay 程序.csay --format
```

它只格式化命令行指定的文件，不会把 `引` 进来的模块展开写回；有语法错误时拒绝改写。

## 选择编译器

Csay 会按下面的顺序找 C 编译器：

1. 环境变量 `CSAY_CC` 指定的编译器；
2. 系统的 `clang`；
3. 系统的 `gcc`；
4. 自带的 TCC。

前三个会加 `-O2`，TCC 不优化。日常改代码用 `--fast` 快，发布程序用默认编译更划算。

## 小结

- 推荐使用一键安装包；Node 与 C 编译器由安装脚本处理。
- `csay 文件.csay` 编译并运行，`--check` 只检查语法。
- `csay-editor` 打开浏览器编辑器。
- 生成的原生 exe 在 `build/` 下，可以独立分发。
