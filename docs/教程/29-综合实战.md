# 综合实战：学生成绩

这一章用一个完整的小程序把前面学的类、属性、列表、函数、循环和字符串串起来。

## 需求

有一份学生名单，每个学生有姓名和分数。程序要：

1. 逐个输出学生信息；
2. 计算平均分；
3. 找出最高分的学生。

## 完整程序

```csay 学生成绩统计
列表<学生> 名单 = 新 列表<学生>()  // 空名单
名单.追加(新 学生("张三", 88))       // 1 人，88 分
名单.追加(新 学生("李四", 95))       // 2 人，最高 95
名单.追加(新 学生("王五", 76))       // 3 人

遍历 (学生 人 在 名单) {
    打印(人.描述())                  // 依次输出三人
}

打印($"平均分：{平均分(名单)}")          // (88+95+76)/3 ≈ 86.33
打印($"最高分：{最高分(名单).描述()}")   // 李四：95 分

小数 平均分(列表<学生> 表) {
    整数 合计 = 0
    遍历 (学生 人 在 表) {
        合计 += 人.分数               // 88 → 183 → 259
    }
    返回 (合计 + 0.0) / 表.数量       // 259 / 3 ≈ 86.33
}

学生 最高分(列表<学生> 表) {
    学生 最好 = 表[0]                 // 先假设第一个最高
    遍历 (学生 人 在 表) {
        若 (人.分数 > 最好.分数) {
            最好 = 人                  // 发现更高就替换
        }
    }
    返回 最好;
}

公开 类 学生 {
    私有 文本 _姓名;
    私有 整数 _分数;

    公开 学生(文本 姓名, 整数 分数) {
        _姓名 = 姓名;
        _分数 = 分数;
    }

    公开 整数 分数 {
        取 { 返回 _分数; }
    }

    公开 文本 描述() {
        返回 $"{_姓名}：{_分数} 分";
    }
}
```

## 结构说明

**数据类**

`学生` 只负责保存姓名和分数，并提供 `描述()` 和只读的 `分数` 属性。字段是 `私有` 的，外面不能直接改分数。

**两个函数**

- `平均分` 遍历列表求和，再除以人数；
- `最高分` 先假设第一个学生最高，再依次比较。

两个函数的参数类型都是 `列表<学生>`，返回类型分别是 `小数` 和 `学生`。

**顶层代码**

先创建三个学生，再用 `遍历` 输出，最后调用两个函数。所有顶层代码都写在 `学生` 类之前，符合“语句在类型声明之前”的规则。

## 可以继续改的地方

这个程序还可以加：

- 从文件读学生名单，而不是写在代码里；
- 按分数排序，输出排名；
- 增加科目和总分；
- 用 `电话`、`年龄` 等字段扩展学生类。

改的时候注意两点：

1. 类里的字段尽量 `私有`，通过属性或方法暴露；
2. 列表会动态增长，学生人数变化不需要改代码。

## 小结

- 类负责保存数据，函数负责计算，顶层代码负责组织流程。
- 列表可以装类对象，`遍历` 直接取出。
- 返回类对象的函数可以继续调用它的方法。
- 完整程序要遵守“顶层语句在类型声明之前”的顺序。
