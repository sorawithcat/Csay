# 输入、时间与系统

这一章处理程序和外界的交互：从控制台读入、读取命令行参数、获取时间、拼接路径、读取环境变量，以及调用系统命令。文件读写见[文件与目录](22-文件与目录.md)。

## 输入与询问

`输入()` 读一行，不带提示；`询问(提示)` 先打印提示再读一行：

```csay 交互输入
文本 名字 = 询问("请输入名字：");
打印($"你好，{名字}！");

整数 年龄 = 转整数(询问("年龄："));
打印($"明年你 {年龄 + 1} 岁");
```

运行交互程序时，编辑器会打开一个新的命令行窗口，请在新窗口输入。输入结束后窗口会停住，按回车关闭。

> 控制台的中文输入依赖 UTF-8 代码页。如果在旧版 Windows 控制台看到乱码，换用 Windows Terminal 或更新系统。

## 命令行参数

`命令行参数()` 返回 `列表<文本>`，第一个元素是第一个参数，不包含程序名：

```csay 命令行参数
列表<文本> 参数 = 命令行参数();

若 (参数.数量 == 0) {
    打印("没有参数");
} 否则 {
    打印($"收到 {参数.数量} 个参数");
    遍历 (文本 一个 在 参数) {
        打印(一个);
    }
}
```

运行 `csay 程序.csay 甲 乙`，列表里就是 `甲`、`乙` 两项。

## 时间

```csay 时间
打印(当前时间());                  // 年-月-日 时:分:秒
打印(当前日期());                  // 年-月-日
打印(时间戳());                    // Unix 秒数
打印(格式化时间(0, "%Y-%m-%d"));   // 1970-01-01（本地时区）
```

- `当前时间()` 返回本地时间文本；
- `当前日期()` 只返回日期；
- `时间戳()` 返回从 1970-01-01 UTC 起的秒数，类型是整数；
- `格式化时间(秒, 格式)` 按 C 的 `strftime` 格式输出。常用占位符：`%Y` 年、`%m` 月、`%d` 日、`%H` 时、`%M` 分、`%S` 秒。

`strftime` 的占位符由运行平台决定，Windows 和 Linux 对少数扩展占位符可能不同。

## 路径与环境

```csay 路径与环境
打印(当前目录());
打印(路径合并("build", "教程"));   // build\教程（Windows）
打印(路径存在("."));               // 真
打印(系统平台());                  // Windows 或 Linux
打印(读环境变量("PATH"));          // 环境变量不存在时返回空文本
```

- `当前目录()` 返回进程的工作目录；
- `路径合并(目录, 名字)` 用当前平台的路径分隔符拼接；
- `路径存在(路径)` 对文件和目录都返回 `真`；
- `读环境变量(名字)` 不存在时返回空文本，不抛异常；
- `系统平台()` 返回 `Windows` 或 `Linux`。

## 运行系统命令

`运行命令(命令)` 调用系统命令并返回退出码；`运行命令输出(命令)` 返回命令写入标准输出的文本：

```csay 运行命令
打印(运行命令("echo Csay"));          // 输出 Csay 后返回 0
文本 输出 = 运行命令输出("echo Csay");
打印(输出);                            // Csay\n
```

命令和参数作为一整段文本交给系统命令解释器。`运行命令输出` 只捕获标准输出，标准错误不会出现在返回值里；退出码仍用 `运行命令` 获取。

> 不要把未经检查的用户输入直接拼进命令。这等同于把输入交给 shell，可能执行任意命令。

## 函数一览

| 函数 | 作用 |
|---|---|
| `输入()` / `询问(提示)` | 读一行 / 先提示再读一行 |
| `命令行参数()` | 返回参数列表，不含程序名 |
| `当前时间()` / `当前日期()` | 本地时间 / 日期文本 |
| `时间戳()` | Unix 秒数 |
| `格式化时间(秒, 格式)` | 按 `strftime` 格式输出 |
| `当前目录()` | 当前工作目录 |
| `路径合并(目录, 名字)` | 拼接路径 |
| `路径存在(路径)` | 文件或目录是否存在 |
| `读环境变量(名字)` | 环境变量，不存在返回空 |
| `系统平台()` | `Windows` 或 `Linux` |
| `运行命令(命令)` | 执行命令，返回退出码 |
| `运行命令输出(命令)` | 执行命令，返回标准输出 |

完整的内建函数清单见[标准库参考](27-标准库参考.md)。

## 小结

- `输入` / `询问` 读取控制台；交互程序会打开新窗口。
- `命令行参数()` 不包含程序名。
- 时间用 `当前时间`、`当前日期`、`时间戳` 和 `格式化时间`。
- 路径用 `路径合并` 和 `路径存在`，不要手写分隔符。
- `运行命令` 返回退出码，`运行命令输出` 返回标准输出。
