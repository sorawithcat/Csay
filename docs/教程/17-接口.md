# 接口

接口只规定“必须提供哪些方法/属性”，不写具体实现。类可以选择实现一个接口，从而被当作这个接口类型使用。

## 定义与实现

```csay 形状接口
形状[] 堆 = [新 圆(2.0), 新 方(3.0)]

遍历 (形状 形 在 堆) {
    打印($"{形.名字}：{形.面积()}")  // 圆、正方形各自实现
}

公开 接口 形状 {
    小数 面积();
    文本 名字 { 取; }
}

公开 类 圆 : 形状 {
    私有 小数 _半径;

    公开 圆(小数 半径) {
        _半径 = 半径;
    }

    公开 虚拟 小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }

    公开 虚拟 文本 名字 {
        取 { 返回 "圆"; }
    }
}

公开 类 方 : 形状 {
    私有 小数 _边;

    公开 方(小数 边) {
        _边 = 边;
    }

    公开 虚拟 小数 面积() {
        返回 _边 * _边;
    }

    公开 虚拟 文本 名字 {
        取 { 返回 "正方形"; }
    }
}
```

接口里的成员只写签名，不写函数体：

```
公开 接口 形状 {
    小数 面积();
    文本 名字 { 取; }
}
```

实现接口的类用 `:` 接在接口名后面，写法和继承父类一样。类必须实现接口里的所有成员，否则编译报错。

## 接口变量与多态

接口最重要的用途是**用同一种类型装不同的实现**：

```csay 接口变量
形状 甲 = 新 圆(1.0)
形状 乙 = 新 方(2.0)

打印(甲.面积())  // 3.14159
打印(乙.面积())  // 4

公开 接口 形状 {
    小数 面积();
}

公开 类 圆 : 形状 {
    私有 小数 _半径;

    公开 圆(小数 半径) {
        _半径 = 半径;
    }

    公开 虚拟 小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }
}

公开 类 方 : 形状 {
    私有 小数 _边;

    公开 方(小数 边) {
        _边 = 边;
    }

    公开 虚拟 小数 面积() {
        返回 _边 * _边;
    }
}
```

`甲` 和 `乙` 的声明类型都是 `形状`，但实际对象不同。调用 `.面积()` 时，运行时会找到对象真正的实现，这就是接口多态。

实现接口的方法通常写 `虚拟`，和教程里的写法保持一致。接口分派按对象的实际实现执行，即使变量声明成接口类型也一样。

## 接口属性

接口可以要求属性，实现方提供 `取`、`写` 或两者：

```csay 接口属性
矩形 甲 = 新 矩形(3, 4)
形状 形 = 甲
打印(形.名字)  // 矩形
打印(形.面积()) // 12

公开 接口 形状 {
    文本 名字 { 取; }
    小数 面积();
}

公开 类 矩形 : 形状 {
    私有 整数 _宽;
    私有 整数 _高;

    公开 矩形(整数 宽, 整数 高) {
        _宽 = 宽;
        _高 = 高;
    }

    公开 虚拟 文本 名字 {
        取 { 返回 "矩形"; }
    }

    公开 虚拟 小数 面积() {
        返回 (_宽 * _高) + 0.0;
    }
}
```

`形状 形 = 甲;` 把一个具体类的对象赋给接口变量是允许的，因为 `矩形` 实现了 `形状`。

## 接口与父类的区别

| | 父类 | 接口 |
|---|---|---|
| 能否有实现 | 可以 | 只能有签名 |
| 表达关系 | 是一种（猫是动物） | 具备某种能力（形状能算面积） |
| 数量 | 单继承 | 一个类可以实现多个接口 |
| 字段 | 可以继承 | 不包含字段 |

实际设计时，共用实现放父类，跨类型的能力放接口。比如“可保存”“可比较”“可打印”这类能力，适合用接口表达。

## 小结

- 接口用 `公开 接口 名字 { ... }` 声明，只写方法/属性签名。
- 类用 `:` 实现接口，必须实现全部成员。
- 接口变量可以装不同实现，调用时走运行时多态。
- 实现接口的方法通常要写 `虚拟`。
- 一个类只能继承一个父类，但可以实现多个接口。
