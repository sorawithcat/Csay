# 正则表达式

Csay 自带一个很小的正则引擎，够做常见的前缀、后缀、重复字符和简单模式匹配，不是完整 PCRE。需要分组、字符类或分支时，当前要自己写扫描代码，或扩展运行时。

## 三个函数

```csay 正则基础
打印(正则匹配("abc123", "^abc.*$"));   // 真
打印(正则匹配("ac", "ab*c"));            // 真
打印(正则匹配("ac", "ab+c"));            // 假
打印(正则查找("你好abc", "abc"));       // 2
打印(正则替换("你好世界", "好.", "X")); // 你X界
```

- `正则匹配(文本, 模式)`：文本中是否有匹配，返回真假；
- `正则查找(文本, 模式)`：返回第一个匹配的起始码点下标，找不到返回 `-1`；
- `正则替换(文本, 模式, 新文本)`：把第一个匹配替换成新文本，返回新文本。

`正则替换` 只替换第一个匹配，替换文本按字面量处理，不解析 `$1` 这样的分组引用。

## 支持的语法

| 写法 | 含义 |
|---|---|
| `a` | 字面量字符 |
| `.` | 任意一个字符 |
| `*` | 前一个元素重复 0 次或多次 |
| `+` | 前一个元素重复 1 次或多次 |
| `?` | 前一个元素重复 0 次或 1 次 |
| `^` | 匹配文本开头 |
| `$` | 匹配文本结尾 |
| `\.` `\*` `\\` | 反斜杠转义，匹配字面量 |

例如 `a\\.c` 匹配字面量 `a.c`，不匹配 `abc`。

## 限制

- 不支持分组 `(...)`，因此没有捕获组和反向引用；
- 不支持字符类 `[abc]`、`\d`、`\w`、`\s`；
- 不支持分支 `|`；
- 不支持 `{n,m}` 形式的重复次数；
- `*`、`+`、`?` 是贪婪匹配，但没有回溯控制选项；
- `^`、`$` 只匹配整个文本的开头和结尾，不匹配每一行的开头和结尾。

这些限制是为了保持运行时小、可自举。复杂模式请在 Csay 里写扫描函数，或修改 `src/runtime.ts` 与 `selfhost/编译器.csay` 的对应调用。

## 常见用法

当前版本没有字符类，日期这种“固定形状”的文本可以用 `.` 和数量来描述：

```csay 正则形状
文本 输入 = "2026-11-25"
若 (正则匹配(输入, "^....-..-..$")) {
    打印("形状像日期")
}
```

这只能检查“四个字符、横线、两个字符、横线、两个字符”的形状，不能保证每一段都是数字。需要严格校验数字时，请用文本下标逐字符判断。

## 小结

- 三个函数：`正则匹配`、`正则查找`、`正则替换`。
- 支持字面量、`.`、`*`、`+`、`?`、`^`、`$` 和转义。
- 不支持分组、字符类、分支和 `{n,m}`。
- `正则替换` 只替换第一个匹配，替换文本按字面量处理。
