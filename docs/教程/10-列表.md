# 列表

列表是长度可变的同类型集合。需要在运行时不断追加、删除元素时，用列表；长度固定的集合在下一章《数组》学习。

## 创建与追加

```csay 列表的基本操作
列表<整数> 分数 = 新 列表<整数>()
分数.追加(88)   // 分数 = [88]
分数.追加(92)   // 分数 = [88, 92]
分数.追加(76)   // 分数 = [88, 92, 76]

打印($"共 {分数.数量} 个")   // 3
打印($"最高 {分数.最大()}")  // 92

遍历 (整数 分 在 分数) {
    打印(分)                 // 88、92、76
}
```

`列表<整数>` 里的 `<整数>` 是元素类型。创建时必须写 `新 列表<元素类型>()`，不能只写 `新 列表()`。

用 `遍历 (元素 在 列表)` 按顺序读取元素；元素类型可以省略，编译器会从列表推断。

文本、小数、整数都可以放进列表：

```csay 文本列表
列表<文本> 待办 = 新 列表<文本>();
待办.追加("学会列表");
待办.追加("写一个小程序");

打印($"有 {待办.数量} 件事");
遍历 (文本 一件 在 待办) {
    打印($"- {一件}");
}
```

## 从文本切分

文本可以用 `.切分(分隔符)` 或 `.切分空白()` 得到 `列表<文本>`：

```csay 切分文本
文本 句子 = "苹果,香蕉,橘子"
列表<文本> 水果 = 句子.切分(",")   // ["苹果", "香蕉", "橘子"]

打印($"一共 {水果.数量} 种")  // 3
遍历 (文本 一件 在 水果) {
    打印(一件)
}
```

`切分空白()` 会按空格、换行和制表符切分，适合处理一行里的多个词。

## 常用方法

| 方法 | 作用 | 说明 |
|---|---|---|
| `.追加(值)` | 末尾添加 | 最常用 |
| `.插入(位置, 值)` | 在指定下标插入 | 后面的元素后移 |
| `.删除(位置)` | 删除指定下标 | 后面的元素前移 |
| `.清空()` | 删除全部 | 数量变 0 |
| `.查找(值)` | 返回下标 | 找不到返回 `-1` |
| `.排序()` | 从小到大排序 | 支持整数、小数、文本 |
| `.反转()` | 原地反转 | 不创建新列表 |
| `.去重()` | 去掉重复值 | 保留第一次出现的位置 |
| `.切片(起, 止)` | 取子列表 | 包含起，不包含止 |
| `.最大()` | 最大值 | 空列表不要调用 |
| `.数量` | 元素个数 | 属性，不加括号 |
| `列表[下标]` | 按下标读写 | 从 0 开始 |

```csay 增删查改
列表<整数> 数 = 新 列表<整数>()
数.追加(5)       // [5]
数.追加(2)       // [5, 2]
数.追加(8)       // [5, 2, 8]

数.插入(1, 99)   // [5, 99, 2, 8]
打印($"插入后 {数.数量} 个，第二个是 {数[1]}")  // 4 个，99

数.排序()        // [2, 5, 8, 99]
打印($"排序后最大 {数.最大()}，8 在位置 {数.查找(8)}")  // 99，2

数.删除(0)       // [5, 8, 99]
打印($"删除后还剩 {数.数量} 个")  // 3

数.清空()
打印($"清空后 {数.数量} 个")  // 0
```

## 切片

`.切片(起, 止)` 返回一个新的列表，包含起下标，不包含止下标：

```csay 切片
列表<整数> 数 = 新 列表<整数>();
数.追加(10);
数.追加(20);
数.追加(30);
数.追加(40);

列表<整数> 前两个 = 数.切片(0, 2);
列表<整数> 后两个 = 数.切片(2, 4);

遍历 (整数 x 在 前两个) {
    打印(x);
}
打印("--");
遍历 (整数 x 在 后两个) {
    打印(x);
}
```

切片不会修改原列表，返回的列表可以独立增删。

## 去重与反转

```csay 去重反转
列表<整数> 数 = 新 列表<整数>()
数.追加(3)
数.追加(1)
数.追加(3)
数.追加(2)
数.追加(1)
数.追加(5)

数.去重();
数.反转();

打印($"去重反转后有 {数.数量} 个：");
遍历 (整数 x 在 数) {
    打印(x);
}
```

`去重` 保留每个值第一次出现的位置，再 `反转` 就得到上面的顺序。

## 集合、队列与栈

`集合<T>`、`队列<T>`、`栈<T>` 是列表的轻量别名，创建和存储方式与列表相同，只是多了几个表示用途的方法：

```csay 集合队列栈
集合<文本> 标签 = 新 集合<文本>();
打印(标签.集合添加("新"));    // 真
打印(标签.集合添加("新"));    // 假，已存在
打印(标签.集合添加("热"));    // 真

队列<文本> 排队 = 新 队列<文本>();
排队.入队("甲");
排队.入队("乙");
打印(排队.出队());            // 甲
打印(排队.出队());            // 乙

栈<整数> 盘子 = 新 栈<整数>();
盘子.入栈(1);
盘子.入栈(2);
打印(盘子.出栈());            // 2
打印(盘子.出栈());            // 1
```

| 方法 | 作用 |
|---|---|
| `.集合添加(值)` | 不存在时添加，返回是否添加成功 |
| `.入队(值)` / `.出队()` | 队尾添加 / 队首取出 |
| `.入栈(值)` / `.出栈()` | 栈顶添加 / 栈顶取出 |

`出队` 和 `出栈` 在空容器上会抛出 `越界异常`。因为它们是列表别名，`.数量`、`.清空`、遍历等列表操作仍然可用；不要把它们当成独立类型做重载或类型判断。

## 小结

- 列表用 `新 列表<类型>()` 创建，长度可变。
- `.追加`、`.插入`、`.删除`、`.清空` 修改内容。
- `.查找` 返回下标或 `-1`，`.最大` 返回最大值。
- `.排序`、`.反转`、`.去重`、`.切片` 提供常用集合操作。
- `集合`、`队列`、`栈` 是列表别名，分别提供去重添加、先进先出、后进先出方法。
- 数量用 `.数量`，下标从 0 开始。
- `遍历 (元素 在 列表)` 按顺序读取元素。
