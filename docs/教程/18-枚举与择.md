# 枚举与择

枚举给一组固定的整数起名字。`择` 根据一个值跳转到不同分支，相当于 C# 的 `switch`。

## 定义枚举

```csay 星期枚举
文本 上班吗(星期 天) {
    择 (天) {
        情形 星期.六:
        情形 星期.日:
            返回 "休息";
        默认:
            返回 "上班";
    }
}

打印(上班吗(星期.日))  // 休息
打印(上班吗(星期.三))  // 上班

公开 枚举 星期 {
    一, 二, 三, 四, 五, 六, 日
}
```

枚举的成员从 `0` 开始编号：`一` 是 0，`二` 是 1，……`日` 是 6。

枚举比直接用整数好：调用 `上班吗` 时只能传 `星期` 类型，传 `整数` 会报错，减少把 `2` 当成星期三这种错误。

## 择的写法

`择 (表达式) { ... }` 里用 `情形 值:` 列出分支，`默认:` 处理其他情况：

```csay 数字名
打印(数字名(0))  // 零
打印(数字名(1))  // 一
打印(数字名(9))  // 很多

文本 数字名(整数 数) {
    择 (数) {
        情形 0:
            返回 "零";
        情形 1:
            返回 "一";
        默认:
            返回 "很多";
    }
}
```

每个 `情形` 后面是冒号，不是分号。分支体可以有多条语句。

## 情形贯穿

空的 `情形` 会继续往下走到下一个分支：

```csay 周末
打印(类型(星期.六))  // 周末
打印(类型(星期.三))  // 工作日

文本 类型(星期 天) {
    择 (天) {
        情形 星期.六:
        情形 星期.日:
            返回 "周末";
        默认:
            返回 "工作日";
    }
}

公开 枚举 星期 {
    一, 二, 三, 四, 五, 六, 日
}
```

`情形 星期.六:` 后面没有语句，就直接落到 `情形 星期.日:`。这和 C# 的 switch 贯穿规则一致。

非空分支不会自动贯穿。如果分支里没有 `返回`，可以用 `跳出` 结束 `择`：

```csay 跳出择
文本 结果 = "";

择 (2) {
    情形 1:
        结果 = "一";
        跳出;
    情形 2:
        结果 = "二";
        跳出;
    默认:
        结果 = "其他";
}

打印(结果);
```

## 枚举背后的值

枚举成员本质上是整数常量，从 0 开始编号：

| 成员 | 值 |
|---|---|
| `星期.一` | 0 |
| `星期.二` | 1 |
| `星期.三` | 2 |
| `星期.四` | 3 |
| `星期.五` | 4 |
| `星期.六` | 5 |
| `星期.日` | 6 |

## 什么时候用枚举

- 状态只有有限几种：订单的待付款/已付款/已发货；
- 选项是固定集合：星期、月份、方向；
- 替代“魔法数字”：代码里出现 `若 (状态 == 2)` 时，`2` 是什么意思没人知道，写成 `状态 == 订单状态.已付款` 就清楚了。

## 小结

- `公开 枚举 名字 { 成员, 成员 }` 定义枚举，成员从 0 开始。
- 用 `枚举名.成员` 访问。
- `择 (值) { 情形 ...: 默认: }` 做多分支。
- 空 `情形` 贯穿到下一个分支；非空分支用 `返回` 或 `跳出` 结束。
- 枚举让有限集合的取值更安全、更好读。
