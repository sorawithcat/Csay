# 字符串

字符串用双引号 `"..."` 包起来。Csay 的字符串默认支持插值：花括号里的表达式会被替换成结果。

```csay 字符串插值
文本 名字 = "小明";
整数 年龄 = 18;

打印("你好，{名字}！");
打印($"明年你 {年龄 + 1} 岁。");
```

`$"..."` 和 `"..."` 都能插值，`$` 只是从 C# 带过来的写法。花括号里可以放变量和算术表达式。

## 转义与字面花括号

| 写法 | 结果 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |
| `\{` | 字面量左花括号 |

```csay 转义字符
打印("第一行\n第二行");
打印("引号：\"你好\"");
打印("花括号：\{名字\}");
```

中文引号 `“ ”` 也可以作为字符串边界，里面能直接写英文双引号：

```csay 中文引号
打印(“他说："你好"”);
```

## 拼接与长度

两个文本可以用 `+` 拼接。文本不能直接和数字相加，混合内容用插值：

```csay 拼接
文本 姓 = "张";
文本 名 = "三";
打印(姓 + 名);

文本 句子 = "Csay 是一门中文编程语言";
打印(句子.长度);
```

`.长度` 返回的是**码点数**，不是字节数。一个汉字算 1，一个 emoji 也算 1，和 C# 按 UTF-16 单元计数不同。

用下标可以取一个字符，结果仍然是文本。下标从 0 开始，按码点计数：

```csay 按下标取字符
文本 句子 = "a你b好"
打印(句子[0])  // a
打印(句子[1])  // 你
打印(句子[3])  // 好
```

越界下标返回空文本，不会让程序崩溃。

## 常用文本方法

| 方法 | 作用 | 例子 |
|---|---|---|
| `.长度` | 码点数 | `"你好".长度` 得 `2` |
| `[下标]` | 取一个字符 | `"你好"[1]` 得 `"好"` |
| `.替换(旧, 新)` | 替换所有匹配 | `"abc".替换("b", "x")` |
| `.含(子串)` | 是否包含，返回真假 | `"abc".含("b")` |
| `.转整数()` | 解析成整数 | `"42".转整数()` |
| `.转小数()` | 解析成小数 | `"3.14".转小数()` |

```csay 替换与判断
文本 原文 = "我喜欢吃苹果"
打印(原文.含("苹果"))              // 真
打印(原文.替换("苹果", "香蕉"))    // 我喜欢吃香蕉
```

## 文本转数字

`转整数()` 会跳过开头和结尾的空白。解析到第一个不是数字的字符就停止，完全不是数字时得到 `0`；比如 `"12abc"` 会得到 `12`。实际程序里最好先校验输入：

```csay 文本转数字
文本 输入 = "  42  "
打印(输入.转整数() + 8)  // 50

文本 价格 = "3.5"
打印(价格.转小数() * 2)  // 7
```

## 小结

- 字符串用 `"..."` 或 `“...”`，默认支持 `{表达式}` 插值。
- `$` 前缀可选，写不写都能插值。
- 文本用 `+` 拼接，不能直接和数字相加。
- `.长度` 按码点计数。
- 文本转数字用 `.转整数()` / `.转小数()`。
