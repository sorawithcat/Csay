# 变量与数据类型

变量是给数据起的名字。Csay 是静态类型语言：声明变量时要先写类型，之后这个变量只能装这个类型的值。

```csay 声明变量
整数 年龄 = 18      // 整数
小数 身高 = 1.72   // 小数
文本 名字 = "小明"  // 文本
真假 已成年 = 真    // 真假

打印(名字)          // 小明
打印(年龄)          // 18
打印(身高)          // 1.72
打印(已成年)        // 真
```

## 五种基本类型

| 类型 | 含义 | 字面量例子 | 说明 |
|---|---|---|---|
| `整数` | 64 位有符号整数 | `42`、`-7`、`0` | 日常计数、下标、金额（以分为单位） |
| `小数` | 双精度浮点数 | `3.14`、`-0.5`、`3.0` | 科学计算、比例；不要用它存精确金额 |
| `文本` | UTF-8 字符串 | `"你好"`、`"abc"` | 支持插值、拼接、切分 |
| `真假` | 布尔值 | `真`、`假` | 条件判断的结果 |
| `无` | 没有返回值 | — | 只用于函数返回类型 |

`无` 不是变量的类型。`整数` 和 `小数` 是两种不同的类型，`3` 是整数，`3.0` 是小数。

## 声明与赋值

声明变量的格式是：

```
类型 名字 = 初始值;
```

初始化可以省略，变量会得到默认值：

```csay 默认值
整数 计数      // 默认 0
文本 名字      // 默认空文本
真假 标志      // 默认 假

打印(计数)     // 0
打印(名字)     // （空行）
打印(标志)     // 假
```

`文本` 的默认值是空字符串，所以第二行输出是空的。实际写程序时建议总是显式初始化，避免忘了赋值。

声明之后可以重新赋值，但类型不能变：

```csay 重新赋值
整数 分数 = 60  // 初始 60
分数 = 95        // 改成 95
打印(分数)       // 95
```

## 类型转换

变量的类型声明后不会变。整数和小数混合运算时，结果会自动变成小数；把小数赋给整数则会截断小数部分，容易埋下错误，建议显式转换。

小数转整数用 `取整`。

```csay 小数转整数
打印(取整(3.7));   // 4
打印(取整(-3.7));  // -4
打印(取整(2.5));   // 3
```

`取整` 是四舍五入，不是直接截断。`2.5` 会变成 `3`，`-3.7` 会变成 `-4`。

## 整数与小数不要混着算

整数和小数可以一起运算，结果会提升为小数：

```csay 混合运算
打印(3 + 1.5);  // 4.5
打印(3 * 2.0);  // 6
```

真正需要注意的是**整数除以整数**：两边都是整数时，结果还是整数，小数部分直接丢掉：

```csay 整数除法
打印(7 / 2);      // 3
打印(7.0 / 2.0);  // 3.5
打印(7 % 2);      // 1
```

需要小数结果时，至少让一个操作数是小数（写 `7.0` 或 `2.0`）。`%` 是取余，只能用于整数。

## 小结

- 声明格式：`类型 名字 = 初始值;`，类型必须写。
- 五种基本类型：`整数`、`小数`、`文本`、`真假`、`无`。
- 未初始化的变量有默认值，但建议显式赋值。
- 小数取整用 `取整()`，不是直接截断。
- 整数除法会截断，需要小数就写 `7.0`。
- 变量只在所在代码块内有效。
