# 类与对象

类是把数据和行为包在一起的模板。对象是按这个模板创建出来的实例。

## 定义一个类

```csay 第一个类
圆 甲 = 新 圆(2.0)   // 创建一个半径为 2 的圆
打印(甲.面积())       // 约 12.566

公开 类 圆 {
    私有 小数 _半径;

    公开 圆(小数 半径) {
        _半径 = 半径;
    }

    公开 小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }
}
```

这段代码包含了一个类的全部基本部件：

- `公开 类 圆 { ... }`：声明一个叫 `圆` 的类；
- `私有 小数 _半径;`：字段，保存对象的数据；
- `公开 圆(小数 半径) { ... }`：构造器，名字必须和类名相同，没有返回类型；
- `公开 小数 面积() { ... }`：方法，定义对象能做什么；
- `新 圆(2.0)`：创建对象并调用构造器；
- `甲.面积()`：通过对象调用方法。

构造器里的 `_半径 = 半径` 把参数保存到字段。字段在对象创建时分配，之后每个对象各有一份。

> 注意：顶层语句必须写在类型声明之前。所以上面是“先用类，后定义类”。这是 C# 9 顶层语句的规则，不是 Csay 特有的。

## 字段与方法

字段默认是对象的一部分，方法里可以直接用字段名：

```csay 计数器
计数器 甲 = 新 计数器();
甲.加一()       // 次数 = 1
甲.加一()       // 次数 = 2
甲.加一()       // 次数 = 3
打印(甲.当前()) // 3

公开 类 计数器 {
    公开 整数 次数;

    公开 计数器() {
        次数 = 0;
    }

    公开 无 加一() {
        次数++;
    }

    公开 整数 当前() {
        返回 次数;
    }
}
```

`次数` 是 `公开` 的，所以外面也能直接读写 `甲.次数`。如果它是 `私有`，编译器会拒绝类外的访问，只能由类自己的方法使用。

## 访问控制与只读

字段、方法、属性和静态成员都可以写访问修饰符：

| 修饰符 | 谁能访问 |
| --- | --- |
| `公开` | 任何位置，默认值 |
| `私有` | 只有声明它的类自己 |
| `保护` | 声明它的类和子类 |
| `内部` | 同一程序集内；当前单文件构建中等同于公开 |

字段还可以用 `只读` 或 `常` 修饰。只读字段只能在构造器里赋值，对象创建完成后就不能再改：

```csay 只读字段
账号 甲 = 新 账号("小明");
打印(甲.名称);

公开 类 账号 {
    公开 只读 文本 名称;

    公开 账号(文本 名称) {
        自.名称 = 名称;
    }
}
```

在构造器外写 `甲.名称 = "小红"` 会编译失败。

## 静态成员

字段或方法加 `静态` 后属于类本身，不属于某个对象。用类名访问，不需要 `新`：

```csay 静态成员
计数器.增加();
计数器.增加();
打印(计数器.次数);

公开 类 计数器 {
    公开 静态 整数 次数;

    公开 静态 无 增加() {
        次数 = 次数 + 1;
    }
}
```

输出 `2`。静态字段在所有对象之间共享；静态方法里可以直接写静态字段名，也可以写 `计数器.次数`。静态字段当前固定从 `0` / `空` 开始，不能在声明处写初始值；需要初值时在第一次使用前显式赋值。

## 自

当参数名和字段名相同时，用 `自` 指代当前对象：

```csay 自
点 甲 = 新 点(3.0, 4.0);
打印(甲.长度());

公开 类 点 {
    公开 小数 横;
    公开 小数 纵;

    公开 点(小数 横, 小数 纵) {
        自.横 = 横;
        自.纵 = 纵;
    }

    公开 小数 长度() {
        返回 开方(横 * 横 + 纵 * 纵);
    }
}
```

`自.横` 是字段，右边的 `横` 是参数。如果名字不冲突，可以省略 `自`；冲突时必须写，否则赋值的还是参数自己。

## 构造器

构造器在 `新` 的时候执行，用来把对象初始化到可用状态。构造器没有返回类型，也不能写 `返回 值`：

```csay 构造器
文本 描述(整数 宽, 整数 高) {
    矩形 甲 = 新 矩形(宽, 高);
    返回 $"面积 {甲.面积()}，周长 {甲.周长()}";
}

打印(描述(3, 4))  // 面积 12，周长 14

公开 类 矩形 {
    私有 整数 _宽;
    私有 整数 _高;

    公开 矩形(整数 宽, 整数 高) {
        _宽 = 宽;
        _高 = 高;
    }

    公开 整数 面积() {
        返回 _宽 * _高;
    }

    公开 整数 周长() {
        返回 2 * (_宽 + _高);
    }
}
```

`甲` 是局部对象，离开函数后不再使用。Csay 没有垃圾回收，普通对象会一直占着内存直到进程结束；需要控制生命周期时用后面的《区域与内存》。

## 类和结构

`结构` 的写法与类相似，但按值复制，适合很小的数据：

```csay 结构按值复制
点 甲 = 新 点(3, 4)   // 甲 = (3, 4)
点 乙 = 甲            // 复制一份，乙 和 甲 互不影响
乙.x = 99
打印(甲.x)            // 3
打印(乙.x)            // 99

公开 结构 点 {
    公开 整数 x;
    公开 整数 y;

    公开 点(整数 a, 整数 b) {
        x = a;
        y = b;
    }
}
```

`结构` 支持字段、构造器、方法和 `新`；赋值或传参时复制整个值，不会共享同一个对象。需要引用语义、继承或多个对象共享状态时用 `类`。

## 泛型

同一个类如果只是字段类型不同，可以把它写成泛型类。类型参数写在类名后面的尖括号里：

```csay 泛型类
盒子<整数> 整数盒 = 新 盒子<整数>(3)
盒子<文本> 文本框 = 新 盒子<文本>("你好")
打印(整数盒.内容)      // 3
打印(文本框.内容)      // 你好

公开 类 盒子<T> {
    公开 T 内容;

    公开 盒子(T v) {
        内容 = v
    }
}
```

`T` 是类型参数，`盒子<整数>` 和 `盒子<文本>` 会生成两个独立的类型，字段 `内容` 分别是整数和文本。类型实参要显式写出来，`新 盒子(3)` 不会自动推断成 `盒子<整数>`。

目前泛型只支持写在类、结构或接口上；泛型方法要等后面的版本。

## 小结

- 类用 `公开 类 名字 { ... }` 声明，里面可以有字段、构造器、方法。
- 构造器和类同名，没有返回类型。
- 用 `新 类名(...)` 创建对象，用 `对象.成员` 访问字段和方法。
- 方法里可以直接访问字段，名字冲突时用 `自`。
- 顶层语句要写在所有类型声明之前。
