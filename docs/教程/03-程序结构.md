# 程序结构

Csay 程序的最外层是**顶层语句**：直接写在文件里的代码，不需要先包一个类。

```csay 最小的程序
// 顶层语句从第一行开始执行
打印("你好")
```

顶层语句在编译时会被自动放进一个隐藏的入口函数，所以程序启动后从第一条顶层语句开始执行。

## 语句顺序

同一个文件里可以同时有顶层语句、函数和类型声明，顺序固定为：

1. 顶层变量与顶层语句；
2. 顶层函数；
3. 类、结构、接口、枚举等类型声明。

函数和类型的具体写法分别在“函数”和“类与对象”章节学习。本节只需要记住：**语句写在最前面，声明写在后面**。

## 注释

Csay 支持两种注释：

- `//` 行注释，从 `//` 到行尾；
- `/* ... */` 块注释，可以跨行。

```csay 两种注释
// 这是一行注释，不会执行
打印("第一行")

/*
   这是块注释
   里面的内容不会执行
*/
打印("第三行") // 行尾也可以写注释
```

注释可以写在代码中间，但不能插在标识符或字符串中间。

## 退出码

顶层代码里的 `返回` 可以设置进程退出码：

```csay 用返回设置退出码
打印("准备退出") // 先输出
返回 0          // 0 表示成功
```

命令行程序常用退出码表示成功或失败；非零值通常表示失败。编辑器里看不到退出码，命令行可以读取。

## 多文件与空间

程序变大后，可以把函数和类型放进单独的文件，在开头用 `引` 引入：

```text
// 工具.csay
整数 加一(整数 x) {
    返回 x + 1
}

// 程序.csay
引 "工具.csay"
打印(加一(2))
```

路径相对于当前源文件；被引文件只能放类型和函数，不能写顶层语句。多个文件都引入同一个文件时，它只加载一次。

`空间` 用来把一组类型声明收进一个块，编译时展开：

```text
空间 数学 {
    公开 类 复数 {
        公开 整数 实部 = 0;
    }
}
```

`空间` 只做声明分组，不改变名字查找；同一个文件里仍然直接写类型名。

## 小结

- 顶层语句直接写，编译时自动进入隐藏入口。
- 语句写在所有函数和类型声明之前。
- `//` 和 `/* */` 是两种注释。
- `返回 0;` 设置退出码。
