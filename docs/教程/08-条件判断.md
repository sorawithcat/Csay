# 条件判断

程序不能只会从上往下执行，还要根据情况走不同的路。Csay 用 `若 / 否则若 / 否则` 做判断。

## 基本写法

```csay 判断年龄
整数 年龄 = 17

若 (年龄 >= 18) {          // 17 >= 18 为假
    打印("可以进入")
} 否则 {
    打印("未成年人不能进入")   // 走这里
}
```

规则只有三条：

- 条件必须写在括号里，结果必须是 `真假`；
- 建议总是用 `{ }` 包住分支体。单条语句可以省略花括号，但教程统一写全，避免后续加语句时出错；
- `否则若` 是一个词，中间不能加空格。

`否则若` 可以连续写多个，形成多分支：

```csay 成绩评级
整数 分数 = 80
文本 评级 = ""

若 (分数 >= 90) {
    评级 = "优秀"
} 否则若 (分数 >= 75) {
    评级 = "良好"
} 否则若 (分数 >= 60) {
    评级 = "及格"
} 否则 {
    评级 = "不及格"
}

打印(评级)  // 80 分，良好
```

判断从上往下依次进行，一旦某个条件成立，后面的分支就不再检查。

## 条件里能写什么

条件的结果必须是布尔值。比较运算和逻辑运算返回布尔值，所以它们可以直接用：

```csay 复合条件
整数 分数 = 85
真假 出勤 = 真

若 (分数 >= 60 && 出勤) {   // 真 && 真 = 真
    打印("通过")
} 否则 {
    打印("未通过")
}
```

不能写 `若 (分数)`。整数不会自动转成布尔值，必须明确比较。

## 嵌套判断

`若` 里面可以再写 `若`。嵌套太深时可读性会变差，尽量把每一层判断写得简单：

```csay 嵌套
整数 年龄 = 20
真假 有票 = 假

若 (年龄 >= 18) {           // 真，进入外层
    若 (有票) {             // 假
        打印("入场")
    } 否则 {
        打印("请先买票")     // 走这里
    }
} 否则 {
    打印("年龄不够")
}
```

## 三元运算符

只有两个结果、逻辑又很短时，可以用 `条件 ? 值1 : 值2`：

```csay 三元判断
整数 分数 = 58
文本 结果 = 分数 >= 60 ? "及格" : "不及格"
打印(结果)  // 不及格
```

三元表达式只适合返回值，不适合执行多条语句。要在分支里打印或修改变量，还是用 `若`。

## 小结

- `若 (条件) { } 否则若 (条件) { } 否则 { }`。
- 条件必须是 `真假`，不能拿整数当布尔值。
- `否则若` 必须连写。
- 分支从上到下匹配，命中一个就结束。
- 短小的二选一可以用三元表达式。
