# 数组

数组是一组**类型相同、长度固定**的值。适合存放数量已知、按位置访问的数据。

## 声明与初始化

数组的类型写成 `元素类型[]`，初始化用方括号：

```csay 数组
整数[] 数列 = [3, 1, 4, 1, 5]
文本[] 名单 = ["张三", "李四", "王五"]

打印(数列.长度)  // 5
打印(名单.长度)  // 3
```

数组的长度在创建时确定，之后不能变长或缩短。需要动态增删元素时，用上一章的《列表》。

## 下标

下标从 `0` 开始。`数列[0]` 是第一个元素，最后一个元素的下标是 `长度 - 1`：

```csay 下标读写
整数[] 数列 = [10, 20, 30]

打印(数列[0])  // 10
打印(数列[2])  // 30

数列[1] = 99
打印(数列[1])  // 99
```

下标必须是整数，并且要在 `0` 到 `长度 - 1` 之间。Csay 不做运行时越界检查，写错下标可能读到垃圾值或让程序崩溃。

## 遍历数组

`遍历` 会按顺序取出每个元素：

```csay 遍历数组
整数[] 数列 = [3, 1, 4, 1, 5]
整数 合计 = 0

遍历 (整数 x 在 数列) {
    合计 += x                 // 每轮把 x 加到合计
    打印($"当前 {x}，累计 {合计}")
}
```

数组也可以直接在 `遍历` 里用字面量：

```csay 直接遍历字面量
遍历 (整数 x 在 [2, 4, 6]) {
    打印(x * x);
}
```

数组字面量也可以直接取下标：

```csay 直接取字面量下标
打印([1, 2, 3][0])  // 1
打印([7, 8, 9][2])  // 9
```
## 数组与列表的区别

| | 数组 | 列表 |
|---|---|---|
| 长度 | 固定 | 可变 |
| 创建 | `整数[] 数 = [1, 2, 3];` | `新 列表<整数>()` |
| 添加元素 | 不支持 | `.追加(值)` |
| 删除元素 | 不支持 | `.删除(下标)` |
| 适用场景 | 数量固定的数据 | 需要增删的数据 |

不确定用哪个时，先想数据量会不会变。会变就用 `列表`。

## 小结

- 数组是固定长度的同类型集合，用 `[值, 值]` 初始化。
- 下标从 0 开始，最后一个下标是 `.长度 - 1`。
- `遍历` 可以遍历数组或数组字面量。
- 数组通过下标或 `遍历` 访问。
- 需要增删元素时改用 `列表`。
