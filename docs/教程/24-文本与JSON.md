# 文本与 JSON

文本是 Csay 最常用的类型之一。这一章集中说明文本的拼接、查找、替换、切分、大小写和 JSON 转换；文件、时间和正则分别见[文件与目录](22-文件与目录.md)、[输入、时间与系统](23-输入时间与系统.md)和[正则表达式](25-正则表达式.md)。

## 拼接与插值

`+` 拼接两个文本，插值把表达式嵌进字符串：

```csay 拼接与插值
文本 名字 = "小明"
文本 问候 = "你好，" + 名字
打印(问候)                 // 你好，小明
打印($"{名字}今年 {18 + 1} 岁")   // 小明今年 19 岁
```

插值里的 `{`、`}` 是语法符号。要输出字面花括号，写成 `\{`、`\}`。

## 长度与下标

文本按 Unicode 码点计数和取下标，不是按 UTF-8 字节：

```csay 文本下标
文本 s = "甲乙丙"
打印(s.长度)       // 3
打印(s[0])         // 甲
打印(s[2])         // 丙
```

下标从 0 开始。越界读取会抛出 `越界异常`。

## 切分与替换

```csay 切分替换
文本 行 = "苹果,香蕉,橘子"
列表<文本> 词 = 行.切分(",")
打印(词.数量)              // 3
打印(词[1])                // 香蕉

打印("a-b-c".替换("-", "+"))   // a+b+c
打印("a b  c".切分空白().数量) // 3
```

- `.切分(分隔符)` 返回 `列表<文本>`，保留空段；
- `.切分空白()` 按连续空白切分，丢弃空段；
- `.替换(旧, 新)` 替换所有出现，返回新文本。

## 包含与查找

```csay 包含查找
打印("abcdef".含("cd"))       // 真
打印(查找文本("甲乙丙", "乙")) // 1
打印(查找文本("甲乙丙", "丁")) // -1
```

`.含(子串)` 返回真假；`查找文本(文本, 子串)` 返回码点下标，找不到返回 `-1`。

## 大小写与空白

```csay 大小写
打印(转大写("abc"))          // ABC
打印(转小写("ABC"))          // abc
打印("  hi  ".去除空白())    // hi
```

大小写转换只处理 ASCII 字母；`去除空白` 去掉首尾的空格、制表符、回车和换行，不删除中间空白。

## 格式化

`重复文本`、`连接文本`、`格式化小数` 处理常见排版：

```csay 文本工具
打印(重复文本("哈", 3))              // 哈哈哈
列表<文本> 词 = 新 列表<文本>()
词.追加("甲")
词.追加("乙")
打印(连接文本(词, " / "))            // 甲 / 乙
打印(格式化小数(3.14159, 2))         // 3.14
```

`格式化` 用 `%s` 占位，参数是 `列表<文本>`；`%%` 输出字面百分号。占位符数量必须和参数数量一致，否则抛出 `参数异常`：

```csay 格式化
列表<文本> 参数 = 新 列表<文本>()
参数.追加("小明")
参数.追加("3")
打印(格式化("你好，%s！消息 %s 条", 参数)) // 你好，小明！消息 3 条
打印(格式化("完成度 100%%", 新 列表<文本>())) // 完成度 100%
```

`填充文本(文本, 宽度, 填充)` 在右侧补到指定码点宽度；`查找文本` 见上一节。

## JSON 序列化

`JSON文本` 把文本转成带引号、转义后的 JSON 字符串；`JSON序列化` 把值转成 JSON 文本：

```csay JSON序列化
打印(JSON文本("他说：\"好\""))   // "他说：\"好\""
打印(JSON序列化("abc"))          // "abc"
打印(JSON序列化(42))             // 42
打印(JSON序列化(真))             // true

列表<整数> 数 = 新 列表<整数>()
数.追加(1)
数.追加(2)
打印(JSON序列化(数))             // [1,2]
```

目前 `JSON序列化` 支持基本类型和元素为基本类型的一层列表；对象和嵌套列表不能直接序列化。

## JSON 解析

`JSON解析` 把对象或数组解析成一层 `表<文本, 文本>`：

- 对象：键是字段名；
- 数组：键是 `[0]`、`[1]`；
- 字符串会解码转义；
- `true` / `false` 变成文本 `真` / `假`；
- `null` 保留文本 `null`；
- 嵌套对象或数组的值保留原始 JSON 文本，可以再解析一次。

```csay JSON解析
表<文本, 文本> 数据 = JSON解析("\{\"名字\":\"小明\",\"年龄\":18,\"标签\":[\"a\",\"b\"]\}")
打印(数据.取值("名字", "?"))  // 小明
打印(数据.取值("年龄", "?"))  // 18
打印(数据.取值("标签", "?"))  // ["a","b"]

表<文本, 文本> 标签 = JSON解析(数据.取值("标签", "[]"))
打印(标签.取值("[0]", "?"))   // a
```

Csay 普通字符串里的 `{`、`}` 要写成 `\{`、`\}`，所以 JSON 字面量里会出现反斜杠。格式错误会抛出 `格式异常`；读取不存在的键用 `.取值(键, 默认值)`，不要直接下标。

## 文本函数与成员

| 写法 | 作用 |
|---|---|
| `文本长度(s)` / `s.长度` | 码点数量 |
| `s[下标]` | 按码点取字符 |
| `s.切分(分隔符)` | 切分成列表，保留空段 |
| `s.切分空白()` | 按空白切分 |
| `s.含(子串)` | 是否包含 |
| `s.替换(旧, 新)` | 替换所有出现 |
| `s.转大写()` / `s.转小写()` | ASCII 大小写 |
| `s.去除空白()` | 去首尾 ASCII 空白 |
| `s.转整数()` / `s.转小数()` | 文本转数字 |
| `重复文本(s, 次数)` | 重复拼接 |
| `连接文本(列表, 分隔符)` | 连接文本列表 |
| `格式化(格式, 列表)` | `%s` 占位填充 |
| `填充文本(s, 宽度, 填充)` | 右侧补齐 |
| `查找文本(s, 子串)` | 码点下标，找不到 -1 |
| `JSON文本(s)` | 转 JSON 字符串 |
| `JSON序列化(值)` | 基本类型/一层列表转 JSON |
| `JSON解析(s)` | JSON 转一层表 |

完整清单见[标准库参考](27-标准库参考.md)。

## 小结

- 文本按码点取长度和下标。
- `.切分` 保留空段，`.切分空白` 丢弃空段。
- `.替换` 替换全部出现。
- 大小写转换只处理 ASCII。
- `JSON解析` 返回一层表，嵌套值保留原始 JSON 文本。
- JSON 字面量里的花括号在 Csay 源码中要转义。
