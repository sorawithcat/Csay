# 关键字与速查

这一章不引入新语法，把关键字、类型、运算符和常用写法集中列出来。内建函数和成员按用途的完整清单在[标准库参考](27-标准库参考.md)，这里只给入口。

## 保留字（53 个）

保留字是语言自己用的名字，不能拿来当变量名、函数名或类名。

| 分类 | 保留字 |
|---|---|
| 类型 | `整数` `小数` `文本` `真假` `字节` `无` `任意` |
| 访问 | `公开` `私有` `保护` `内部` |
| 修饰 | `静态` `只读` `抽象` `密封` `虚拟` `覆盖` `常` |
| 定义 | `类` `结构` `接口` `枚举` `委托` |
| 自指 | `自` `基` |
| 控制 | `若` `否则` `否则若` `择` `情形` `默认` `对于` `遍历` `只要` `做` `在` `返回` `跳出` `跳过` `区域` `使用` |
| 异常 | `试` `捕获` `最终` `抛出` |
| 表达式 | `新` `空` `真` `假` |
| 模块 | `引` `空间` |
| 属性 | `取` `写` |

另有 1 个上下文关键字：

| 关键字 | 生效位置 | 说明 |
|---|---|---|
| `值` | 属性的 `写 { }` 里 | 代表要赋进来的新值，其他位置可以当普通变量名 |

## 内建类型名

下面两个名字在特定位置当作类型使用，但它们不在保留字表里：

| 名字 | 用途 |
|---|---|
| `异常` | `捕获 (异常 错)` 里的通用异常类型，`错.信息` 取错误文本，`错.类型` 取类型名；具体类型有 `参数异常`、`状态异常`、`文件异常`、`越界异常`、`格式异常` |
| `条目` | 遍历表时 `遍历 (项 在 表.条目())`，`项.键` / `项.值` |

## 基本类型

| 类型 | 字面量 | 说明 |
|---|---|---|
| `整数` | `42`、`-7` | 64 位有符号整数 |
| `小数` | `3.14`、`2.0` | 双精度浮点 |
| `文本` | `"你好"`、`“你好”` | UTF-8 字符串，支持 `$"..."` 插值 |
| `真假` | `真`、`假` | 布尔值 |
| `无` | — | 函数无返回值 |
| `字节` | `1` | 无符号 8 位整数 |
| `任意` | `空` | 可存放任意类型的动态值 |

数组写成 `整数[]`、`文本[]`；容器写成 `列表<整数>`、`表<文本, 整数>`；集合、队列、栈写成 `集合<T>`、`队列<T>`、`栈<T>`。

## 运算符

| 分类 | 运算符 |
|---|---|
| 算术 | `+` `-` `*` `/` `%` `++` `--` |
| 比较 | `==` `!=` `<` `<=` `>` `>=` |
| 逻辑 | `&&` `\|\|` `!` |
| 赋值 | `=` `+=` `-=` `*=` `/=` `%=` |
| 三元 | `条件 ? 值1 : 值2` |
| 成员/下标/调用 | `.` `[]` `()` |
| Lambda | `(参数类型 名) => 表达式` |

`+` 在两边都是文本时拼接；其他算术运算要求数值。`&&` 的优先级高于 `||`。

## 语句速查

| 写法 | 用途 |
|---|---|
| `整数 年龄 = 18;` | 声明并初始化局部变量 |
| `返回 值;` / `返回;` | 从函数或 Lambda 返回 |
| `若 (条件) { ... } 否则若 (条件) { ... } 否则 { ... }` | 条件分支 |
| `择 (值) { 情形 1: ... 默认: ... }` | 多分支匹配 |
| `对于 (整数 i = 0; i < 10; i++) { ... }` | 计数循环 |
| `只要 (条件) { ... }` | 条件循环 |
| `做 { ... } 只要 (条件);` | 至少执行一次 |
| `遍历 (项 在 列表) { ... }` | 遍历列表、数组或表的条目 |
| `跳出;` / `跳过;` | 跳出当前循环 / 进入下一轮 |
| `试 { ... } 捕获 (异常 错) { ... } 最终 { ... }` | 异常处理 |
| `抛出 "出错了";` | 抛出通用异常 |
| `使用 (资源) { ... }` | 离开块时自动调用无参 `关闭()` |
| `区域 名字 { ... }` | 区域内存分配；`保留(文本)` 把结果移出区域 |
| `引 工具;` | 引入同目录的 `工具.csay` |
| `空间 数学 { ... }` | 把类型声明分组，名字仍然直接可见 |

`使用` 块内不能 `返回`、`跳出`、`跳过`，因为那样会绕过关闭；需要提前结束时用条件包住其余代码。

| `整数[] 固定 = [1, 2, 3];` | 定长数组 |

| `公开 类 账户 { 私有 整数 _余额; 公开 整数 余额 { 取 { 返回 _余额; } } }` | 属性 |

| `公开 类 实现 : 接口名 { ... }` | 实现接口 |
