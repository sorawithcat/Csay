# 标准库参考

这一章按用途列出 Csay 当前公开的内建函数、类型成员和异常。具体用法和示例分别见[文本与 JSON](24-文本与JSON.md)、[文件与目录](22-文件与目录.md)、[输入、时间与系统](23-输入时间与系统.md)、[正则表达式](25-正则表达式.md)和[数学与随机](26-数学与随机.md)。函数名区分中文，参数顺序按表中书写。

## 输入输出

| 函数 | 返回 | 说明 |
|---|---|---|
| `打印(值)` | `无` | 输出一个值并换行；一次只接受一个参数 |
| `输入()` | `文本` | 读一行，不含换行 |
| `询问(提示)` | `文本` | 先打印提示，再读一行 |
| `断言(条件)` / `断言(条件, 消息)` | `无` | 条件为假时抛出 `状态异常`；空消息使用“断言失败” |
| `退出(码)` | `无` | 立即结束进程，返回给操作系统的退出码 |

`打印` 遇到多个值要先拼成一个文本。`断言` 是测试运行器使用的基础函数，不替代正常错误处理。

## 类型转换

| 函数 | 返回 | 说明 |
|---|---|---|
| `转整数(文本)` | `整数` | 解析开头的十进制整数；无法解析返回 `0` |
| `转小数(文本)` | `小数` | 按浮点解析；无法解析返回 `0.0` |
| `字符(码点)` | `文本` | 把 Unicode 码点转成一个字符 |
| `保留(文本)` | `文本` | 把文本复制到当前区域外，只接受文本 |

`转整数` 不报错，也不检查整段文本是否全部是数字；需要严格校验时自己检查字符。`保留` 用于[区域与内存](21-区域与内存.md)，普通代码不需要调用。

## 文本

| 函数 | 返回 | 说明 |
|---|---|---|
| `文本长度(文本)` | `整数` | Unicode 码点数量 |
| `转大写(文本)` / `转小写(文本)` | `文本` | 只转换 ASCII 字母 |
| `去除空白(文本)` | `文本` | 去掉首尾空格、tab、CR、LF |
| `重复文本(文本, 次数)` | `文本` | 重复拼接；次数小于等于 0 返回空文本 |
| `连接文本(列表<文本>, 分隔符)` | `文本` | 用分隔符连接列表元素 |
| `格式化小数(小数, 位数)` | `文本` | 固定小数位 |
| `格式化(格式, 列表<文本>)` | `文本` | `%s` 占位，`%%` 输出百分号；参数不匹配抛 `参数异常` |
| `填充文本(文本, 宽度, 填充)` | `文本` | 右侧补到指定码点宽度 |
| `查找文本(文本, 子串)` | `整数` | 子串起始码点下标，找不到返回 `-1` |

文本成员：

| 成员 | 返回 | 说明 |
|---|---|---|
| `.长度` | `整数` | 码点数量 |
| `[下标]` | `文本` | 按码点取一个字符；越界抛 `越界异常` |
| `.切分(分隔符)` | `列表<文本>` | 切分，保留空段 |
| `.切分空白()` | `列表<文本>` | 按连续空白切分，丢弃空段 |
| `.含(子串)` | `真假` | 是否包含子串 |
| `.替换(旧, 新)` | `文本` | 替换所有出现 |
| `.转大写()` / `.转小写()` | `文本` | 同全局函数 |
| `.去除空白()` | `文本` | 同全局函数 |
| `.转整数()` / `.转小数()` | `整数` / `小数` | 同全局转换 |

## JSON

| 函数 | 返回 | 说明 |
|---|---|---|
| `JSON文本(文本)` | `文本` | 加引号并转义成 JSON 字符串 |
| `JSON序列化(值)` | `文本` | 基本类型或元素为基本类型的一层列表转 JSON |
| `JSON解析(文本)` | `表<文本, 文本>` | 对象/数组解析成一层表；数组键为 `[0]`、`[1]` |

`JSON序列化` 不支持对象和嵌套列表；`JSON解析` 遇到格式错误抛 `格式异常`，嵌套容器的值保留原始 JSON 文本。普通 Csay 字符串里的 `{`、`}` 要写成 `\{`、`\}`。

## 正则

| 函数 | 返回 | 说明 |
|---|---|---|
| `正则匹配(文本, 模式)` | `真假` | 是否存在匹配 |
| `正则查找(文本, 模式)` | `整数` | 第一个匹配的码点下标，找不到 `-1` |
| `正则替换(文本, 模式, 新文本)` | `文本` | 只替换第一个匹配，替换文本按字面量处理 |

支持字面量、`.`、`*`、`+`、`?`、`^`、`$` 和反斜杠转义；不支持分组、字符类、分支和 `{n,m}`。

## 文件

| 函数 | 返回 | 说明 |
|---|---|---|
| `读文件(路径)` | `文本` | 读整个文件；失败抛 `文件异常` |
| `写文件(路径, 内容)` | `真假` | 写整个文件；失败返回 `假` |
| `打开文件(路径, 模式)` | `整数` | 模式 `"读"`、`"写"`、`"追加"`；失败返回 `-1` |
| `读文件行(句柄)` | `文本` | 读一行，不含换行；结束返回空文本 |
| `写文件行(句柄, 文本)` | `真假` | 写一行并补换行 |
| `文件末尾(句柄)` | `真假` | 是否已到末尾 |
| `关闭文件(句柄)` | `无` | 关闭句柄 |

流式句柄最多同时打开 32 个。忘记关闭会占用系统句柄；异常路径可以用 `使用` 自动关闭支持 `关闭()` 的类。

## 目录与路径

| 函数 | 返回 | 说明 |
|---|---|---|
| `当前目录()` | `文本` | 进程工作目录 |
| `路径合并(目录, 名字)` | `文本` | 用平台分隔符拼接 |
| `路径存在(路径)` | `真假` | 文件或目录存在 |
| `目录列表(路径)` | `列表<文本>` | 排序后的目录项，不含 `.`、`..` |
| `创建目录(路径)` | `真假` | 创建目录，已存在返回假 |
| `删除文件(路径)` | `真假` | 删除文件 |
| `删除目录(路径)` | `真假` | 只删除空目录 |
| `是目录(路径)` / `是文件(路径)` | `真假` | 路径类型判断 |
| `文件大小(路径)` | `整数` | 字节数，失败返回 `-1` |

## 时间与系统

| 函数 | 返回 | 说明 |
|---|---|---|
| `当前时间()` | `文本` | 本地 `年-月-日 时:分:秒` |
| `当前日期()` | `文本` | 本地 `年-月-日` |
| `时间戳()` | `整数` | Unix 秒数 |
| `格式化时间(秒, 格式)` | `文本` | 按 `strftime` 格式输出 |
| `命令行参数()` | `列表<文本>` | 不含程序名 |
| `读环境变量(名字)` | `文本` | 不存在返回空文本 |
| `系统平台()` | `文本` | `Windows` 或 `Linux` |
| `运行命令(命令)` | `整数` | 执行命令，返回退出码 |
| `运行命令输出(命令)` | `文本` | 执行命令，返回标准输出 |

`运行命令` 和 `运行命令输出` 都把命令交给系统命令解释器，不要把未检查的用户输入直接拼进去。

## 数学

| 函数 | 返回 | 说明 |
|---|---|---|
| `取整(小数)` | `整数` | 四舍五入 |
| `绝对值(数)` | 同参数 | 绝对值 |
| `开方(小数)` | `小数` | 平方根 |
| `幂(底, 指数)` | `小数` | 乘方 |
| `指数(小数)` / `自然对数(小数)` / `常用对数(小数)` | `小数` | e 的幂、自然对数、以 10 为底 |
| `向下取整` / `向上取整` / `截断` | `整数` | floor / ceil / 向零截断 |
| `符号(数)` | `整数` | -1、0、1 |
| `最大(甲, 乙)` / `最小(甲, 乙)` | 同参数 | 两数比较 |
| `正弦` / `余弦` / `正切` | `小数` | 参数是弧度 |
| `反正弦` / `反余弦` / `反正切` | `小数` | 反三角函数 |
| `反正切2(y, x)` | `小数` | 根据坐标求角度 |
| `圆周率()` | `小数` | 圆周率 |
| `随机()` | `小数` | `[0, 1)` |
| `随机整数(最小, 最大)` | `整数` | 闭区间，两端包含 |
| `随机种子(整数)` | `无` | 固定随机序列 |

整数是 64 位有符号数，溢出按 C 的规则回绕；小数是双精度，比较时留误差。

## 列表、数组、集合、队列、栈

`列表<T>`、`集合<T>`、`队列<T>`、`栈<T>` 共用同一种存储，创建后都能使用列表方法。数组 `T[]` 是定长存储，支持下标和 `.长度`，不支持列表的增删方法。

| 成员 | 返回 | 说明 |
|---|---|---|
| `.数量` / `.长度` | `整数` | 元素个数 |
| `[下标]` | `T` | 读写元素；越界抛 `越界异常` |
| `.追加(值)` | `无` | 末尾追加 |
| `.插入(下标, 值)` | `无` | 在指定位置插入 |
| `.删除(下标)` | `无` | 删除指定位置 |
| `.清空()` | `无` | 删除全部元素 |
| `.查找(值)` | `整数` | 第一个匹配下标，找不到 `-1` |
| `.含(值)` | `真假` | 是否包含 |
| `.排序()` | `无` | 原地升序排序 |
| `.最大()` / `.最小()` | `T` | 最大/最小元素；空列表抛 `越界异常` |
| `.反转()` | `无` | 原地反转 |
| `.切片(起, 止)` | `列表<T>` | 取 `[起, 止)` 区间 |
| `.去重()` | `无` | 原地去重 |
| `.集合添加(值)` | `真假` | 仅用于集合语义，已存在返回假 |
| `.入队(值)` / `.入栈(值)` | `无` | 队列/栈语义的追加 |
| `.出队()` / `.出栈()` | `T` | 队列取前端 / 栈取后端；空时抛 `越界异常` |

## 表

| 成员 | 返回 | 说明 |
|---|---|---|
| `表[键]` | `V` | 读写；读取不存在的键抛 `越界异常` |
| `.数量` | `整数` | 键值对个数 |
| `.含(键)` | `真假` | 键是否存在 |
| `.取值(键, 默认值)` | `V` | 不存在时返回默认值 |
| `.设置(键, 值)` | `无` | 写入键值对 |
| `.删除(键)` | `无` | 删除键 |
| `.条目()` | `列表<条目>` | 键值对列表，顺序不保证 |

键支持 `文本` 和 `整数`；值支持基本类型、文本、列表、表和类引用等。遍历顺序由内部哈希决定。

## 异常

| 类型 | 含义 |
|---|---|
| `异常` | 所有异常的通用类型，`.信息` 是文本，`.类型` 是类型名 |
| `参数异常` | 参数数量或内容不合法 |
| `状态异常` | 对象状态不允许当前操作；空委托也用它 |
| `文件异常` | 文件打开、读取失败 |
| `越界异常` | 下标、空列表、空队列、空栈、表键不存在 |
| `格式异常` | 文本转数字、JSON 等格式错误 |

`抛出 "文本"` 会生成通用 `异常`。具体异常可以按类型多捕获，未匹配的异常执行 `最终` 后继续向外抛。详见[异常处理](20-异常处理.md)。

## 命令行与测试

```bat
csay 程序.csay            编译并运行
csay 程序.csay --check    只检查语法
csay 程序.csay --build    只生成 exe
csay 程序.csay --fast     使用 TCC
csay 程序.csay --rebuild  强制重新编译
csay 程序.csay --debug    生成 #line 源码映射并传 -g
csay 程序.csay --format   按规范格式原地重写
csay --project 目录       构建 目录\主.csay 及其 引 依赖
csay --test [目录]        递归运行测试，默认 tests
```

`--project` 的输出名取目录名。`--test` 会为每个 `.csay` 启动一次编译并运行，失败时汇总并返回退出码 1。详见[安装与运行](02-安装与运行.md)。

## 还没有的标准库

当前没有网络、线程、数据库、GUI、压缩、加密、日期加减和完整 Unicode 大小写。需要这些能力时，应在 `src/runtime.ts` 增加 C 运行时函数，并在默认编译器和自举编译器里同步注册；这不是 Csay 源码能单独完成的部分。

## 小结

- 标准库围绕文本、文件、时间、数学和容器，保持小而可自举。
- 绝大多数函数不抛异常；读文件、JSON、下标、空容器和格式化参数会抛异常。
- 列表/集合/队列/栈共享存储，数组是定长存储。
- 表的遍历顺序不保证，读取不存在的键要先判断。
- 没有的能力需要扩展运行时，而不是在语言层假装存在。
