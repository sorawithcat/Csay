# 委托与闭包

函数除了直接调用，还可以先存进变量，稍后再调用。Csay 用“委托”描述这种函数值的参数和返回值，用 Lambda 创建函数值。Lambda 用到外层局部变量时，会形成闭包。

## 委托声明

委托是一种类型声明，格式是：

```text
委托 名字(参数类型, ...): 返回类型;
```

例如：

```csay 声明委托
委托 变换(整数): 整数;
委托 问候(): 文本;
委托 行动(文本): 无;
```

委托只描述“能接收什么参数、返回什么”，本身不包含实现。声明放在类型声明区，和类、结构、接口、枚举同级；参数只写类型，不写参数名。

## Lambda 表达式

Lambda 用 `=>` 创建函数值。参数必须带类型：

```csay Lambda
变换 加倍 = (整数 x) => x * 2
问候 问好 = () => "你好"
行动 记录 = (文本 s) => { 打印(s) }

打印(加倍(5))   // 10
打印(问好())    // 你好
记录("块体")    // 块体

委托 变换(整数): 整数;
委托 问候(): 文本;
委托 行动(文本): 无;
```

有两种写法：

- 表达式体：`(整数 x) => x * 2`，箭头右边是一个表达式，它的值就是返回值；
- 块体：`(文本 s) => { 打印(s) }`，箭头右边是语句块。目前块体只支持返回类型为 `无` 的委托，块里不能写 `返回 值`。

Lambda 的返回类型由委托的签名决定。把 Lambda 赋给不同类型的委托时，参数个数、参数类型或返回类型不一致会编译失败：

```csay-static 签名不一致
委托 变换(整数): 整数;
变换 f = (文本 s) => 1;   // 参数类型不一致
```

## 调用委托

委托变量可以像函数一样调用：

```csay 调用委托
变换 f = (整数 x) => x + 1;
打印(f(4))   // 5

委托 变换(整数): 整数;
```

委托字段也可以调用：

```csay 委托字段
计算器 甲 = 新 计算器((整数 x) => x * 3);
打印(甲.算(4))   // 12

公开 类 计算器 {
    公开 变换 规则;

    公开 计算器(变换 规则) {
        自.规则 = 规则;
    }

    公开 整数 算(整数 x) {
        返回 自.规则(x);
    }
}

委托 变换(整数): 整数;
```

调用一个值为空的委托会抛出 `状态异常`，消息是“委托为空”。因此委托字段在调用前必须已经赋值；类里没有初值的委托字段默认是空委托。

## 委托作为参数和返回值

委托是普通类型，可以当参数、返回值和字段类型：

```csay 委托参数
打印(应用((整数 x) => x * x, 5))   // 25
打印(应用(选规则(真), 5))          // 10

整数 应用(变换 f, 整数 x) {
    返回 f(x)
}

变换 选规则(真假 加倍) {
    若 (加倍) {
        返回 (整数 x) => x * 2
    }
    返回 (整数 x) => x + 1
}

委托 变换(整数): 整数;
```

## 闭包：捕获局部变量

Lambda 可以使用创建它的函数里的局部变量。捕获发生在创建 Lambda 的那一刻，按值复制一份：

```csay 闭包
变换 加五 = 造加数(5)
打印(加五(3))   // 8

变换 造加数(整数 增量) {
    返回 (整数 x) => x + 增量
}

委托 变换(整数): 整数;
```

`造加数` 返回以后，参数 `增量` 已经离开作用域，但闭包仍然保存着它的副本，所以 `加五(3)` 还能用。

捕获是复制值，之后再改外层变量不会影响已经创建的闭包：

```csay 捕获后修改
整数 计数 = 10
变换 f = (整数 x) => x + 计数
计数 = 99
打印(f(1))   // 11，不是 100

委托 变换(整数): 整数;
```

需要让多个闭包共享可变状态时，当前要用类字段或表等引用类型；闭包捕获的是值，不是变量本身。

方法里的 Lambda 可以用 `自` 访问当前对象。此时捕获的是对象引用，之后修改字段，闭包能看到新值：

```csay 捕获自
乘法器 甲 = 新 乘法器(2);
变换 f = 甲.规则();
打印(f(5))      // 10
甲.倍数 = 3;
打印(f(5))      // 15

公开 类 乘法器 {
    公开 整数 倍数;

    公开 乘法器(整数 倍数) {
        自.倍数 = 倍数;
    }

    公开 变换 规则() {
        返回 (整数 x) => x * 自.倍数
    }
}

委托 变换(整数): 整数;
```

## 限制

- Lambda 参数必须写类型，不能省略成 `(x) => x`。
- 表达式体支持有返回值的委托；块体目前只支持 `无` 返回类型。
- 捕获数组暂不支持。
- 闭包环境分配在堆上，当前不会自动释放；创建大量长期闭包时要考虑内存。
- 普通顶层函数目前不能直接赋给委托变量；需要函数值时用 Lambda 包一层，例如 `(整数 x) => 平方(x)`。

## 小结

- `委托` 声明函数值的签名，本身没有实现。
- Lambda 用 `(类型 参数) => 表达式` 或 `=> { ... }` 创建。
- 委托可以调用、作为参数、返回值和字段。
- Lambda 按值捕获外层局部变量；`自` 捕获对象引用。
- 调用空委托会抛出 `状态异常`。
- 块体 Lambda、数组捕获和闭包自动释放有当前限制。
