# 表

表用键来存取值，相当于其他语言里的字典、哈希表。Csay 的写法是 `表<键类型, 值类型>`。

## 创建与读写

```csay 库存
表<文本, 整数> 库存 = 新 表<文本, 整数>()
库存["苹果"] = 3    // 苹果 3 个
库存["香蕉"] = 2    // 香蕉 2 个
库存["苹果"]++      // 苹果 4 个

打印($"苹果 {库存["苹果"]} 个")  // 4
打印($"香蕉 {库存["香蕉"]} 个")  // 2
打印($"一共 {库存.数量} 种")    // 2
```

- `表<文本, 整数>`：键是文本，值是整数；
- `库存["苹果"]` 读值，`库存["苹果"] = 3` 写值；
- `.数量` 返回键值对个数；
- 用 `++` 可以直接给表里的整数加一。

## 键和值的类型

键支持 `文本` 和 `整数`，值支持四种基本类型：

| 写法 | 含义 |
|---|---|
| `表<文本, 整数>` | 名字 → 数量 |
| `表<文本, 小数>` | 名字 → 价格 |
| `表<整数, 文本>` | 学号 → 姓名 |
| `表<文本, 真假>` | 开关名 → 状态 |

```csay 学号表
表<整数, 文本> 学号 = 新 表<整数, 文本>()
学号[1001] = "张三"
学号[1002] = "李四"

打印(学号[1001])    // 张三
打印(学号.含(1003)) // 假
```

键的类型必须一致。`表<整数, 文本>` 不能用文本当键，反过来也一样。

## 含、取值、设置、删除

| 方法 | 作用 | 返回值 |
|---|---|---|
| `.含(键)` | 键是否存在 | `真假` |
| `.取值(键, 默认值)` | 取不到时返回默认值 | 值类型 |
| `.设置(键, 值)` | 写入一个键值对 | 无 |
| `.删除(键)` | 删除键 | 无 |
| `.数量` | 键值对个数 | `整数` |
| `表[键]` | 读写 | 值类型 |

```csay 安全取值
表<文本, 整数> 库存 = 新 表<文本, 整数>()
库存["苹果"] = 3

打印(库存.取值("苹果", 0))  // 3
打印(库存.取值("香蕉", 0))  // 0，默认值

库存.设置("香蕉", 5)
打印(库存["香蕉"])          // 5

库存.删除("苹果")
打印(库存.数量)             // 1
```

直接用 `库存["西瓜"]` 读取一个不存在的键，会抛出“表里没有这个键”的异常并结束程序。所以“键可能不存在”时，先用 `.含` 判断，或者用 `.取值` 给一个明确的默认值。

## 遍历条目

`.条目()` 返回键值对集合，每个元素有 `.键` 和 `.值`：

```csay 遍历条目
表<文本, 整数> 价格 = 新 表<文本, 整数>()
价格["牛奶"] = 3

遍历 (项 在 价格.条目()) {
    打印($"{项.键}：{项.值} 元")  // 牛奶：3 元
}
```

> 注意：表的遍历顺序由内部哈希决定，不保证按插入顺序。需要固定顺序时，把键取出来放进列表排序后再按顺序访问。

## 用表统计词频

表中很常见的用法是计数：键是词，值是出现次数。

```csay 词频
文本[] 词 = ["苹果", "香蕉", "苹果", "橘子", "苹果"];
表<文本, 整数> 频次 = 新 表<文本, 整数>();

遍历 (文本 一个 在 词) {
    频次[一个] = 频次.取值(一个, 0) + 1;
}

打印($"苹果出现 {频次["苹果"]} 次")  // 3
打印($"香蕉出现 {频次["香蕉"]} 次")  // 1
打印($"不同单词 {频次.数量} 个")    // 3
```

`频次.取值(一个, 0)` 在键不存在时返回 0，再加一，正好完成“第一次见到就建键，后面累加”。

## 表与列表怎么选

| 需求 | 选择 |
|---|---|
| 按连续下标访问 | 列表 |
| 按名字、学号等键查找 | 表 |
| 需要固定顺序 | 列表 |
| 需要快速判断“有没有” | 表 |
| 需要排序、切片 | 列表 |

## 小结

- 表用 `新 表<键类型, 值类型>()` 创建。
- 用 `表[键]` 读写，键支持文本和整数。
- `.含` 判断存在，`.取值` 提供默认值，`.删除` 删除键。
- `.条目()` 遍历键值对，顺序不保证。
- 词频统计是表的典型用法。
