# 运算符

运算符用来对值做计算。Csay 的运算符和 C# 基本一致，不需要记额外的符号。

## 算术运算符

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加法、文本拼接 | `3 + 2` | `5` |
| `-` | 减法 | `3 - 2` | `1` |
| `*` | 乘法 | `3 * 2` | `6` |
| `/` | 除法 | `7 / 2` | `3`（整数除法） |
| `%` | 取余 | `7 % 2` | `1` |
| `++` | 自增 1 | `计数++` | 原值加 1 |
| `--` | 自减 1 | `计数--` | 原值减 1 |

```csay 算术运算
整数 甲 = 7
整数 乙 = 2

打印(甲 + 乙)      // 9
打印(甲 - 乙)      // 5
打印(甲 * 乙)      // 14
打印(甲 / 乙)      // 3，整数除法
打印(甲 % 乙)      // 1
打印(7.0 / 2.0)    // 3.5
```

整数除法和取余只对整数有意义。需要小数结果时，把其中一个操作数写成小数；小数不能取余。

## 比较运算符

比较的结果是 `真` 或 `假`：

| 运算符 | 含义 |
|---|---|
| `==` | 等于 |
| `!=` | 不等于 |
| `<` `<=` | 小于、小于等于 |
| `>` `>=` | 大于、大于等于 |

```csay 比较大小
整数 甲 = 5
整数 乙 = 8

打印(甲 == 乙)   // 假
打印(甲 != 乙)   // 真
打印(甲 < 乙)    // 真
打印(甲 >= 乙)   // 假
```

文本可以直接用 `==` 和 `!=` 比较内容，但不能用 `<`、`>` 比较大小：

```csay 文本比较
打印("abc" == "abc");
打印("abc" != "def");
```

## 逻辑运算符

| 运算符 | 含义 | 说明 |
|---|---|---|
| `&&` | 并且 | 两边都为真才为真 |
| `\|\|` | 或者 | 至少一边为真就为真 |
| `!` | 取反 | 真变假，假变真 |

`&&` 和 `||` 有短路行为：左边已经能决定结果时，右边不会执行。

```csay 逻辑运算
整数 分数 = 85

打印(分数 >= 60)                 // 真
打印(分数 >= 60 && 分数 < 90)    // 真
打印(分数 >= 90 || 分数 < 60)    // 假
打印(!(分数 == 100))             // 真
```

注意 `&&`、`||` 只能用于布尔值。`若 (分数)` 这种写法不合法，必须写成 `若 (分数 >= 60)`。

## 赋值运算符

除了最基本的 `=`，还可以把运算和赋值合在一起：

| 写法 | 等价于 |
|---|---|
| `甲 += 乙` | `甲 = 甲 + 乙` |
| `甲 -= 乙` | `甲 = 甲 - 乙` |
| `甲 *= 乙` | `甲 = 甲 * 乙` |
| `甲 /= 乙` | `甲 = 甲 / 乙` |
| `甲 %= 乙` | `甲 = 甲 % 乙` |

```csay 复合赋值
整数 计数 = 10;
计数 += 5;
计数--;
计数 *= 2;

打印(计数);
```

`计数++` 是后置自增，先返回原值再加一；`++计数` 是前置自增，先加一再返回。日常写循环时两者效果一样，不需要特意区分。

## 三元运算符

`条件 ? 值1 : 值2` 根据条件返回其中一个值：

```csay 三元运算
整数 年龄 = 17
文本 结果 = 年龄 >= 18 ? "成年" : "未成年"
打印(结果)  // 未成年
```

三元表达式适合很短的选择。分支里有多条语句时，用 `若 / 否则` 更清楚。

## 运算优先级

优先级从高到低大致是：

1. 括号 `( )`；
2. `!`、`++`、`--`；
3. `*`、`/`、`%`；
4. `+`、`-`；
5. `<`、`<=`、`>`、`>=`；
6. `==`、`!=`；
7. `&&`；
8. `||`；
9. `? :`；
10. 赋值 `=` 及其复合形式。

不确定时直接加括号。括号是唯一不花钱就能让代码变清楚的东西：

```csay 用括号明确顺序
打印((2 + 3) * 4);
打印(2 + 3 * 4);
```

## 小结

- 算术 `+ - * / %`，整数除法会截断。
- 比较返回 `真` / `假`；文本只能比较相等，不能比大小。
- 逻辑 `&&`、`||`、`!` 只接受布尔值，并且有短路。
- `+=` 等复合赋值和 `++` / `--` 可以少写重复代码。
- `条件 ? 值1 : 值2` 适合简单选择。
- 不确定优先级就加括号。
