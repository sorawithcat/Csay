# Lambda 表达式

## Lambda 表达式

Lambda 用 `=>` 创建函数值。参数必须带类型：

```csay Lambda
变换 加倍 = (整数 x) => x * 2
问候 问好 = () => "你好"
行动 记录 = (文本 s) => { 打印(s) }

打印(加倍(5))   // 10
打印(问好())    // 你好
记录("块体")    // 块体

委托 变换(整数): 整数;
委托 问候(): 文本;
委托 行动(文本): 无;
```

有两种写法：

- 表达式体：`(整数 x) => x * 2`，箭头右边是一个表达式，它的值就是返回值；
- 块体：`(文本 s) => { 打印(s) }`，箭头右边是语句块；有返回值时在块里写 `返回 值;`，无返回值委托可以省略返回。

Lambda 的返回类型由委托的签名决定；参数类型和返回类型要与委托声明一致。
