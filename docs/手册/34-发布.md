# 发布

## 发布前检查

发布前运行：

```bash
npm run release
```

它会检查版本号、运行时头文件、C 代码可重复性，并跑完整语言测试；不生成安装包。

## 只运行程序

编辑器“打包”生成 `dist/<输出名>-<版本>.zip`，里面包含 exe、项目文件、源码和 `README.txt`。对方解压后双击 exe 即可，不需要安装 Csay 或 C 编译器。

## 让对方编写 Csay

发布 `release/Csay-<版本>-win64.zip`。当前 `release/Csay-0.2.0-win64.zip` 已生成；包内包含安装脚本、编辑器、命令行、TCC、文档和示例，解压后双击 `安装Csay.bat`。

两种包都面向 64 位 Windows。未签名的 exe 第一次运行可能触发 SmartScreen，需要选择“更多信息 → 仍要运行”。

相关：[安装](01-安装.md)、[项目与打包](31-项目与打包.md)。
