# 文本

文本用双引号 `"..."` 或中文引号 `“...”` 包起来，按 UTF-8 保存，长度和下标按 Unicode 码点计算。

```csay 文本字面量
文本 名字 = "小明";
打印("你好，{名字}！");       // 插值
打印($"明年你 {18 + 1} 岁");  // $ 可省略
```

## 转义

| 写法 | 结果 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |
| `\{` | 字面量左花括号 |

```csay 转义字符
打印("第一行\n第二行");
打印("引号：\"你好\"");
打印("花括号：\{名字\}");
```

## 长度与下标

```csay 长度下标
文本 s = "甲乙丙";
打印(s.长度);   // 3
打印(s[0]);     // 甲
打印(s[2]);     // 丙
```

`.长度` 是码点数，不是 UTF-8 字节数。下标从 0 开始；越界返回空文本，不抛异常。

## 拼接与切分

`+` 拼接两个文本；文本不能直接和数字相加，混合内容用插值。

```csay 拼接切分
文本 行 = "苹果,香蕉,橘子";
列表<文本> 词 = 行.切分(",");
打印(词.数量);              // 3
打印(词[1]);                // 香蕉
打印("a b  c".切分空白().数量); // 3
```

- `.切分(分隔符)` 保留空段；
- `.切分空白()` 按连续空白切分，丢弃空段。

## 查找与替换

```csay 查找替换
打印("abcdef".含("cd"));        // 真
打印(查找文本("甲乙丙", "乙")); // 1
打印(查找文本("甲乙丙", "丁")); // -1
打印("a-b-c".替换("-", "+"));   // a+b+c
```

`.替换(旧, 新)` 替换全部出现；`查找文本` 返回码点下标，找不到返回 `-1`。

## 大小写与空白

```csay 大小写
打印(转大写("abc"));        // ABC
打印(转小写("ABC"));        // abc
打印("  hi  ".去除空白());  // hi
```

大小写只处理 ASCII 字母；`去除空白` 去掉首尾空白，不删除中间空白。

## 成员与函数

| 写法 | 作用 |
|---|---|
| `s.长度` | 码点数 |
| `s[下标]` | 取一个码点，越界返回空文本 |
| `s.切分(分隔符)` / `s.切分空白()` | 切分 |
| `s.含(子串)` | 是否包含 |
| `s.替换(旧, 新)` | 替换全部 |
| `s.转大写()` / `s.转小写()` | ASCII 大小写 |
| `s.去除空白()` | 去首尾空白 |
| `s.转整数()` / `s.转浮点数()` / `s.转长小数()` | 转数字 |
| `文本长度(s)` | 同 `s.长度` |
| `重复文本` / `连接文本` | 重复、连接 |
| `格式化` / `填充文本` | 格式化 |
| `查找文本(s, 子串)` | 查找下标 |
