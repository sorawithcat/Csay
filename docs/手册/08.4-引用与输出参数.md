# 引用与输出参数

参数前写 `引用` 或 `输出`，函数就能修改调用方的变量：

```csay 引用参数
整数 a = 1;
整数 b = 0;
整数 c = 加一(引用 a, 输出 b);
打印(c); // 2
打印(a); // 2
打印(b); // 5

整数 加一(引用 整数 x, 输出 整数 y) {
    x++;
    y = 5;
    返回 x;
}
```

调用时必须也写 `引用`/`输出`，传入的实参必须是变量。`输出` 只表示这个参数会被写入，函数内部仍可读取它。顶层函数、普通方法、构造器、虚拟/覆盖/抽象方法和接口方法都支持，参数不能是数组，也不能带默认值。

```csay 方法引用参数
类 计数器 {
    公开 无 加一(引用 整数 x) {
        x++;
    }
}

计数器 c = 新 计数器();
整数 n = 1;
c.加一(引用 n);
打印(n); // 2
```

虚拟、覆盖、抽象方法和接口方法同样支持：

```csay 虚拟与接口引用参数
接口 可加 {
    无 增加(引用 整数 x);
}

类 基础 {
    公开 虚拟 无 增加(引用 整数 x) {
        x = x + 1;
    }
}

类 子类 : 基础, 可加 {
    公开 覆盖 无 增加(引用 整数 x) {
        x = x + 10;
    }
}

基础 对象 = 新 子类();
整数 n = 1;
对象.增加(引用 n);
打印(n); // 11
```

构造器同样支持 `引用`/`输出`，调用 `新` 时仍要写前缀：

```csay 构造器引用参数
类 配置 {
    公开 整数 值;
    公开 配置(输出 整数 结果) {
        结果 = 7;
        自.值 = 结果;
    }
}

整数 r = 0;
配置 c = 新 配置(输出 r);
打印(r); // 7
```
