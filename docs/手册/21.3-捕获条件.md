# 捕获条件

捕获后面可以写 `若 (条件)`，只有条件为真时才进入这个分支；条件为假时继续尝试后面的捕获：

```csay 捕获条件
试 {
    抛出 文件异常("权限不足");
} 捕获 (文件异常 错) 若 (错.信息 == "文件不存在") {
    打印("处理不存在");
} 捕获 (文件异常 错) 若 (错.信息 == "权限不足") {
    打印($"处理权限：{错.信息}"); // 处理权限：权限不足
} 捕获 (文件异常 错) {
    打印("其他文件错误");
}
```

条件必须是真假值，并且可以访问当前捕获到的异常变量；不写 `若` 时只按异常类型匹配。
