# 访问控制与只读

字段、方法、属性、构造器和静态成员都可以写访问修饰符：

| 修饰符 | 谁能访问 |
| --- | --- |
| `公开` | 任何位置，默认值 |
| `私有` | 只有声明它的类自己 |
| `保护` | 声明它的类和子类 |
| `内部` | 同一次构建内可见；当前没有多程序集，等价于公开 |

`保护` 成员可以被子类直接使用；`内部` 目前在单程序集构建里等价于 `公开`：

同一个成员只能写一个访问修饰符，例如 `公开 私有` 会直接报错。构造器也可以写访问修饰符；`私有` 构造器只能在类内部 `新`，`保护` 构造器可以在子类构造器里通过 `: 基(...)` 使用。

字段、属性和方法还可以组合 `静态`、`只读`/`常`、`虚拟`/`覆盖`/`抽象`：

- `静态` 可以与 `只读`/`常` 组合成静态只读字段；不能和 `虚拟`、`覆盖`、`抽象` 组合。
- `常` 只能用于字段；`只读` 可用于字段，也可用于只有 `取` 访问器的属性，不能再写 `写`。
- `虚拟`、`覆盖`、`抽象` 只能用于方法；抽象方法不能是 `私有`。
- 静态属性和静态字段一样用类型名访问，不能声明为 `虚拟`、`覆盖` 或 `抽象`。

```csay 保护与内部
储蓄账户 甲 = 新 储蓄账户();
甲.存入(10.0);
打印(甲.查询());          // 10

公开 类 银行账户 {
    保护 长小数 余额;
    内部 无 记录() { }
    公开 长小数 查询() { 返回 余额; }
}

公开 类 储蓄账户 : 银行账户 {
    公开 无 存入(长小数 x) {
        余额 = 余额 + x;
    }
}
```

字段还可以用 `只读` 或 `常` 修饰。只读字段只能在构造器里赋值，对象创建完成后就不能再改。

```csay 只读字段
账号 甲 = 新 账号("小明");
打印(甲.名称);

公开 类 账号 {
    公开 只读 文本 名称;

    公开 账号(文本 名称) {
        自.名称 = 名称;
    }
}
```

在构造器外写 `甲.名称 = "小红"` 会编译失败。

`常` 是编译期常量，必须在声明处用常量表达式初始化，不能在构造器或别处赋值。初始值可以写字面量、括号、一元 `+`/`-`/`!` 和数字或真假运算，不能引用变量、字段或函数：

```csay 常字段
设置 甲 = 新 设置();
打印(甲.最大);  // 105

公开 类 设置 {
    公开 常 整数 最大 = 100 + 5;
    公开 静态 常 文本 单位 = "次";
}
```

`常` 字段可以用于 `情况` 等需要编译期值的位置。`只读` 字段仍然只能在构造器里赋值。
