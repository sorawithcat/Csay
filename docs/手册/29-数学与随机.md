# 数学与随机

数学函数分三类：取整与绝对值、三角与指数对数、随机数。它们都返回基本数值类型，不抛异常。

## 取整与符号

```csay 取整
打印(四舍五入(3.7))          // 4
打印(四舍五入(-3.7))         // -4
打印(向下取整(3.7))      // 3
打印(向上取整(3.1))      // 4
打印(截断(-3.7))         // -3
打印(符号(-2))           // -1
打印(绝对值(-2.5))       // 2.5
打印(最大(3, 5))         // 5
打印(最小(3, 5))         // 3
```

- `四舍五入` 四舍五入到最近的整数，`.5` 远离零；
- `向下取整` / `向上取整` 对应 floor / ceil；
- `截断` 直接去掉小数部分，向零靠拢；
- `符号` 返回 `-1`、`0` 或 `1`；
- `最大` / `最小` 接受两个数。

## 幂与开方

```csay 幂
打印(开方(16.0))          // 4
打印(幂(2.0, 10.0))       // 1024
打印(指数(1.0))           // 2.718...
打印(自然对数(指数(1.0))) // 1
打印(常用对数(100.0))     // 2
```

`开方` 的参数是数值，返回 `长小数`。`幂(底, 指数)`、`指数`、`自然对数` 和 `常用对数` 都使用长小数浮点运算；`浮点数` 参数会先提升为长小数。

## 三角函数

```csay 三角函数
打印(圆周率())                     // 3.141592653589793
打印(正弦(圆周率() / 2.0))        // 1
打印(余弦(0.0))                    // 1
打印(正切(0.0))                    // 0
打印(反正弦(1.0))                  // 1.570...
打印(反余弦(1.0))                  // 0
打印(反正切(1.0))                  // 0.785...
打印(反正切2(1.0, 1.0))            // 0.785...
```

三角函数的参数是弧度，不是角度。角度转弧度用 `角度 * 圆周率() / 180.0`。

## 随机数

```csay 随机数
随机种子(42)              // 固定序列，方便复现
打印(随机())              // 0.0 ≤ x < 1.0
打印(随机整数(1, 6))      // 1 到 6，包含两端
```

- `随机()` 返回 `[0, 1)` 的 `长小数`；
- `随机整数(最小, 最大)` 返回闭区间内的整数，两个参数顺序可以反过来；
- `随机种子(整数)` 固定后续随机序列，便于测试复现。

不调用 `随机种子` 时，每次运行使用不同的种子。随机数不适合密码学用途。

## 溢出与精度

`整数` 是 32 位有符号数，`长整数` 是 64 位有符号数；赋给较窄的整数类型时会截断。`长小数` 是 64 位浮点，`0.1 + 0.2` 不会精确等于 `0.3`；比较浮点时要留一个误差范围：

```csay 浮点比较
长小数 甲 = 0.1 + 0.2
若 (绝对值(甲 - 0.3) < 0.000001) {
    打印("约等于 0.3")
}
```

## 函数一览

| 函数 | 作用 |
|---|---|
| `四舍五入(x)` | 四舍五入到整数 |
| `绝对值(x)` | 绝对值 |
| `开方(x)` | 平方根 |
| `幂(底, 指数)` | 乘方 |
| `指数(x)` / `自然对数(x)` / `常用对数(x)` | e 的幂 / 自然对数 / 以 10 为底 |
| `向下取整(x)` / `向上取整(x)` / `截断(x)` | floor / ceil / 向零截断 |
| `符号(x)` | -1、0、1 |
| `最大(a, b)` / `最小(a, b)` | 两数比较 |
| `正弦/余弦/正切(x)` | 三角函数，弧度 |
| `反正弦/反余弦/反正切(x)` | 反三角函数 |
| `反正切2(y, x)` | 根据坐标求角度 |
| `圆周率()` | 圆周率 |
| `随机()` / `随机整数(最小, 最大)` / `随机种子(n)` | 随机数 |

完整清单见[标准库索引](36-标准库索引.md)。
