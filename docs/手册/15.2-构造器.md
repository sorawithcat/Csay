# 构造器

构造器在 `新` 的时候执行，用来把对象初始化到可用状态。构造器没有返回类型，也不能写 `返回 值`：

构造器和方法的参数都可以写默认值，规则与普通函数相同；省略的实参在调用处补上默认表达式。构造器参数也支持 `引用`/`输出`，规则见[引用与输出参数](08.4-引用与输出参数.md)。

```csay 构造器
文本 描述(整数 宽, 整数 高) {
    矩形 甲 = 新 矩形(宽, 高);
    返回 $"面积 {甲.面积()}，周长 {甲.周长()}";
}

打印(描述(3, 4))  // 面积 12，周长 14

公开 类 矩形 {
    私有 整数 _宽;
    私有 整数 _高;

    公开 矩形(整数 宽, 整数 高) {
        _宽 = 宽;
        _高 = 高;
    }

    公开 整数 面积() {
        返回 _宽 * _高;
    }

    公开 整数 周长() {
        返回 2 * (_宽 + _高);
    }
}
```

`甲` 是局部对象，离开函数后不再使用。普通对象由垃圾回收在合适时机自动释放；需要更短、更确定的生命周期时，可以用后面的《区域与内存》。
