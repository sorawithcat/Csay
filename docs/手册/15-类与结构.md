# 类与对象

类是把数据和行为包在一起的模板。对象是按这个模板创建出来的实例。

## 定义一个类

```csay 第一个类
圆 甲 = 新 圆(2.0)   // 创建一个半径为 2 的圆
打印(甲.面积())       // 约 12.566

公开 类 圆 {
    私有 长小数 _半径;

    公开 圆(长小数 半径) {
        _半径 = 半径;
    }

    公开 长小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }
}
```

这段代码包含了一个类的全部基本部件：

- `公开 类 圆 { ... }`：声明一个叫 `圆` 的类；
- `私有 长小数 _半径;`：字段，保存对象的数据；
- `公开 圆(长小数 半径) { ... }`：构造器，名字必须和类名相同，没有返回类型；
- `公开 长小数 面积() { ... }`：方法，定义对象能做什么；
- `新 圆(2.0)`：创建对象并调用构造器；
- `甲.面积()`：通过对象调用方法。

构造器里的 `_半径 = 半径` 把参数保存到字段。字段在对象创建时分配，之后每个对象各有一份。

类和表一样是引用类型：`圆 甲;` 只声明不创建对象，`甲` 是空引用，调用 `甲.面积()` 会在运行期崩溃。必须写成 `圆 甲 = 新 圆(...)`；`结构` 是值类型，声明后字段会按默认值初始化。

可能为空的引用可以用 `?.` 读取成员：`甲?.半径` 在 `甲` 为空时得到 `空`，不会崩溃。`?.` 也可用于接口对象，结果可以是文本、类、接口、列表、表、数组、委托或异常；每个可能为空的环节都要单独写 `?.`，详见[运算符](05-运算符.md)。

> 注意：顶层语句、函数和类型声明可以按任意顺序书写。上面是“先用类，后定义类”，这种写法同样有效。

## 字段与方法

字段默认是对象的一部分，方法里可以直接用字段名：

```csay 计数器
计数器 甲 = 新 计数器();
甲.加一()       // 次数 = 1
甲.加一()       // 次数 = 2
甲.加一()       // 次数 = 3
打印(甲.当前()) // 3

公开 类 计数器 {
    公开 整数 次数;

    公开 计数器() {
        次数 = 0;
    }

    公开 无 加一() {
        次数++;
    }

    公开 整数 当前() {
        返回 次数;
    }
}
```

`次数` 是 `公开` 的，所以外面也能直接读写 `甲.次数`。如果它是 `私有`，编译器会拒绝类外的访问，只能由类自己的方法使用。

## 表达式体成员

只有一个表达式的方法和只读属性可以用 `=>` 简写：

```csay 表达式体成员
圆 甲 = 新 圆(2.0);
打印(甲.面积()); // 4
打印(甲.直径);   // 4

公开 类 圆 {
    公开 长小数 半径;
    公开 圆(长小数 半径) => 自.半径 = 半径;
    公开 长小数 面积() => 半径 * 半径;
    公开 长小数 直径 => 半径 * 2;
}
```

`=>` 后面只能写一个表达式；需要多条语句时仍然写 `{ ... }`。

## 自

当参数名和字段名相同时，用 `自` 指代当前对象：

```csay 自
点 甲 = 新 点(3.0, 4.0);
打印(甲.长度());

公开 类 点 {
    公开 长小数 横;
    公开 长小数 纵;

    公开 点(长小数 横, 长小数 纵) {
        自.横 = 横;
        自.纵 = 纵;
    }

    公开 长小数 长度() {
        返回 开方(横 * 横 + 纵 * 纵);
    }
}
```

`自.横` 是字段，右边的 `横` 是参数。如果名字不冲突，可以省略 `自`；冲突时必须写，否则赋值的还是参数自己。

## 类和结构

`结构` 的写法与类相似，但按值复制，适合很小的数据：

```csay 结构按值复制
点 甲 = 新 点(3, 4)   // 甲 = (3, 4)
点 乙 = 甲            // 复制一份，乙 和 甲 互不影响
乙.x = 99
打印(甲.x)            // 3
打印(乙.x)            // 99

公开 结构 点 {
    公开 整数 x;
    公开 整数 y;

    公开 点(整数 a, 整数 b) {
        x = a;
        y = b;
    }
}
```

`结构` 支持字段、构造器、方法和 `新`；赋值或传参时复制整个值，不会共享同一个对象。需要引用语义、继承或多个对象共享状态时用 `类`。
