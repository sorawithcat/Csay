# 输入输出

## 命令行参数

`命令行参数()` 返回 `列表<文本>`，不含程序名：

```csay 命令行参数
列表<文本> 参数 = 命令行参数();

若 (参数.数量 == 0) {
    打印("没有参数");
} 否则 {
    打印($"收到 {参数.数量} 个参数");
    遍历 (文本 一个 在 参数) {
        打印(一个);
    }
}
```

运行 `csay 程序.csay 甲 乙` 时，列表是 `甲`、`乙`。

## 输出

`打印(值)` 输出值并换行。文本、整数、浮点数、长小数、真假、字符、列表、表、枚举、异常和 `空` 都可以打印；`空` 输出为 `空`。

`断言(条件, 消息)` 条件为假时抛出 `状态异常`，常用于测试。测试文件见[命令行](30-命令行.md)。
