# 委托与闭包

函数除了直接调用，还可以先存进变量，稍后再调用。Csay 用“委托”描述这种函数值的参数和返回值，用 Lambda 创建函数值。Lambda 用到外层局部变量时，会形成闭包。

## 委托声明

委托是一种类型声明，格式是：

```text
委托 名字(参数类型, ...): 返回类型;
```

例如：

```csay 声明委托
委托 变换(整数): 整数;
委托 问候(): 文本;
委托 行动(文本): 无;
```

委托只描述“能接收什么参数、返回什么”，本身不包含实现。声明放在类型声明区，和类、结构、接口、枚举同级；参数只写类型，不写参数名。

## 空委托

委托变量可以赋 `空`，表示当前没有可调用的函数：

```csay 空委托
变换 操作 = 空;
断言(操作 == 空, "还没有函数");

操作 = (整数 x) => x + 1;
断言(操作 != 空, "已经有函数");
打印(操作(2)); // 3

委托 变换(整数): 整数;
```

调用空委托会在运行期抛出 `委托为空`；需要给默认行为时，用 `??` 合并：

```csay 空委托合并
变换 空操作 = 空;
变换 备用 = (整数 x) => x * 2;
变换 选中 = 空操作 ?? 备用;
打印(选中(3)); // 6

委托 变换(整数): 整数;
```

## 调用委托

委托变量可以像函数一样调用：

```csay 调用委托
变换 f = (整数 x) => x + 1;
打印(f(4))   // 5

委托 变换(整数): 整数;
```

委托字段也可以调用：

```csay 委托字段
计算器 甲 = 新 计算器((整数 x) => x * 3);
打印(甲.算(4))   // 12

公开 类 计算器 {
    公开 变换 规则;

    公开 计算器(变换 规则) {
        自.规则 = 规则;
    }

    公开 整数 算(整数 x) {
        返回 自.规则(x);
    }
}

委托 变换(整数): 整数;
```

调用一个值为空的委托会抛出 `状态异常`，消息是“委托为空”。因此委托字段在调用前必须已经赋值；类里没有初值的委托字段默认是空委托。

## 委托作为参数和返回值

委托是普通类型，可以当参数、返回值和字段类型：

```csay 委托参数
打印(应用((整数 x) => x * x, 5))   // 25
打印(应用(选规则(真), 5))          // 10

整数 应用(变换 f, 整数 x) {
    返回 f(x)
}

变换 选规则(真假 加倍) {
    若 (加倍) {
        返回 (整数 x) => x * 2
    }
    返回 (整数 x) => x + 1
}

委托 变换(整数): 整数;
```

## 闭包：捕获局部变量

Lambda 可以使用创建它的函数里的局部变量。捕获发生在创建 Lambda 的那一刻，按值复制一份：

```csay 闭包
变换 加五 = 造加数(5)
打印(加五(3))   // 8

变换 造加数(整数 增量) {
    返回 (整数 x) => x + 增量
}

委托 变换(整数): 整数;
```

`造加数` 返回以后，参数 `增量` 已经离开作用域，但闭包仍然保存着它的副本，所以 `加五(3)` 还能用。

捕获是复制值，之后再改外层变量不会影响已经创建的闭包：

```csay 捕获后修改
整数 计数 = 10
变换 f = (整数 x) => x + 计数
计数 = 99
打印(f(1))   // 11，不是 100

委托 变换(整数): 整数;
```

需要让多个闭包共享可变状态时，当前要用类字段或表等引用类型；闭包捕获的是值，不是变量本身。

数组也按值捕获，但不是复制元素：闭包保存数组指针和当时的长度。之后修改外层数组的元素，闭包能看到；把外层变量重新赋值为另一个数组，不影响已经创建的闭包：

```csay 捕获数组
整数[] 数 = [10, 20, 30]
变换 f = (整数 i) => 数[i] + 数.长度
数[0] = 99
打印(f(0))   // 102，元素共享
数 = [1, 2]
打印(f(0))   // 102，仍指原数组

委托 变换(整数): 整数;
```

闭包逃逸出函数时，被捕获的数组必须仍然存活；捕获栈上的局部数组并在函数返回后调用闭包，会留下悬空指针。

方法里的 Lambda 可以用 `自` 访问当前对象。此时捕获的是对象引用，之后修改字段，闭包能看到新值：

```csay 捕获自
乘法器 甲 = 新 乘法器(2);
变换 f = 甲.规则();
打印(f(5))      // 10
甲.倍数 = 3;
打印(f(5))      // 15

公开 类 乘法器 {
    公开 整数 倍数;

    公开 乘法器(整数 倍数) {
        自.倍数 = 倍数;
    }

    公开 变换 规则() {
        返回 (整数 x) => x * 自.倍数
    }
}

委托 变换(整数): 整数;
```
