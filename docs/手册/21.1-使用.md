# 使用：自动关闭

## 使用：自动关闭

有些资源用完必须关闭。`使用` 会在离开块时自动调用对象的 `关闭()`，即使块里抛出异常也会调用：

```csay 使用
使用 (新 门()) {
    打印("正常离开");
}

试 {
    使用 (新 门()) {
        抛出 "门里出错了";
    }
} 捕获 (异常 错) {
    打印(错.信息);
}

类 门 {
    公开 门() { }
    公开 无 关闭() {
        打印("关门");
    }
}
```

输出顺序是：

```text
正常离开
关门
关门
门里出错了
```

第二次 `关门` 发生在异常向外抛出之前。`使用` 的目标必须是类对象，类里要有无参的 `关闭()` 方法；目标不是类、缺少 `关闭()`、`关闭()` 是静态方法或带参数，都会在 `--check` 和编辑器里直接报错。

`使用` 的目标表达式只求值一次，之后关闭的是同一个对象；目标为空时不会调用 `关闭()`。`使用` 块里可以写 `返回`、`跳出` 或 `跳过`。离开块前会先调用 `关闭()`；返回表达式的值会先求值，再关闭资源。如果关闭本身抛出异常，异常会继续向外传播，且不会重复调用 `关闭()`。
