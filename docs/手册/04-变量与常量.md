# 变量与常量

变量在声明时写类型，之后只能保存该类型的值：

```csay 声明变量
整数 年龄 = 18
浮点数 比例 = 0.75
长小数 身高 = 1.72
文本 名字 = "小明"
真假 已成年 = 真

打印(名字)
打印(年龄)
```

## 默认值

初始化可以省略，变量会得到该类型的默认值：

```csay 默认值
整数 计数
浮点数 比例
长小数 身高
文本 名字
真假 标志

打印(计数)   // 0
打印(名字)   // 空行
打印(标志)   // 假
```

| 类型 | 默认值 |
|---|---|
| `整数`、`浮点数`、`长小数` | `0` |
| `文本` | 空文本 |
| `真假` | `假` |
| 类、列表、表 | `空` |
| 结构 | 各字段的默认值 |

## 赋值

声明后可以重新赋值，类型不能改变：

```csay 重新赋值
整数 分数 = 60
分数 = 95
打印(分数)   // 95
```

把浮点赋给整数会截断小数部分；需要四舍五入时用 `四舍五入`：

```csay 截断
整数 甲 = 3.7
打印(甲)   // 3
```

## 常量

`常` 声明编译期常量，必须在声明处用常量表达式初始化，之后不能赋值：

```csay 常量
公开 类 圆 {
    公开 常 长小数 圆周率 = 3.141592653589793;
    公开 长小数 半径;

    公开 长小数 面积() {
        返回 圆周率 * 半径 * 半径;
    }
}
```

初始值支持字面量、括号、一元 `+`/`-`/`!` 和数字或真假运算，不能引用变量、字段或函数。读取常量时直接使用声明处的值，因此可以写在 `情况` 等需要编译期值的位置。

## 作用域

变量只在声明它的代码块内有效：

```csay 作用域
若 (真) {
    整数 临时 = 1;
    打印(临时)   // 1
}
// 这里不能再使用 临时
```

内层代码块可以声明与外层同名的变量；离开代码块后恢复外层的名字。
