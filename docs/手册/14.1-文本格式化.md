# 文本格式化

```csay 文本工具
打印(重复文本("哈", 3));       // 哈哈哈

列表<文本> 词 = 新 列表<文本>();
词.追加("甲");
词.追加("乙");
打印(连接文本(词, " / "));     // 甲 / 乙

打印(格式化浮点(3.14159, 2));  // 3.14
打印(填充文本("7", 3, "0"));   // 700
```

`格式化(格式, 列表<文本>)` 用 `%s` 占位，`%%` 输出百分号；占位符和参数数量必须一致，否则抛 `参数异常`：

```csay 格式化
列表<文本> 参数 = 新 列表<文本>();
参数.追加("小明");
参数.追加("3");
打印(格式化("你好，%s！消息 %s 条", 参数));
```
