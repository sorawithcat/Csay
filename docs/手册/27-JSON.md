# JSON

## 序列化

`JSON字符串` 把文本转成带引号、转义后的 JSON 字符串；`JSON序列化` 把值转成 JSON 文本：

```csay JSON序列化
打印(JSON字符串("他说：\"好\""));   // "他说：\"好\""
打印(JSON序列化("abc"));          // "abc"
打印(JSON序列化(42));             // 42
打印(JSON序列化('A'));            // "A"
打印(JSON序列化(真));             // true

整数[] 数组 = [1, 2, 3];
打印(JSON序列化(数组));           // [1,2,3]

列表<整数> 数 = 新 列表<整数>();
数.追加(1);
数.追加(2);
打印(JSON序列化(数));             // [1,2]

表<文本, 文本> 人 = 新 表<文本, 文本>();
人.设置("名字", "小明");
打印(JSON序列化(人));             // {"名字":"小明"}

表<文本, 整数[]> 索引 = 新 表<文本, 整数[]>();
索引["甲"] = [1, 2];
打印(JSON序列化(索引));           // {"甲":[1,2]}

打印(JSON序列化([[1, 2], [3]]));  // [[1,2],[3]]
```

当前支持基本类型、列表、任意嵌套的数组，以及键为文本、整数或真假、值为基本类型、列表、表或数组的表。字符会序列化为字符串。列表和表可以互相嵌套。数组在创建时保存元素个数，因此数组套数组、表值为数组都能序列化；表的键顺序不保证固定。

## 解析

`JSON解析` 把对象或数组解析成一层 `表<文本, 文本>`：

- 对象：键是字段名；
- 数组：键是 `[0]`、`[1]`；
- 字符串会解码转义；
- `true` / `false` 变成文本 `真` / `假`；
- `null` 保留文本 `null`；
- 嵌套对象或数组的值保留原始 JSON 文本，可以再解析一次。

```csay JSON解析
表<文本, 文本> 数据 = JSON解析("\{\"名字\":\"小明\",\"年龄\":18,\"标签\":[\"a\",\"b\"]\}")
打印(数据.取值("名字", "?"));  // 小明
打印(数据.取值("年龄", "?"));  // 18
打印(数据.取值("标签", "?"));  // ["a","b"]

表<文本, 文本> 标签 = JSON解析(数据.取值("标签", "[]"));
打印(标签.取值("[0]", "?"));   // a
```

Csay 普通字符串里的 `{`、`}` 要写成 `\{`、`\}`。格式错误抛 `格式异常`；读取不存在的键用 `.取值(键, 默认值)`。

## 按路径读取

`JSON取值(文本, 路径)` 按 `a.b[0].c` 的形式读取嵌套值，返回文本：

```csay JSON取值
文本 嵌套 = "\{\"用户\":\{\"名字\":\"小明\"\},\"列表\":[10,20]\}";
打印(JSON取值(嵌套, "用户.名字"));  // 小明
打印(JSON取值(嵌套, "列表[1]"));    // 20
```

字符串会解码；数字、`true`、`false`、`null` 和嵌套对象/数组保留原始 JSON 文本。路径写错或键不存在会抛 `格式异常`。键名里含 `.` 或 `[` 时不能用这个函数，先用 `JSON解析` 取出再处理。

## 按路径写入

`JSON设置(文本, 路径, 新值)` 把路径上的值替换成新值，返回完整 JSON 文本。第三个参数必须是一段合法 JSON：

```csay JSON设置
文本 嵌套 = $"\{\"用户\":\{\"名字\":\"小明\"\},\"列表\":[10,20]\}";
文本 改后 = JSON设置(嵌套, "用户.名字", JSON字符串("小红"));
打印(JSON取值(改后, "用户.名字"));  // 小红
打印(JSON取值(JSON设置(嵌套, "列表[1]", "25"), "列表[1]"));  // 25
```

数字和布尔值直接写成 `25`、`true`；文本要用 `JSON字符串` 包成带引号的 JSON 字符串。路径不存在、路径格式不对或原文本不是对象/数组时抛 `格式异常`。
