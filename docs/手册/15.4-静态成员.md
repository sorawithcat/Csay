# 静态成员

字段或方法加 `静态` 后属于类本身，不属于某个对象。用类名访问，不需要 `新`：

```csay 静态成员
计数器.增加();
计数器.增加();
打印(计数器.次数);

公开 类 计数器 {
    公开 静态 整数 次数;

    公开 静态 无 增加() {
        次数 = 次数 + 1;
    }
}
```

输出 `2`。静态字段在所有对象之间共享；静态方法里可以直接写静态字段名，也可以写 `计数器.次数`。

静态字段可以在声明处写初始值：

```csay 静态字段初始化
打印(配置.版本); // 3
打印(配置.名称); // 正式

公开 类 配置 {
    公开 静态 整数 版本 = 3;
    公开 静态 文本 名称 = "正式";
}
```

初始化在程序启动、顶层语句执行前完成，按类型和字段的声明顺序进行。需要根据运行期数据计算的值，仍然要在第一次使用前显式赋值。

属性也可以声明为静态，用类名读写；访问器里没有 `自`，静态字段要写成 `类名.字段`：

```csay 静态属性
打印(配置.倍率); // 4
配置.倍率 = 10;
打印(配置.倍率); // 10

公开 类 配置 {
    公开 静态 整数 基数 = 2;
    公开 静态 整数 倍率 {
        取 { 返回 配置.基数 * 2; }
        写 { 配置.基数 = 值 / 2; }
    }
}
```

静态属性不能是 `虚拟`、`覆盖` 或 `抽象`；需要多态时用实例属性。
