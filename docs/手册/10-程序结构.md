# 程序结构

Csay 程序的最外层是**顶层语句**：直接写在文件里的代码，不需要先包一个类。

```csay 最小的程序
// 顶层语句从第一行开始执行
打印("你好")
```

顶层语句在编译时会被自动放进一个隐藏的入口函数，所以程序启动后从第一条顶层语句开始执行。

## 语句与声明顺序

同一个文件里可以同时有顶层语句、函数和类型声明，顺序不限：

```csay 任意顺序
公开 枚举 颜色 {
    红,
    绿,
}

打印("程序开始")

整数 加一(整数 x) {
    返回 x + 1
}

打印(加一(1))
```

类型声明和函数声明不产生运行时代码；顶层语句按书写顺序执行。上面的程序先打印“程序开始”，再打印 `2`，枚举和函数写在哪里都不影响执行顺序。

函数和类型的具体写法见[函数](08-函数.md)、[类与结构](15-类与结构.md)。

## 注释

Csay 支持两种注释：

- `//` 行注释，从 `//` 到行尾；
- `/* ... */` 块注释，可以跨行。

```csay 两种注释
// 这是一行注释，不会执行
打印("第一行")

/*
   这是块注释
   里面的内容不会执行
*/
打印("第三行") // 行尾也可以写注释
```

注释可以写在代码中间，但不能插在标识符或字符串中间。

## 退出码

顶层代码里的 `返回` 可以设置进程退出码：

```csay 用返回设置退出码
打印("准备退出") // 先输出
返回 0          // 0 表示成功
```

命令行程序常用退出码表示成功或失败；非零值通常表示失败。编辑器里看不到退出码，命令行可以读取。

## 多文件

程序变大后，可以把函数和类型放进单独的文件，在开头用 `引` 引入：

```text
// 工具.csay
整数 加一(整数 x) {
    返回 x + 1
}

// 程序.csay
引 "工具.csay"
打印(加一(2))
```

路径相对于当前源文件；也可以写 `引 工具;`，自动加载同目录的 `工具.csay`。被引文件只能放类型和函数，不能写顶层语句。多个文件都引入同一个文件时，它只加载一次。

命名空间用于把类型声明分组，见[命名空间](09-命名空间.md)。
