# 属性与封装

字段直接暴露给外面用起来方便，但外部可以随便改，类就失去了对数据的控制。**属性**是在字段外面加一层访问器，读写都经过方法。按约定字段用 `私有`、属性用 `公开`；编译器会检查私有成员，类外访问会报错。

## 私有字段 + 公开属性

```csay 账户
账户 甲 = 新 账户(100)   // 初始余额 100
甲.余额 = -5             // 写访问器把负数改成 0
打印(甲.余额)            // 0

甲.余额 = 80             // 正常写入
打印(甲.余额)            // 80
打印(甲.描述)            // 账户余额 80 元

公开 类 账户 {
    私有 整数 _余额;

    公开 账户(整数 初始) {
        _余额 = 初始;
    }

    公开 整数 余额 {
        取 { 返回 _余额; }
        写 { _余额 = 值 < 0 ? 0 : 值; }
    }

    公开 文本 描述 {
        取 { 返回 $"账户余额 {_余额} 元"; }
    }
}
```

属性的写法是：

```
访问修饰符 类型 属性名 {
    取 { 返回 字段; }
    写 { 字段 = 值; }
}
```

- `取` 是 getter，读取属性时执行；
- `写` 是 setter，给属性赋值时执行；
- `值` 是上下文关键字，只在 `写` 块里代表“要赋进来的新值”，其他位置可以当普通变量名；
- 只写 `取` 就是只读属性，外部赋值会报错。

`甲.余额 = -5` 没有直接把字段改成负数，而是走了 `写` 访问器，被改成了 `0`。这就是封装的价值：**数据怎么变由类自己决定**。

## 只读属性

只提供 `取` 的属性，外部只能读：

```csay 只读属性
圆 甲 = 新 圆(2.0);
打印(甲.半径);
打印(甲.面积);

公开 类 圆 {
    私有 长小数 _半径;

    公开 圆(长小数 半径) {
        _半径 = 半径;
    }

    公开 长小数 半径 {
        取 { 返回 _半径; }
    }

    公开 长小数 面积 {
        取 { 返回 3.14159 * _半径 * _半径; }
    }
}
```

注意 `甲.半径` 和 `甲.面积` 后面没有括号。属性看起来像字段，读的时候会自动执行 `取` 块。

## 访问修饰符

| 修饰符 | 设计意图 |
|---|---|
| `公开` | 任何地方都能访问 |
| `私有` | 只应该由类自己访问 |
| `保护` | 类自己和派生类 |
| `内部` | 同一次构建内；当前没有多程序集，等价于公开 |

通常遵循两条：**数据字段尽量用 `私有`，需要给外面用的行为用 `公开` 方法或属性**。`保护` 和 `内部` 在小型程序里很少用到。

> 编译器会检查 `私有` 成员的访问；自举编译器和默认编译器都执行这项检查。

## 方法封装

属性适合包装单个值，复杂一点的校验或计算写成方法：

```csay 方法封装
分数 甲 = 新 分数(3, 4);
打印(甲.显示());
打印(甲.小数值());

公开 类 分数 {
    私有 整数 _分子;
    私有 整数 _分母;

    公开 分数(整数 分子, 整数 分母) {
        _分子 = 分子;
        _分母 = 分母;
    }

    公开 文本 显示() {
        返回 $"{_分子}/{_分母}";
    }

    公开 长小数 小数值() {
        返回 (_分子 + 0.0) / _分母;
    }
}
```

这里没有写校验，分母为 0 会在运行时出错。真实程序里应该在构造器或 setter 里拒绝非法值。
