# 枚举

枚举给一组固定的整数起名字：

```csay 定义枚举
打印(星期.一);   // 0
打印(星期.日);   // 6

公开 枚举 星期 {
    一, 二, 三, 四, 五, 六, 日
}
```

成员从 `0` 开始依次编号。访问成员写 `枚举名.成员`。

枚举是独立的类型：函数参数声明为 `星期` 时，只能传 `星期` 的值，传 `整数` 会在检查阶段报错：

```csay 枚举参数
文本 上班吗(星期 天) {
    选择 (天) {
        情况 星期.六:
        情况 星期.日:
            返回 "休息";
        默认:
            返回 "上班";
    }
}

打印(上班吗(星期.日));  // 休息

公开 枚举 星期 {
    一, 二, 三, 四, 五, 六, 日
}
```

`选择` 的语法、贯穿规则和 `跳出` 见[条件与选择](06-条件与选择.md)。

枚举适合状态、星期、方向等有限集合，也适合替代难懂的数字常量。

相关：[条件与选择](06-条件与选择.md)、[类型系统](03-类型系统.md)。
