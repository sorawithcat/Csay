# 编辑器

运行 `csay-editor` 或开始菜单中的「Csay 编辑器」即可打开。

## 界面

- 顶栏“打开”可选择打开文件或项目文件夹；关闭编辑器后再次打开会自动恢复上次的工作区、标签页和光标位置；
- 左侧工作区文件树，可切换文件夹、筛选 `.csay` / `.csayproj`；
- 中间多标签编辑区，带行号、语法高亮、自动缩进和注释切换；侧栏与底部面板的分隔条可拖动调整宽高；
- 标签可以拖出主区域，成为可移动、可缩放的独立面板，点“停靠”放回标签栏；
- 鼠标停在变量、函数、类型或成员上显示签名与说明，跨 `引` 文件也能识别；
- `///` 文档注释会进入悬浮说明；
- 底部“问题 / 输出 / 引用”面板；
- 顶栏保存、打开、运行、项目、打包、设置、文档。

“设置”左侧是分类目录，右侧显示当前页：常规控制保存时自动排版；编辑下的自动补全可开关括号、引号、注释补全和代码悬浮；外观调整字号、缩进和格式化时的花括号位置。子页顶部显示当前路径，可点路径返回上一级。设置保存在浏览器本地，默认开启自动排版。

文件树右键支持新建、重命名、删除、复制路径、在资源管理器中显示、设为项目入口和打包；标签页右键支持关闭和复制路径。

## 编辑功能

- 输入 `对象.` 或 `对象?.` 按接收者类型列出字段和方法，显示参数、返回值和说明；用户泛型类会把 `元素` 替换成实际类型参数；
- 输入 `新` 后只列类型，不混入函数和关键字；
- 普通补全只列出当前语言支持的候选，并按类型、方法、字段、局部变量、函数和关键字分类排序；内建函数以函数形式插入，类型名单独标记；变量只列当前光标之前、且位于当前或外层块里的声明，不再混入后面或其他分支的局部变量；函数/方法参数只在所属函数体内参与补全，不会泄漏到函数外；类内输入 `自.` 时会列出当前类及继承来的字段和方法，`基.` 会列出父类的字段和方法；输入类名加 `.` 只列出静态成员，输入对象加 `.` 只列出实例成员；输入枚举类型名加 `.` 会列出该枚举的成员；
- 输入 `{`、`(`、`[`、`"` 自动补右半边，输入 `/*` 自动补 `*/`，输入 `///` 生成文档注释模板；中文输入法产生的 `「」` 会自动纠正为花括号，这个纠正不受自动补全开关影响；
- 方法补全插入 `()`，光标停在括号内；
- 鼠标悬停补全候选或代码中的标识符，显示签名、类型和说明；枚举成员会显示所属枚举；函数或方法的参数在签名和函数体内悬浮时显示参数类型、所属函数/方法，引用/输出参数也会标出；调用实参悬浮时显示对应形参的名称、类型、序号和完整函数/方法签名。
- `F12` 转到定义，`Shift+F12` 查找引用，结果可跨文件跳转；内建函数按 `F12` 显示签名和说明；
- `F2` 在当前工作区及其 `引` 依赖中重命名符号，跳过注释和字符串；
- `Ctrl+S` 保存前按标准格式重新打印当前 `.csay` 文件（可在设置中关闭；语法有错时保留原文并提示）；
- `Shift+Alt+F` 格式化整个文件，`Ctrl+Alt+F` 按当前缩进格式化选中行；格式化使用“外观”里设置的缩进空格数和花括号位置，选中区域必须是完整语句，否则保留原文并提示；
- 大文件按可视区域增量高亮。

点击问题可以直接打开对应文件并定位。重命名会修改当前工作区及其 `引` 依赖中同名的标识符。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+S` | 保存；开启自动排版时先格式化 |
| `Ctrl+Enter` / `F5` | 编译并运行 |
| `Ctrl+N` | 新建文件 |
| `Ctrl+O` | 打开文件夹 |
| `Ctrl+Shift+O` | 打开文件 |
| `Ctrl+W` | 关闭标签 |
| `Ctrl+,` | 打开编辑器设置 |
| `Ctrl+/` | 切换行注释 |
| `F12` / `Shift+F12` | 定义 / 引用 |
| `F2` | 重命名当前工作区及 `引` 依赖中的符号 |
| `Shift+Alt+F` | 格式化整个文件 |
| `Ctrl+Alt+F` | 格式化选中行 |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进 |
| `F1` | 打开文档 |

## 项目

编辑器会在浏览器本地保存上次打开的工作区和文件标签；下次打开时自动恢复。若文件已被移动或删除，只跳过该文件并保留仍然可用的工作区。

打开项目目录后，顶栏“项目”可设置名称、入口、输出名、版本、资源文件、依赖项目、构建前/后命令和多个目标。项目文件按目录独立；同名项目文件会在文件树中标出所在目录。入口必须是项目目录内的 `.csay` 文件。点击“打包”会先构建依赖项目，再带上资源文件并执行构建命令，生成 `dist/<输出名>-<版本>.zip`，详见[项目与打包](31-项目与打包.md)。

编辑器服务随启动它的命令行窗口存在；关闭窗口后服务停止。启动时可以带文件名：

```bash
csay-editor 我的程序.csay
```
