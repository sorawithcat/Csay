# 循环

循环让一段代码重复执行。本页说明 `只要`、`做…只要`、`循环`，以及循环里的 `跳出` 和 `跳过`。

## 只要循环

`只要 (条件)` 在条件为真时反复执行，条件为假时结束：

```csay 只要循环
整数 计数 = 5

只要 (计数 > 0) {
    打印($"倒计时 {计数}")  // 5、4、3、2、1
    计数--                  // 每轮减 1
}

打印("发射！")
```

条件在每次循环开始时检查。如果一开始条件就是假，循环体一次也不会执行。

## 做…只要

`做 { } 只要 (条件)` 会**先执行一次**循环体，再检查条件：

```csay 做只要
整数 次数 = 0

做 {
    次数++                  // 第一次进来先变成 1
    打印($"第 {次数} 次")    // 1、2、3
} 只要 (次数 < 3)
```

注意 `只要` 写在右花括号后面，和 `若` 的写法不同。

## 循环

`循环` 适合“从起点走到终点”的计数循环：

```csay 循环
循环 (整数 i = 1; i <= 5; i++) {
    打印($"第 {i} 天")      // 1 到 5
}
```

括号里用两个分号分成三部分：初始化、条件、每轮结束后的更新。两个分号必须写；分号在中文输入法下是 `；` 也可以，但为了可读性建议用半角。

## 跳出与跳过

- `跳出`：立刻结束整个循环；
- `跳过`：结束本轮，继续下一轮。

```csay 跳出与跳过
循环 (整数 i = 1; i <= 10; i++) {
    若 (i == 3) {
        跳过;               // 3 不打印
    }
    若 (i == 6) {
        跳出;               // 到 6 时整个循环结束
    }
    打印(i);                // 1、2、4、5
}
```

`继续` 不是 Csay 的关键字。要跳过本轮，写 `跳过`，不加括号。

## 嵌套循环

循环可以嵌套，`跳出` / `跳过` 只作用于它所在的那一层：

```csay 嵌套循环
循环 (整数 行 = 1; 行 <= 3; 行++) {
    循环 (整数 列 = 1; 列 <= 3; 列++) {
        打印($"{行}-{列}")   // 1-1、1-2……3-3
    }
}
```

## 什么时候用哪种

| 场景 | 推荐写法 |
|---|---|
| 次数不确定，条件满足就继续 | `只要` |
| 至少执行一次 | `做…只要` |
| 有明确计数范围 | `循环` |

所有 `只要 (真)` 都能写，但必须确保循环体里有 `跳出` 或 `返回`，否则程序会一直卡住。
