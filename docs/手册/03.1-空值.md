# 空值

## 空值

类、接口、列表、表、数组和委托可以用 `空` 表示“还没有对象”：

```csay 空引用
圆 甲 = 空;
若 (甲 == 空) {
    打印("还没有对象");
}

公开 类 圆 {
    公开 长小数 半径;
}
```

`空` 目前可以赋给类、接口、列表、表、数组、委托和异常。`文本` 的默认值是空字符串，不是 `空`；判断文本是否为空用 `文本长度(s) == 0`。`结构` 是值类型，不能用 `空`。数组为 `空` 时长度为 0；委托为 `空` 时调用会抛出 `委托为空`；接口为 `空` 时不能访问成员；异常为 `空` 时可以用 `??` 合并，也可以和 `空` 比较。

访问空引用的成员（例如 `甲.半径`）会在运行期崩溃，调用前先和 `空` 比较。直接写 `空.成员`、`空[下标]` 或 `空()` 会在检查阶段报错。编译器还会跟踪局部变量：声明为 `空` 且之后没有赋非空值的类、接口或委托变量，直接写 `.`、`[]` 或 `()` 也会在检查阶段报错；在 `若 (甲 != 空)` 的分支里，`甲` 被视为非空；`甲 != 空 && ...` 的右侧和循环体在条件保证非空时也会这样处理。循环条件写成 `甲 != 空` 时，循环结束后 `甲` 被视为可能为空；循环体里的 `跳出` 会合并跳出时的状态，跳出前 `甲` 非空时不会误报为空。方法内给 `自.字段` 或局部对象的 `对象.字段`（支持嵌套字段）赋 `空` 后，再对同一字段写嵌套 `.`/`[]`/`()` 也会报错，`若` 分支结束后按两边都为空才保留；`若 (对象.字段 != 空)` 的分支里该字段视为非空，`若 (对象.字段 == 空)` 的否则分支同样。默认值为 `空` 的参数在函数体内也按可能为空处理；当前项目加载的文件（含 `引`）中，顶层函数或方法可能返回 `空` 时，调用结果也按可能为空处理；调用点传入 `空` 的普通参数（含方法实参）在函数体内也按可能为空处理；同名方法会保守合并。其他参数和未加载文件见[未来计划](../未来计划.md)，需要先用 `?.` 或显式判断。Csay 支持 `??` 空合并和 `?.` 空安全访问：`甲?.名字` 在 `甲` 为空时得到 `空`，否则读取成员。`?.` 接受类、接口对象、列表、表、数组或异常；列表和表支持 `?.数量`/`?.长度`，列表还支持数值元素的 `?.最大()`/`?.最小()`，表还支持 `?.含()` 和 `?.取值(键, 缺省值)`（文本、数值、真假、列表或表值），数组支持 `?.长度`，为空时得到 0、假或缺省值；异常只支持 `?.信息` 和 `?.类型`，为空时得到空文本。结果可以是文本、类、接口、列表、表、数组、委托或异常；整数、布尔等值类型不能为空，不能用在 `?.` 后面。把 `空` 赋给 `文本`、整数或结构会在检查阶段报类型错误；`文本` 也不能和 `空` 比较，判断空文本请用 `文本长度(s) == 0`。`打印(空)` 输出 `空`。

```csay 空合并
类 人 {
    公开 文本 名字;
    公开 人(文本 名字) {
        自.名字 = 名字;
    }
}

人 甲 = 空;
人 乙 = 新 人("小红");
打印((甲 ?? 乙).名字);  // 小红
```
