# 正则表达式

Csay 自带一个轻量正则引擎，支持常见的前缀、后缀、重复字符、字符类、分组、分支和数量词范围，但不是完整 PCRE。分组只用于组合，没有捕获组和反向引用。

## 三个函数

```csay 正则示例
打印(正则匹配("abc123", "^abc.*$"));           // 真
打印(正则匹配("ac", "ab*c"));                    // 真
打印(正则匹配("ac", "ab+c"));                    // 假
打印(正则匹配("ababab", "^(ab)\{3\}$"));          // 真
打印(正则匹配("颜色:红", "颜色:(红|蓝|绿)"));      // 真
打印(正则查找("你好abc", "abc"));               // 2
打印(正则替换("a1b22", "(\\d+)", "X"));         // aXb22
```

- `正则匹配(文本, 模式)`：文本中是否有匹配，返回真假；
- `正则查找(文本, 模式)`：返回第一个匹配的起始码点下标，找不到返回 `-1`；
- `正则替换(文本, 模式, 新文本)`：把第一个匹配替换成新文本，返回新文本。

`正则替换` 只替换第一个匹配，替换文本按字面量处理，不解析 `$1` 这样的分组引用。

## 支持的语法

| 写法 | 含义 |
|---|---|
| `a` | 字面量字符 |
| `.` | 任意一个字符 |
| `*` | 前一个元素重复 0 次或多次 |
| `+` | 前一个元素重复 1 次或多次 |
| `?` | 前一个元素重复 0 次或 1 次 |
| `{n}` `{n,}` `{n,m}` | 前一个元素精确重复 n 次、至少 n 次、n 到 m 次 |
| `^` | 匹配文本开头 |
| `$` | 匹配文本结尾 |
| `(...)` | 分组，只改变结合范围，不保存捕获结果 |
| `a` 或 `b` | 分支，匹配 a 或 b |
| `\.` `\*` `\\` | 反斜杠转义，匹配字面量 |
| `[abc]` `[a-z]` `[^0-9]` | 字符类、ASCII 范围和取反 |
| `\d` `\w` `\s` | 数字、单词字符、空白；也可写进字符类 |

例如正则模式 `a\.c` 匹配字面量 `a.c`，不匹配 `abc`；在 Csay 源码里写成 `"a\\.c"`。

## 限制

- 分组只用于组合，没有捕获组和 `$1` 反向引用；
- `*`、`+`、`?`、`{n,m}` 是贪婪匹配，没有非贪婪量词和回溯控制选项；
- `^`、`$` 只匹配整个文本的开头和结尾，不匹配每一行的开头和结尾；
- 命名分组、前后查找和 Unicode 属性类见[未来计划](../未来计划.md)。

Csay 文本里的 `{` 会开始插值，所以正则数量词要写成 `\{3\}`。例如匹配三位数字：

```csay 正则数量词
文本 模式 = "^\\d\{3\}$"
打印(正则匹配("123", 模式))
```

模式字符串里的 `\\d` 经过 Csay 字符串转义后是正则的 `\d`。

字符类只对 ASCII 范围做区间判断；中文等非 ASCII 字符按完整 UTF-8 字符逐个比较，不能写 `[一-龥]` 这种跨码点范围。

这些限制是为了保持运行时小、可自举。复杂模式可以在 Csay 里写扫描函数。

## 常见用法

日期这种“固定形状”的文本可以直接用字符类描述：

```csay 正则形状
文本 输入 = "2026-11-25"
若 (正则匹配(输入, "^\\d\\d\\d\\d-\\d\\d-\\d\\d$")) {
    打印("形状像日期")
}
```

这仍然只检查“数字、横线、数字”的形状，不校验月份和日期范围。
