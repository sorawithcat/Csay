# 异常捕获

```csay 试捕获最终
试 {
    抛出 "演示错误"          // 模拟一段可能失败的代码
} 捕获 (异常 错) {
    打印($"捕获到：{错.信息}") // 捕获到：演示错误
} 最终 {
    打印("无论如何都会执行")   // 一定会执行
}
```

三个部分的含义：

- `试 { }`：放可能出错的代码；
- `捕获 (异常 错) { }`：出错时执行，`错` 是异常对象；
- `最终 { }`：不管有没有出错都执行，适合清理资源。

`错.信息` 是错误说明文本。
