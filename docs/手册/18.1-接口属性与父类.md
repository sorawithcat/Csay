# 接口属性与父类

## 接口属性

接口可以要求属性，实现方提供 `取`、`写` 或两者：

```csay 接口属性
矩形 甲 = 新 矩形(3, 4)
形状 形 = 甲
打印(形.名字)  // 矩形
打印(形.面积()) // 12

公开 接口 形状 {
    文本 名字 { 取; }
    长小数 面积();
}

公开 类 矩形 : 形状 {
    私有 整数 _宽;
    私有 整数 _高;

    公开 矩形(整数 宽, 整数 高) {
        _宽 = 宽;
        _高 = 高;
    }

    公开 文本 名字 {
        取 { 返回 "矩形"; }
    }

    公开 虚拟 长小数 面积() {
        返回 (_宽 * _高) + 0.0;
    }
}
```

`形状 形 = 甲;` 把一个具体类的对象赋给接口变量是允许的，因为 `矩形` 实现了 `形状`。

## 接口与父类的区别

| | 父类 | 接口 |
|---|---|---|
| 能否有实现 | 可以 | 只能有签名 |
| 表达关系 | 是一种（猫是动物） | 具备某种能力（形状能算面积） |
| 数量 | 单继承 | 一个类可以实现多个接口 |
| 字段 | 可以继承 | 不包含字段 |

实际设计时，共用实现放父类，跨类型的能力放接口。比如“可保存”“可比较”“可打印”这类能力，适合用接口表达。

接口引用可以使用 `?.`；接口为空时属性/方法返回空值，文本返回空字符串。
