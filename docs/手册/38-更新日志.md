# 更新日志

## 0.2.0

### 语言

- 新增 `字节`、`有符号字节`、`短整数`、`无符号短整数`、`无符号整数`、`长整数`、`无符号长整数` 和 `字符` 类型；`整数` 对应 C# `int`，`长整数` 对应 `long`。
- 顶层语句、函数和类型声明可以按任意顺序书写。
- 函数、方法和构造器支持默认参数和命名参数；`引用`/`输出` 参数覆盖普通方法、构造器、虚拟/覆盖/抽象方法和接口方法。
- 方法和构造器支持 `=>` 表达式体；顶层函数和普通/静态方法支持重载，重载可用默认参数和命名参数。
- 支持显式类型转换，数字、真假、枚举和文本之间可以按规则转换。
- 泛型类可以从 `新` 和构造器实参推断类型参数，支持嵌套类型和多个名义约束。
- 新增 `??` 空合并和 `?.` 空安全访问；`?.` 的方法结果可以是委托或异常。
- 空值检查覆盖局部变量、对象字段、返回值、调用实参和默认空参数，并支持条件分支细化。
- 区域对象逃逸时给出提示，覆盖变量、字段、容器、函数/方法/构造器调用、委托和 Lambda。
- 数组支持空值、长度、字段、字段和变量的增删插、数组套数组和表值为数组；局部数组变量可以从另一个数组表达式初始化；`JSON序列化` 支持这些结构。
- 表的键支持 `真假`。
- 新增保守垃圾回收，提供 `回收()`、`内存块数()` 和 `内存字节数()`；区域分配仍整块释放。
- 委托、接口和异常支持空值比较与 `??` 合并；签名一致的顶层函数可以直接赋给委托变量、字段或参数。
- Lambda 可以捕获数组，保存数组指针和当时的长度；块体可以用 `返回` 返回值。
- `使用` 块支持 `返回`、`跳出` 和 `跳过`，离开块前自动调用 `关闭()`。
- 静态字段支持声明处初始化；静态属性支持 `取`/`写` 访问器；成员修饰符和异常捕获条件更完整。
- `常` 字段要求声明处用编译期常量初始化，不能在构造器或方法里赋值，并可用于 `情况`。
- 命名空间支持嵌套，类型、泛型类型和枚举项可以使用 `数学.几何.点` 这样的限定路径。
- `格式化时间` 支持 UTC、固定偏移、更多常用时区和夏令时边界；新增 `本地化时间`。

### 标准库

- `打印(空)` 输出 `空`。
- 新增 `JSON取值` 和 `JSON设置`，支持按路径读写嵌套 JSON。
- 正则表达式支持字符类、范围、取反字符类、分组、分支、数量词和常用简写。
- `JSON序列化` 支持列表、表和数组互相嵌套。

### 编辑器

- 新增设置界面，可配置自动排版、自动补全、悬浮提示、字号和缩进。
- 保存时默认自动排版；侧栏和底部面板可调整大小，标签页可拖出为浮动面板。
- 注释、括号和引号自动补全，`///` 生成文档注释模板，中文输入法输入的全角括号自动转换。
- 补全支持 `Tab` 接受第一项，方向键切换后用 `Tab` 或回车接受；未切换时回车只换行，标点不再触发补全。
- 补全按上下文过滤类型、实例成员、静态成员、枚举、参数和跨文件符号。
- 函数签名、参数和调用实参支持悬浮提示；`F12` 查看内建说明，`F2` 重命名符号。
- 顶栏新增“打开”，可打开文件或项目文件夹，并恢复上次工作区、标签页和光标位置。
- `Shift+Alt+F` 格式化整个文件，`Ctrl+Alt+F` 格式化选中行。

### 项目与工具

- 命令行新增 `--version`；编译前检查源文件和依赖，没有变化时复用已有可执行文件，`--rebuild` 强制重新编译。
- 新增 `node tools/发布校验.mjs`，检查版本、更新日志、运行时头文件和两次生成的 C 代码。
- 新增 `npm run release`，自动执行发布校验和全量语言测试。
- 垃圾回收的堆块查找改为按地址索引，大程序反复回收时不再做平方级扫描；自举 stage1 从数十分钟降到秒级。
- 项目支持多目标、资源文件、依赖项目、构建前后命令和 `exclude` 排除规则；多目标也可使用 `--format`、`--print`、`--tokens`。
- 打包时复制资源，多目标分别生成目录，并在压缩后校验包内文件。
- 编辑器运行交互程序时优先使用 Windows Terminal，未安装时回退到系统控制台。

### 文档

- 手册按主题拆分为 59 章，侧栏搜索支持正文内容。
- 手册章节按目录顺序连续编号，参考文档不参与教程编号。

## 0.1.0

2026-11-25

### 语言

- 中文关键字、可选分号和全角标点。
- 类、属性、单继承、虚方法与覆盖、接口和运行时分派。
- 枚举、数组、`列表<T>`、`表<K,V>`，以及 `集合<T>`、`队列<T>`、`栈<T>` 列表别名。
- 异常类型与多捕获、`使用` 自动关闭、区域内存分配。
- 泛型类/结构/接口、静态成员、结构体、访问控制、`密封`、抽象类和只读成员。
- 委托类型与 Lambda，按值捕获局部变量；委托调用带空检查。
- `引` 多文件加载，`断言` 与 `csay --test` 测试运行器。

### 标准库

- 时间、路径、目录、环境变量、系统命令与输出捕获。
- 文件读写和流式文件操作。
- 文本格式化、大小写转换、去空白，轻量正则表达式。
- JSON 序列化与解析。
- 常用数学和随机函数。

### 编译与工具

- 编译器把 Csay 源码生成 C，再生成独立 Windows 可执行文件。
- 自带 TCC，支持 `--check`、`--build`、`--fast`、`--rebuild`、`--debug`、`--format`、`--project` 和 `--test`。
- 自举编译器可编译自身，C 输出达到固定点。
- 编辑器提供文件树、多标签、实时语法检查、跳转定义、查找引用、补全、项目设置和一键打包。
- 提供安装与卸载脚本、VS Code 语法高亮、示例和 30 章教程。
