# 函数

函数把一段可复用的逻辑包起来，起个名字，需要时调用。Csay 的函数写在顶层，和类型声明、顶层语句可以按任意顺序书写。

## 定义与调用

```csay 定义函数
整数 平方(整数 甲) {
    返回 甲 * 甲        // 把结果交回调用处
}

打印(平方(5))          // 25
打印(平方(12))         // 144
```

格式是：

```
返回类型 函数名(参数类型 参数名, ...) {
    函数体
}
```

- 返回类型写在最前面；不需要返回值时写 `无`；
- 参数要写类型和名字，多个参数用逗号分隔；
- 用 `返回 值;` 把结果交回去；
- `无` 函数可以只写 `返回;`，或者不写返回。

## 无返回值的函数

```csay 无返回值
无 分隔线() {
    打印("----------");
}

无 问候(文本 名字) {
    打印($"你好，{名字}！");
}

分隔线();
问候("小明");
分隔线();
```

## 调用可以先于定义

顶层函数可以在定义之前调用。编译器会先生成函数声明，再生成调用：

```csay 先调用后定义
打印(加法(3, 4));

整数 加法(整数 甲, 整数 乙) {
    返回 甲 + 乙;
}
```

虽然语法允许，实际代码里还是建议先定义、后使用，阅读时更顺。


## 文档注释

函数或方法声明前连续写 `///`，编辑器悬浮时会显示这些文字：

```csay 文档注释
/// 返回两个数的和
/// <param name="x">左操作数</param>
/// <param name="y">右操作数</param>
/// <returns>相加结果</returns>
长小数 相加(长小数 x, 长小数 y) {
    返回 x + y;
}
```

`///` 只是给编辑器读的，编译器把它当普通注释，不影响生成的程序。注释必须紧贴声明，中间隔空行就不会显示；`<summary>`、`<param>`、`<returns>` 这些标签会被去掉，只留文字。

## 递归

函数可以调用自己。递归要有终止条件，否则会无限调用直到栈溢出：

```csay 递归
整数 阶乘(整数 甲) {
    若 (甲 <= 1) {
        返回 1                 // 终止条件
    }
    返回 甲 * 阶乘(甲 - 1)     // 例如 5! = 5 * 4!
}

整数 斐波那契(整数 甲) {
    若 (甲 <= 1) {
        返回 甲
    }
    返回 斐波那契(甲 - 1) + 斐波那契(甲 - 2)
}

循环 (整数 i = 1; i <= 6; i++) {
    打印($"{i}! = {阶乘(i)}")   // 1! 到 6!
}

打印($"fib(10) = {斐波那契(10)}") // 55
```

斐波那契的递归写法重复计算很多次，`fib(30)` 就会明显变慢。练习递归可以，真实程序里可以改成循环或缓存结果。

## 参数是按值传递的

基本类型的参数是复制一份传进函数。函数里改参数，不影响外面的变量：

```csay 按值传递
无 尝试修改(整数 甲) {
    甲 = 999             // 只改函数里的副本
    打印($"函数内：{甲}") // 999
}

整数 甲 = 1
尝试修改(甲)
打印($"函数外：{甲}")   // 仍然是 1
```

数组参数会把数组本身传进去，函数里修改元素会影响调用方。这是数组和基本类型的区别。

```csay 数组参数
整数 求和(整数[] 数) {
    整数 合计 = 0
    遍历 (整数 x 在 数) {
        合计 += x
    }
    返回 合计
}

整数[] 分数 = [88, 92, 76, 95]
打印(求和(分数))  // 351
```

## 顶层变量是全局的

写在函数外面的变量会被提升成全局变量，函数里可以直接读写：

```csay 全局变量
整数 计数 = 0

无 加一() {
    计数 = 计数 + 1
}

加一()              // 计数 = 1
加一()              // 计数 = 2
加一()              // 计数 = 3
打印(计数)          // 3
```

如果函数里声明了同名局部变量，局部变量会遮住全局变量；这种写法容易混淆，建议避免。顶层数组目前仍只在入口代码里可见，跨函数共享数据请使用容器类型。

## 函数值

函数除了直接调用，还可以存进“委托”变量，作为参数传递或从函数返回。Lambda 用来就地创建这种函数值；需要捕获外层变量时，它会形成闭包。这些内容单独放在[委托与闭包](20-委托与闭包.md)页。

## 和 C# 的差异

Csay 支持默认参数、命名参数、引用/输出参数和按参数个数/类型区分的顶层函数、普通方法与静态方法重载，但默认值必须是常量表达式；重载可以使用默认参数和命名参数。虚拟/覆盖/抽象方法和接口方法的重载见[未来计划](../未来计划.md)。
