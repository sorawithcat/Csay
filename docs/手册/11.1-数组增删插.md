# 数组增删插

数组变量和类/结构字段支持三个方法：

```csay 数组增删
整数[] 数 = [1, 2, 3]
数.添加(4)          // [1, 2, 3, 4]
数.插入(1, 9)       // [1, 9, 2, 3, 4]
数.删除(0)          // [9, 2, 3, 4]

文本[] 名 = ["甲"]
名.添加("乙")
名.插入(0, "丙")
名.删除(2)
打印(名[0]);        // 丙
```

- `.添加(值)` 把值放到末尾。
- `.插入(下标, 值)` 在下标处插入；下标小于 0 按 0 处理，大于长度按末尾处理。
- `.删除(下标)` 删除该位置；下标越界时什么也不做。
- 字段也可以直接调用，例如 `对象.数.添加(x)`；在方法里可以写 `数.添加(x)`。
- 每次操作都会分配一个新数组并复制元素，旧数组不会自动释放。在区域内执行时，新数组分配在区域内。
- 数组作为函数参数传入时，参数是数组指针和长度的副本；在函数里调用 `.添加` 只改变函数内的局部数组变量，不会改变调用者的数组变量。元素本身仍然是共享的。
- 类/结构的字段可以保存数组，例如 `公开 整数[] 数;`；构造器或字段赋值写成 `数 = 参数`，字段的 `.长度`、下标、传参、遍历和 `JSON序列化` 都会使用数组头里的长度。
