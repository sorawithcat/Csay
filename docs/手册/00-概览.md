# 概览

Csay 是一门使用中文关键字、语法接近 C# 的编程语言。源码编译成原生 exe，不依赖 .NET、Java 或 Python 运行时。

最小程序：

```csay 第一个程序
// 打印是内建函数，把文本输出到控制台
打印("你好，Csay！")
```

语句结尾的分号可以省略，上面没有写分号。

## Csay 是什么

Csay 把 C# 的关键字换成中文，保留 C# 的语法结构：

| Csay | C# | 说明 |
|---|---|---|
| `类` / `接口` / `枚举` | `class` / `interface` / `enum` | 类型声明 |
| `公开` / `私有` | `public` / `private` | 访问修饰符 |
| `若` / `否则` | `if` / `else` | 条件 |
| `只要` / `遍历` | `while` / `foreach` | 循环 |
| `新` / `空` / `自` / `基` | `new` / `null` / `this` / `base` | 对象相关 |
| `试` / `捕获` / `抛出` | `try` / `catch` / `throw` | 异常 |

> Csay 学的是 C# 的语法和面向对象模型，不是 .NET 生态。它没有 NuGet、LINQ、WPF，也没有完整的 .NET 运行时。

## 为什么用中文关键字

英文关键字本身不难，难的是初学时同时记语法、记单词、记报错。Csay 把这一层换成中文：

- 关键字是中文，变量名、函数名也可以用中文，命名不需要在两种输入法之间切换。
- 编译器报错是中文，带行号、列号和修改建议。
- 标准库很小，常用的只有打印、输入、文本、列表、表、文件、数学几类。

## 程序是怎么跑起来的

Csay 不是解释器。一次运行要经过三步：

1. 词法分析和语法分析，把 `.csay` 源码变成语法树；
2. 代码生成，把语法树翻译成 C 代码；
3. 调用 C 编译器（自带的 TCC，或系统的 clang/gcc）生成 exe，再运行。

因此程序启动就是原生程序的启动速度，没有虚拟机预热。编译产物放在仓库的 `build/` 目录里。

## 适用范围

Csay 面向命令行程序、脚本自动化、小工具和嵌入式场景。它没有图形界面库和第三方 SDK 生态，不适合桌面 GUI、大型服务端或依赖 .NET 生态的项目。
