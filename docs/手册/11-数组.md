# 数组

数组是一组**类型相同、长度固定**的值。适合存放数量已知、按位置访问的数据。数组变量可以用 `.添加`、`.插入`、`.删除` 换成一个新的数组。

## 声明与初始化

数组的类型写成 `元素类型[]`，初始化用方括号：

```csay 数组
整数[] 数列 = [3, 1, 4, 1, 5]
文本[] 名单 = ["张三", "李四", "王五"]

打印(数列.长度)  // 5
打印(名单.长度)  // 3
```

数组的长度在创建时确定；数组变量可以通过下面的方法换成新数组。需要频繁增删时，仍建议用上一章的《列表》。

数组的元素也可以是数组，例如 `整数[][] 矩阵 = [[1, 2], [3]]`；每一层数组都有自己的长度。

数组也可以赋 `空`，表示当前没有数据；此时 `.长度` 是 0：

```csay 空数组
整数[] 数据 = 空;
打印(数据.长度);                  // 0
打印(数据 == 空);                 // 真

数据 = [1, 2, 3];
打印(数据.长度);                  // 3
数据 = 空;
打印(数据 == 空);                 // 真
```

数组变量也可以从另一个数组表达式初始化，例如字段、函数返回值或另一个数组变量：

```csay 数组别名
整数[] 数据 = [1, 2, 3]
整数[] 副本 = 数据

副本[0] = 9
打印(数据[0])                     // 9
```

这种初始化只复制数组指针，两个变量指向同一份元素；修改元素会互相影响。对其中一个变量调用 `.添加`、`.插入` 或 `.删除` 时，只有该变量换成新数组，另一个变量仍指向原来的数组。


## 下标

下标从 `0` 开始。`数列[0]` 是第一个元素，最后一个元素的下标是 `长度 - 1`：

```csay 下标读写
整数[] 数列 = [10, 20, 30]

打印(数列[0])  // 10
打印(数列[2])  // 30

数列[1] = 99
打印(数列[1])  // 99
```

下标必须是整数，并且要在 `0` 到 `长度 - 1` 之间。Csay 不做运行时越界检查，写错下标可能读到垃圾值或让程序崩溃。

## 遍历数组

`遍历` 会按顺序取出每个元素：

```csay 遍历数组
整数[] 数列 = [3, 1, 4, 1, 5]
整数 合计 = 0

遍历 (整数 x 在 数列) {
    合计 += x                 // 每轮把 x 加到合计
    打印($"当前 {x}，累计 {合计}")
}
```

数组也可以直接在 `遍历` 里用字面量：

```csay 直接遍历字面量
遍历 (整数 x 在 [2, 4, 6]) {
    打印(x * x);
}
```

数组字面量也可以直接取下标：

```csay 直接取字面量下标
打印([1, 2, 3][0])  // 1
打印([7, 8, 9][2])  // 9
```
