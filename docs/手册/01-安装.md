# 安装

## 环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 |
| Node.js | 22 或更高；安装脚本会检测，缺少时下载便携版 |
| C 编译器 | 不需要单独安装，发布包自带 TCC |
| 磁盘 | 约 10 MB，不含可选的 Node 便携版 |

源码文件使用 UTF-8；可带 BOM，编译器会忽略开头的 BOM，编辑器保存无 BOM。

## 安装

双击发布包里的 `安装Csay.bat`，按提示完成安装。脚本会：

- 复制编译器、编辑器、TCC、文档和示例；
- 把 `csay` 和 `csay-editor` 加入用户 PATH；
- 关联 `.csay` 文件。

安装后打开新的命令行窗口，运行：

```bash
csay 你好.csay
```

不想使用命令行时，运行 `csay-editor` 或开始菜单里的「Csay 编辑器」。

## 第一个程序

新建 `你好.csay`：

```csay 第一个程序
打印("你好，世界！");
```

运行：

```bash
csay 你好.csay
```

编译器依次完成检查、生成 C、调用 C 编译器、运行。第一次会生成 `build/你好.c` 和 `build/你好.exe`；源文件未修改时复用已有 exe。

直接双击 exe 时，程序结束会停住并提示按回车，避免窗口立即关闭；从命令行启动时不会停。

卸载运行 `卸载Csay.bat`，会移除 PATH、文件关联和安装目录。
