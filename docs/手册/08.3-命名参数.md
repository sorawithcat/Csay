# 命名参数

调用函数、方法或构造器时，可以用 `参数名: 值` 指定实参，顺序不必和声明一致：

```csay 命名参数
整数 加(整数 甲, 整数 乙 = 10) {
    返回 甲 + 乙
}

打印(加(乙: 2, 甲: 1))  // 3
打印(加(1))              // 11
```

位置参数要写在命名参数前面，例如 `加(1, 乙: 2)`。命名参数可以跳过带默认值的参数，省略的默认值由声明补齐。内建函数使用位置参数；委托参数也没有公开的参数名。

重载函数和普通方法支持命名参数：编译器先按候选的参数名重排，再按类型选择重载。虚拟、覆盖、抽象方法和接口方法的重载仍见[未来计划](../未来计划.md)。
