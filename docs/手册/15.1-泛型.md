# 泛型

## 泛型

同一个类如果只是字段类型不同，可以把它写成泛型类。类型参数写在类名后面的尖括号里：

```csay 泛型类
盒子<整数> 整数盒 = 新 盒子<整数>(3)
盒子<文本> 文本框 = 新 盒子<文本>("你好")
打印(整数盒.内容)      // 3
打印(文本框.内容)      // 你好

公开 类 盒子<T> {
    公开 T 内容;

    公开 盒子(T v) {
        内容 = v
    }
}
```

`T` 是类型参数，`盒子<整数>` 和 `盒子<文本>` 会生成两个独立的类型，字段 `内容` 分别是整数和文本。构造器参数直接写成 `T` 时，`新 盒子(3)` 会从实参推断成 `盒子<整数>`；类型参数嵌在 `盒子<T>`、`列表<T>` 或数组 `T[]` 里时也会逐层推断。构造器和普通方法内都可以用 `自.字段` 访问泛型字段。方法级类型参数仍需显式写出。

类型参数可以带约束，例如 `类 盒子<T: 有名字>`；多个约束用 `&` 连接，例如 `类 盒子<T: 有名字 & 可打印>`。类型实参必须同时满足所有约束，每个约束目前都是名义类型；约束本身是泛型类型的情况见[未来计划](../未来计划.md)。
