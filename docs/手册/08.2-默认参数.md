# 默认参数

参数可以在声明时给默认值，调用时省略。带默认值的参数必须放在参数表末尾：

```csay 默认参数
整数 加(整数 甲, 整数 乙 = 10) {
    返回 甲 + 乙
}

打印(加(1))     // 11
打印(加(1, 2))  // 3
```

默认值必须是不依赖参数和局部变量的常量表达式，例如数字、文本、`真`/`假`、`空`、枚举成员或它们的简单运算。默认值在调用处求值；调用时传了实参就用实参。

重载函数和普通方法也可以使用默认参数。多个重载都能接受实参时，优先选择不需要补默认值的版本；显式传入的参数仍然按类型精确匹配。
