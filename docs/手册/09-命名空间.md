# 命名空间

`命名空间` 是**声明分组**，用来把相关的类型声明放在一个具名块里。它不生成运行时对象，也不做名字隔离；编译器会把块里的类型声明展开到当前文件。

## 语法

命名空间可以嵌套，名字也可以直接带点：

```csay 命名空间
命名空间 数学 {
    公开 命名空间 几何 {
        公开 结构 点 {
            公开 整数 横 = 0;
            公开 整数 纵 = 0;
        }
    }
}
```

命名空间体里只能放类型声明：类、结构、接口、枚举和委托。函数和顶层语句不能写进命名空间。

## 使用类型

声明之后可以直接写类型名，也可以用命名空间路径限定：

```csay 使用命名空间里的类型
命名空间 数学 {
    公开 命名空间 几何 {
        公开 结构 点 {
            公开 整数 横 = 0;
            公开 整数 纵 = 0;
        }
    }
}

数学.几何.点 甲 = 新 数学.几何.点();
甲.横 = 3;
甲.纵 = 4;
打印(甲.横 + 甲.纵); // 7
```

限定名只改变类型的书写位置，不改变实际类型；`数学.几何.点` 和 `点` 指向同一个结构。

命名空间里的枚举项也可以用限定路径访问：

```csay 枚举项
命名空间 数学 {
    公开 命名空间 几何 {
        公开 枚举 方向 {
            水平,
            垂直,
        }
    }
}

数学.几何.方向 向 = 数学.几何.方向.水平;
打印(向 == 数学.几何.方向.水平); // 真
```

## 多个命名空间

同一个文件可以写多个命名空间：

```csay 多个命名空间
点 p = 新 点();
p.横 = 1;
尺寸 s = 新 尺寸();
s.宽 = 2;
打印(p.横 + s.宽); // 3

命名空间 图形 {
    公开 结构 点 {
        公开 整数 横 = 0;
    }
}

命名空间 布局 {
    公开 结构 尺寸 {
        公开 整数 宽 = 0;
    }
}
```

所有声明最终仍在同一个文件作用域里，所以两个命名空间不能声明同名类型。

## 限定委托和类

限定类型名同样适用于委托和类：

```csay 限定委托和类
命名空间 工具 {
    公开 委托 变换(整数): 整数;
    公开 类 盒子 {
        公开 整数 值 = 0;
    }
}

工具.变换 加倍 = (整数 甲) => 甲 * 2;
打印(加倍(3)); // 6

工具.盒子 盒 = 新 工具.盒子();
盒.值 = 5;
打印(盒.值); // 5

命名空间 容器 {
    公开 类 盒子<T> {
        公开 T 值;
        公开 盒子(T 初值) => 自.值 = 初值;
    }
}

容器.盒子<整数> 泛盒 = 新 容器.盒子<整数>(8);
打印(泛盒.值); // 8
```

带类型实参的限定泛型名也可以这样写；生成代码时仍按实际泛型单态化。

## 跨文件使用

被 `引` 的文件里可以写命名空间；加载后类型名同样直接可见：

```text
// 图形.csay
命名空间 图形 {
    公开 结构 点 {
        公开 整数 横 = 0;
    }
}
```

```text
// 主.csay
引 "图形.csay"
点 p = 新 点();
p.横 = 5;
打印(p.横);
```

被引文件只能包含类型和函数声明，不能有顶层语句。

## 和 C# 的差异

| C# | Csay |
| --- | --- |
| `namespace A.B { }` 形成嵌套命名空间 | 命名空间名可以带点，也可以直接嵌套 |
| 用 `A.B.C` 限定类型 | 类型位置支持 `A.B.C` 限定名 |
| 命名空间可以包含类、方法、嵌套命名空间 | 可以包含类型声明和嵌套命名空间，不能包含函数或顶层语句 |
| 不同命名空间可以放同名类型 | 所有声明展开到同一作用域，同名会冲突 |
