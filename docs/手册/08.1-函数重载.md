# 函数重载

## 函数和方法重载

顶层函数和普通方法可以同名，只要参数个数或参数类型不同：

```csay 函数重载
整数 倍数(整数 a) {
    返回 a * 2
}

整数 倍数(整数 a, 整数 b) {
    返回 a * b
}

文本 描述(整数 x) { 返回 "整数" }
文本 描述(文本 x) { 返回 "文本" }

打印(倍数(3))     // 6
打印(倍数(3, 4))  // 12
打印(描述(1))     // 整数
打印(描述("甲"))  // 文本
```

按实参个数和类型选择重载；数值类型会优先选择精确匹配，再考虑可转换的类型。类、结构体的普通方法和静态方法也支持重载，类内裸方法调用和 `?.` 调用同样按实参选择。

重载可以带默认参数，也可以用命名参数调用。编译器先用命名参数把实参重排到候选函数的参数表，再按类型选择；多个候选都能匹配时，优先选择不需要补默认参数的那个。

虚拟、覆盖、抽象方法和接口方法的重载见[未来计划](../未来计划.md)。
