## 语句

| 写法 | 用途 |
|---|---|
| `整数 年龄 = 18;` | 声明并初始化局部变量 |
| `返回 值;` / `返回;` | 从函数或 Lambda 返回 |
| `若 (条件) { ... } 否则若 (条件) { ... } 否则 { ... }` | 条件分支 |
| `选择 (值) { 情况 1: ... 默认: ... }` | 多分支匹配 |
| `循环 (整数 i = 0; i < 10; i++) { ... }` | 计数循环 |
| `只要 (条件) { ... }` | 条件循环 |
| `做 { ... } 只要 (条件);` | 至少执行一次 |
| `遍历 (项 在 列表) { ... }` | 遍历列表、数组或表的条目 |
| `跳出;` / `跳过;` | 跳出当前循环 / 进入下一轮 |
| `试 { ... } 捕获 (异常 错) { ... } 最终 { ... }` | 异常处理 |
| `抛出 "出错了";` | 抛出通用异常 |
| `使用 (资源) { ... }` | 离开块时自动调用无参 `关闭()` |
| `圆 甲 = 空;` | 引用类型的空值；支持类、接口、列表、表、数组、委托和异常 |
| `区域 名字 { ... }` | 区域内存分配；`移出区域(文本)` 把结果移出区域 |
| `引 工具;` | 引入同目录的 `工具.csay` |
| `命名空间 数学 { ... }` | 把类型声明分组，名字仍然直接可见 |

`使用` 块内可以写 `返回`、`跳出`、`跳过`；离开块前会先调用 `关闭()`，返回表达式的值会先求值。

语言不保留旧关键字；`循环`、`选择`、`情况` 是唯一写法。
