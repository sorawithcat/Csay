# 时间

## 当前时间

```csay 时间
打印(当前时间());                  // 年-月-日 时:分:秒
打印(当前日期());                  // 年-月-日
打印(时间戳());                    // Unix 秒数
```

- `当前时间()` 返回本地时间文本；
- `当前日期()` 只返回日期；
- `时间戳()` 返回从 1970-01-01 UTC 起的秒数，类型是整数。

## 解析与格式化

```csay 时间转换
打印(解析时间("1970-01-01 00:00:00")); // 0（UTC）
打印(格式化时间(0, "%Y-%m-%d"));       // 1970-01-01（本地时区）
```

`解析时间(文本)` 支持：

- `YYYY-MM-DD`
- `YYYY-MM-DD HH:MM:SS`
- 用 `T` 分隔日期和时间
- 结尾的 `Z`，表示 UTC
- 结尾的 `+08:00` / `-05:30` / `+0800` 时区偏移

它按文本里的时区换算成 UTC，返回 Unix 秒；不带时区时按 UTC 处理。格式错误抛 `格式异常`。需要本地时间时，用 `格式化时间` 转换。

```csay 时区
打印(解析时间("2024-01-01T00:00:00+08:00")); // 1704038400
打印(解析时间("2023-12-31T16:00:00Z"));       // 1704038400
```

`格式化时间(秒, 格式)` 按 C 的 `strftime` 输出。常用占位符：

| 占位符 | 含义 |
|---|---|
| `%Y` | 年 |
| `%m` | 月 |
| `%d` | 日 |
| `%H` | 时 |
| `%M` | 分 |
| `%S` | 秒 |

少数扩展占位符在 Windows 和 Linux 上可能不同。

第三个参数可以指定时区：

- `"UTC"` 或 `"Z"`：UTC；
- `"+08:00"`、`"-05:30"`、`"+0800"`：固定偏移；
- `"Asia/Shanghai"`、`"Asia/Tokyo"`、`"Asia/Kolkata"`、`"Asia/Karachi"`、`"Asia/Dhaka"`、`"Asia/Yangon"`、`"Asia/Manila"`、`"Asia/Kuala_Lumpur"`、`"Asia/Taipei"`、`"Asia/Dubai"`、`"Europe/London"`、`"Europe/Lisbon"`、`"Europe/Paris"`、`"Europe/Zurich"`、`"Europe/Athens"`、`"Europe/Helsinki"`、`"Europe/Kyiv"`、`"Europe/Bucharest"`、`"Europe/Sofia"`、`"Europe/Moscow"`、`"America/New_York"`、`"America/Detroit"`、`"America/Chicago"`、`"America/Winnipeg"`、`"America/Denver"`、`"America/Edmonton"`、`"America/Los_Angeles"`、`"America/Anchorage"`、`"America/Halifax"`、`"America/Havana"`、`"America/Bogota"`、`"Africa/Johannesburg"`、`"Australia/Sydney"`、`"Pacific/Auckland"` 等常用时区名称：美国、加拿大、欧洲、悉尼和奥克兰按当地夏令时规则换算，其余名称使用标准偏移；
- `"本地"` 或省略：本地时区。

```csay 时区格式化
打印(格式化时间(0, "%Y-%m-%d %H:%M", "UTC"));           // 1970-01-01 00:00
打印(格式化时间(0, "%Y-%m-%d %H:%M", "+08:00"));        // 1970-01-01 08:00
打印(格式化时间(0, "%Y-%m-%d %H:%M", "Asia/Shanghai")); // 1970-01-01 08:00
```

时区格式错误会抛 `格式异常`。

## 本地化格式

`本地化时间(秒, 风格)` 按本地时区输出中文或英文习惯的日期文本，不需要自己拼 `strftime` 格式：

| 风格 | 输出示例 |
|---|---|
| `"长"` | `2024年03月05日 星期二 20:34:56` |
| `"短"` | `2024/03/05` |
| `"时间"` | `20:34:56` |
| `"星期"` | `星期二` |
| `"英文"` | `Tuesday, March 05, 2024 20:34:56` |

```csay 本地化时间
整数 时刻 = 解析时间("2024-03-05T12:34:56Z");
打印(本地化时间(时刻, "长"));
打印(本地化时间(时刻, "英文"));
```

未知风格按 `"长"` 处理。输出使用本地时区。

时区名称覆盖常用城市和地区；未列出的名称仍可使用固定偏移或 `本地时区`。
