# 系统

## 路径与环境

```csay 路径与环境
打印(当前目录());
打印(路径合并("build", "文档"));   // build\文档（Windows）
打印(路径存在("."));               // 真
打印(系统平台());                  // Windows 或 Linux
打印(读环境变量("PATH"));          // 不存在时返回空文本
```

- `当前目录()` 返回进程的工作目录；
- `路径合并(目录, 名字)` 用当前平台的路径分隔符拼接；
- `路径存在(路径)` 对文件和目录都返回 `真`；
- `读环境变量(名字)` 不存在时返回空文本；
- `系统平台()` 返回 `Windows` 或 `Linux`。

目录列表、创建目录、删除和文件大小见[文件与目录](24-文件与目录.md)。

## 运行命令

`运行命令(命令)` 调用系统命令并返回退出码；`运行命令输出(命令)` 返回标准输出：

```csay 运行命令
打印(运行命令("echo Csay"));          // 输出 Csay 后返回 0
文本 输出 = 运行命令输出("echo Csay");
打印(输出);                            // Csay\n
```

命令和参数作为一整段文本交给系统命令解释器。`运行命令输出` 只捕获标准输出，不包含标准错误；退出码用 `运行命令` 获取。

> 不要把未经检查的用户输入直接拼进命令。这等同于把输入交给 shell，可能执行任意命令。
