# 词法

本页说明语句分隔、代码块、标识符、字面量和中文符号的规则。

## 语句与分号

一条语句是程序执行的最小单位。Csay 的语句结尾分号是**可选的**：

```csay 分号可省略
整数 甲 = 10;  // 甲 = 10
整数 乙 = 20;  // 乙 = 20

打印(甲 + 乙)  // 30
打印(甲 * 乙)  // 200
```

两种例外必须写分号：

- 同一行写多条语句时，用 `;` 分隔；
- 后面循环语句的 `循环 (...; ...; ...)` 头部，两个分号是语法结构的一部分。

```csay 同一行多条语句
整数 甲 = 1; 整数 乙 = 2; 打印(甲 + 乙);
```

## 代码块

花括号 `{ }` 表示一个代码块。`若`、`只要`、`循环`、函数、类都用它包住主体：

```csay 代码块
若 (真) {
    打印("在块里面");
    打印("还在块里面");
}
打印("块结束了");
```

缩进只是给人看的，不参与语法判断。但建议统一用 4 个空格，方便阅读。

## 标识符

变量名、函数名、类名统称标识符。规则是：

- 可以用汉字、英文字母、数字、下划线；
- 不能以数字开头；
- 不能用保留字，比如 `整数`、`文本`、`返回`；
- 区分大小写（英文字母部分）。

```csay 合法与不合法的名字
整数 年龄 = 18;
整数 年龄2 = 19;
整数 _临时 = 20;
文本 名字 = "小明";

打印(年龄 + 年龄2 + _临时);
打印(名字);
```

一个容易踩的坑：**关键字左右不能紧贴标识符字符**。`整数年龄` 是一个完整的标识符，不是“整数”加“年龄”。所以声明变量时，类型和名字之间必须有空格：

```csay 类型和名字之间要有空格
整数 年龄 = 18;
打印(年龄);
```

## 中文标点可以直接写

在中文输入法下，写代码时很容易打出全角标点。Csay 会把下面这些全角符号自动当成对应的半角符号：

| 全角 | 半角 | 全角 | 半角 |
|---|---|---|---|
| `（` `）` | `(` `)` | `；` | `;` |
| `，` | `,` | `：` | `:` |
| `＝` | `=` | `＋` `－` `＊` `／` | `+` `-` `*` `/` |
| `＜` `＞` | `<` `>` | `！` | `!` |
| `【` `】` | `[` `]` | `｛` `｝` | `{` `}` |

所以下面两种写法完全等价：

```csay 全角符号
整数 甲 ＝ 10
整数 乙 ＝ 20

打印（甲 ＋ 乙）  // 全角加号和括号，结果是 30
```

中文引号 `“ ”` 也可以当字符串引号，并且同样支持插值：

```csay 中文引号
文本 名字 = "小明";
打印(“你好，{名字}”);
```

> 注意：全角符号的自动转换只覆盖上表这些常见符号。写代码时如果遇到“无法识别的字符”，先检查是不是用了中文句号 `。`、中文顿号 `、` 或别的全角符号。

## 关键字

保留字是语言自己用的名字，不能拿来当变量名。完整的保留字表在最后一章《关键字速查》里。现在只要记住已经用过的 `整数`、`文本`、`返回` 和 `打印` 都有固定含义。

`打印`、`输入`、`读文件` 这些看起来像关键字的名字其实是**内建函数**，不是保留字，理论上可以重新定义，但不建议这么做。
