# 询问与输入

## 控制台输入

`输入()` 读一行，不带提示；`询问(提示)` 先打印提示，再读一行：

```csay 交互输入
文本 名字 = 询问("请输入名字：");
打印($"你好，{名字}！");

整数 年龄 = 转整数(询问("年龄："));
打印($"明年你 {年龄 + 1} 岁");
```

运行交互程序时，编辑器会打开新的命令行窗口，请在新窗口输入。输入结束后窗口会停住，按回车关闭。

`输入()` 和 `询问()` 读到文件末尾或输入流关闭时返回空文本，不抛异常。判断是否读到内容：

```csay 判断输入结束
文本 行 = 输入();
若 (文本长度(行) == 0) {
    打印("没有更多输入");
}
```

编辑器运行交互程序时会优先使用 Windows Terminal，未安装时使用系统控制台。程序启动时会自动切换到 UTF-8，不需要手动修改代码页。
