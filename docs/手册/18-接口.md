# 接口

接口只规定“必须提供哪些方法/属性”，不写具体实现。类可以选择实现一个接口，从而被当作这个接口类型使用。

## 定义与实现

```csay 形状接口
形状[] 堆 = [新 圆(2.0), 新 方(3.0)]

遍历 (形状 形 在 堆) {
    打印($"{形.名字}：{形.面积()}")  // 圆、正方形各自实现
}

公开 接口 形状 {
    长小数 面积();
    文本 名字 { 取; }
}

公开 类 圆 : 形状 {
    私有 长小数 _半径;

    公开 圆(长小数 半径) {
        _半径 = 半径;
    }

    公开 虚拟 长小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }

    公开 文本 名字 {
        取 { 返回 "圆"; }
    }
}

公开 类 方 : 形状 {
    私有 长小数 _边;

    公开 方(长小数 边) {
        _边 = 边;
    }

    公开 虚拟 长小数 面积() {
        返回 _边 * _边;
    }

    公开 文本 名字 {
        取 { 返回 "正方形"; }
    }
}
```

接口里的成员只写签名，不写函数体：

```
公开 接口 形状 {
    长小数 面积();
    文本 名字 { 取; }
}
```

实现接口的类用 `:` 接在接口名后面，写法和继承父类一样。类必须实现接口里的所有成员，否则编译报错。接口方法可以声明 `引用`/`输出` 参数，实现类的同名方法必须使用相同的参数模式。

## 空接口

接口变量可以赋 `空`，表示当前没有实现对象：

```csay 空接口
形状 甲 = 空;
断言(甲 == 空, "还没有对象");

甲 = 新 圆(1.0);
断言(甲 != 空, "已经有对象");
打印(甲.面积()); // 3.14159

公开 接口 形状 {
    长小数 面积();
}

公开 类 圆 : 形状 {
    私有 长小数 _半径;
    公开 圆(长小数 半径) => _半径 = 半径;
    公开 虚拟 长小数 面积() => 3.14159 * _半径 * _半径;
}
```

访问空接口的成员会在运行期出错；需要默认对象时用 `??` 合并。

## 接口变量与多态

接口最重要的用途是**用同一种类型装不同的实现**：

```csay 接口变量
形状 甲 = 新 圆(1.0)
形状 乙 = 新 方(2.0)

打印(甲.面积())  // 3.14159
打印(乙.面积())  // 4

公开 接口 形状 {
    长小数 面积();
}

公开 类 圆 : 形状 {
    私有 长小数 _半径;

    公开 圆(长小数 半径) {
        _半径 = 半径;
    }

    公开 虚拟 长小数 面积() {
        返回 3.14159 * _半径 * _半径;
    }
}

公开 类 方 : 形状 {
    私有 长小数 _边;

    公开 方(长小数 边) {
        _边 = 边;
    }

    公开 虚拟 长小数 面积() {
        返回 _边 * _边;
    }
}
```

`甲` 和 `乙` 的声明类型都是 `形状`，但实际对象不同。调用 `.面积()` 时，运行时会找到对象真正的实现，这就是接口多态。

实现接口的方法通常写 `虚拟`，和本手册的写法保持一致。接口分派按对象的实际实现执行，即使变量声明成接口类型也一样。

## 泛型接口

接口也可以带类型参数，类和结构在实现时把具体类型填进去：

```csay 泛型接口
容器<整数> 整数盒 = 新 盒子<整数>(7);
打印(整数盒.取值());  // 7

公开 接口 容器<T> {
    T 取值();
}

公开 类 盒子<T> : 容器<T> {
    私有 T _值;

    公开 盒子(T 值) {
        _值 = 值;
    }

    公开 T 取值() {
        返回 _值;
    }
}
```

`容器<整数>` 和 `容器<文本>` 是两个不同的接口类型，类型实参必须显式写出。方法名用 `取值` 而不是 `取`，因为 `取` 是属性访问器的关键字，不能当成员名。
