# 类型系统

类型决定变量能保存什么值、能参与哪些运算，以及传给函数时如何转换。

变量声明和默认值见[变量与常量](04-变量与常量.md)。

## 基本类型

| 类型 | 含义 | 字面量例子 | 说明 |
|---|---|---|---|
| `字节` | 8 位无符号整数 | `42`、`0` | 对应 C# `byte` |
| `有符号字节` | 8 位有符号整数 | `42`、`-7` | 对应 C# `sbyte` |
| `短整数` | 16 位有符号整数 | `42`、`-7` | 对应 C# `short` |
| `无符号短整数` | 16 位无符号整数 | `42`、`0` | 对应 C# `ushort` |
| `整数` | 32 位有符号整数 | `42`、`-7`、`0` | 对应 C# `int`，日常计数、下标 |
| `无符号整数` | 32 位无符号整数 | `42`、`0` | 对应 C# `uint` |
| `长整数` | 64 位有符号整数 | `42`、`-7`、`0` | 对应 C# `long` |
| `无符号长整数` | 64 位无符号整数 | `42`、`0` | 对应 C# `ulong` |
| `浮点数` | 32 位 IEEE 754 浮点数 | `3.14`、`-0.5`、`3.0` | 约 7 位有效十进制数字，适合内存敏感的数据 |
| `长小数` | 64 位 IEEE 754 浮点数 | `3.14`、`-0.5`、`3.0` | 约 15 到 16 位有效数字，默认的浮点类型 |
| `文本` | UTF-8 字符串 | `"你好"`、`"abc"` | 支持插值、拼接、切分 |
| `字符` | 16 位 UTF-16 码元 | `'A'`、`'中'`、`'\n'` | 对应 C# `char`，打印和插值时输出字符本身 |
| `真假` | 布尔值 | `真`、`假` | 条件判断的结果 |
| `无` | 没有返回值 | — | 只用于函数返回类型 |

整数类型可以互相赋值和参与运算，赋给较窄类型时会截断到该类型的位宽；需要保留大范围时用 `长整数`。`整数` 和 `长整数` 是不同类型，整数运算结果按较宽的类型提升。`浮点数`、`长小数` 分别对应 C# 的 `float`、`double`。`字节` 现在是可用类型；`任意` 仍是保留字。

`字符` 字面量用单引号，例如 `'A'`、`'中'`，也支持 `'\n'`、`'\t'`、`'\\'`、`'\''` 和 `'\u0041'`。字符是 16 位 UTF-16 码元；参与整数运算时按整数处理，赋给其他整数类型时按位宽截断。`打印` 和文本插值会输出字符本身，而不是它的码点。

`无` 不是变量的类型。`整数`、`浮点数`、`长小数` 是三种不同的类型，`3` 是整数，`3.0` 是长小数。

## 浮点数与长小数

浮点字面量默认是 `长小数`。赋给 `浮点数` 变量时会转成 32 位，可能丢失精度：

```csay 浮点数精度
浮点数 f = 16777217;
长小数 d = 16777217;

打印(f);  // 16777216
打印(d);  // 16777217
```

`浮点数` 只有约 7 位有效数字，`长小数` 约 15 到 16 位。需要保存很大或很小的数、做科学计算时用 `长小数`；只在内存或带宽敏感、并且能接受精度损失时用 `浮点数`。

Csay 数字字面量不带 `f` 后缀：直接写 `3.14` 再赋给 `浮点数` 变量，或者对文本调用 `.转浮点数()`。

浮点数和长小数可以混合运算，结果会提升为长小数：

```csay 混合浮点
浮点数 f = 1.5;
长小数 d = 2.25;
打印(f + d);  // 3.75
```

文本转浮点用 `转浮点数` 或 `转长小数`：

```csay 文本转浮点
浮点数 f = 转浮点数("1.5");
长小数 d = 转长小数("2.25");
打印(f);  // 1.5
打印(d);  // 2.25
```

## 类型转换

变量的类型声明后不会变。整数和浮点混合运算时，结果会自动提升为浮点；把浮点赋给整数会截断小数部分，容易埋下错误，建议显式转换。

需要强制转换时，可以写 C# 风格的类型转换：

```csay 显式转换
枚举 星期 {
    一,
    二,
}
整数 甲 = (整数) 3.7;       // 3
长小数 乙 = (长小数) 4;     // 4.0
整数 丙 = (整数) 星期.一;    // 0
星期 丁 = (星期) 1;         // 星期.二
```

数字之间可以互转；枚举可以和整数互转；类和接口之间可以显式转换。数字、真假和枚举可以强转为文本，文本也可以强转为数字；文本内容不是合法数字时会在运行时报格式错误。

浮点转整数用 `四舍五入`：

```csay 浮点转整数
打印(四舍五入(3.7));   // 4
打印(四舍五入(-3.7));  // -4
打印(四舍五入(2.5));   // 3
```

`四舍五入` 不是直接截断。`2.5` 会变成 `3`，`-3.7` 会变成 `-4`。

`转整数` 只接受文本；浮点直接赋给整数变量时，小数部分会被截掉：

```csay 截断
整数 甲 = 3.7;
整数 乙 = -3.7;
打印(甲);   // 3
打印(乙);   // -3
```

## 整数与浮点不要混着算

整数和浮点可以一起运算，结果会提升为浮点：

```csay 混合运算
打印(3 + 1.5);  // 4.5
打印(3 * 2.0);  // 6
```

真正需要注意的是**整数除以整数**：两边都是整数时，结果还是整数，小数部分直接丢掉：

```csay 整数除法
打印(7 / 2);      // 3
打印(7.0 / 2.0);  // 3.5
打印(7 % 2);      // 1
```

需要浮点结果时，至少让一个操作数是浮点（写 `7.0` 或 `2.0`）。`%` 是取余，只能用于整数。

## 与 C# 的对应关系

Csay 的语法接近 C#，但类型并不逐项兼容。常见对应如下：

| Csay | C# | 说明 |
|---|---|---|
| `字节` / `有符号字节` | `byte` / `sbyte` | 8 位 |
| `短整数` / `无符号短整数` | `short` / `ushort` | 16 位 |
| `整数` / `无符号整数` | `int` / `uint` | 32 位 |
| `长整数` / `无符号长整数` | `long` / `ulong` | 64 位 |
| `浮点数` | `float` | 32 位浮点 |
| `长小数` | `double` | 64 位浮点 |
| `文本` | `string` | UTF-8 字符串 |
| `字符` | `char` | 16 位 UTF-16 码元 |
| `真假` | `bool` | 布尔值 |
| `无` | `void` | 只用于返回类型 |
| `空` | `null` | 只用于引用类型 |
| `列表<T>` | `List<T>` | 可变长度 |
| `T[]` | `T[]` | 定长数组 |
| `表<K, V>` | `Dictionary<K, V>` | 键值表 |
| `集合<T>` | `HashSet<T>` 的用法相近 | 实际是列表别名，用 `.集合添加` |
| `委托` | `delegate` | 函数类型 |
| `类` / `结构` / `接口` / `枚举` | `class` / `struct` / `interface` / `enum` | 面向对象声明 |
| `使用 (资源) { }` | `using (资源) { }` | 离开块时调用 `关闭()` |

C# 的 `decimal` 目前没有独立类型；需要高精度十进制时应改用整数缩放或外部实现。`char` 已经有独立的 `字符` 类型。后续计划见[未来计划](../未来计划.md)。
