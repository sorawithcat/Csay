# 编译器与自举

## 编译流程

```text
.csay 源文件
  → 词法、语法与类型检查
  → C 代码
  → 系统 C 编译器（clang / gcc / 随包 TCC）
  → 原生 exe
```

默认编译器随 Csay 安装包提供，负责词法、语法、类型检查、泛型展开、`引` 多文件加载和 C 代码生成。生成的 C 是独立程序，不依赖 Csay 运行环境；Windows 发布包自带 TCC，用户不需要另装 C 编译器。

## 两套编译器

Csay 有两套可用的编译器：

- 默认编译器：随安装包提供，覆盖全部语言特性，负责日常编译、项目构建、测试、格式化和调试；
- 自举编译器：用 Csay 编写的编译器，用来验证语言能表达并编译自身。它覆盖语言核心和大多数运行时特性，适合单文件编译与自举验证。

两者使用同一套语法和语义；默认编译器覆盖全部语言特性，自举编译器覆盖语言核心和大多数运行时特性。新增语法会先进入默认编译器，自举编译器随后同步。
