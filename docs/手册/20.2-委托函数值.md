# 委托函数值与限制

## 直接使用顶层函数

签名完全一致时，顶层函数可以直接赋给委托变量、字段或参数，不需要再包一层 Lambda：

```csay 函数赋给委托
整数 平方(整数 x) {
    返回 x * x;
}

委托 变换(整数): 整数;
变换 f = 平方;
打印(f(5))      // 25
```

只有参数类型和返回类型都一致的单个顶层函数才能这样赋值；重载函数和带数组参数的委托需要先用 Lambda。

## 限制

- Lambda 参数必须写类型，不能省略成 `(x) => x`。
- 闭包环境分配在堆上，当前不会自动释放；创建大量长期闭包时要考虑内存。
