# Csay 语言规范

版本：1.0  
适用范围：Csay 0.1.x 编译器与自举编译器

## 1. 概述

Csay 是一门静态类型、编译型语言。关键字与常用类型名使用中文，语法结构接近 C#。源文件扩展名为 `.csay`，编译后生成 C 代码，再编译为原生可执行文件。

语言支持顶层语句、函数、类、接口、继承、属性、枚举、数组、列表、表、异常、区域分配、结构体、静态成员和简单的多文件引入。

## 2. 词法

### 2.1 编码

源文件使用 UTF-8 编码。带 BOM 的文件也能读取，编译器会忽略开头的 BOM；编辑器保存时写无 BOM 的 UTF-8。标识符、字符串和注释均允许非 ASCII 字符。

### 2.2 注释

```csay
// 单行注释
/// 文档注释：编辑器在悬浮时显示，编译器当普通注释
/*
   多行注释
*/
```

### 2.3 标识符

标识符由 Unicode 字母、数字和下划线组成，首字符不能是数字。关键字不能用作标识符。

### 2.4 关键字

```text
类 接口 结构 枚举 委托 公开 私有 保护 内部 静态 虚拟 覆盖 只读 抽象 常 密封
字节 有符号字节 短整数 无符号短整数 整数 无符号整数 长整数 无符号长整数
浮点数 长小数 文本 字符 真假 无 任意 自 基 新 空 真 假
若 否则 否则若 选择 情况 默认 循环 遍历 只要 做 在 返回 跳出 跳过
试 捕获 最终 抛出 区域 使用 引 命名空间 取 写
```

`整数` 对应 C# `int`，`长整数` 对应 `long`，`字符` 对应 `char`，其余整数类型对应同名的 C# 窄类型；`任意` 仍是保留字。

`值` 是上下文关键字，只在属性的 `写` 访问器中表示待赋的值。

### 2.5 字面量

- 整数：十进制数字序列，例如 `42`。
- 浮点：带小数点的十进制数，默认是 `长小数`，例如 `3.14`。
- 文本：双引号或中文引号包围，例如 `"你好"`、`“你好”`。
- 字符：单引号包围一个字符，例如 `'A'`、`'中'`；支持 `'\n'`、`'\t'`、`'\r'`、`'\0'`、`'\''`、`'\\'` 和 `'\u0041'`。
- 真假：`真`、`假`。
- 空值：`空`。目前可以用于类、接口、列表、表、数组、委托和异常；`文本` 用空字符串表示空，`结构` 是值类型，不能用 `空`。`文本` 不能和 `空` 比较，判断空文本用 `文本长度(s) == 0`。数组为 `空` 时长度为 0；委托为 `空` 时调用会抛出 `委托为空`；接口为 `空` 时不能访问成员；异常为 `空` 时可以用 `??` 合并或和 `空` 比较。检查器会跟踪局部类/接口/委托变量确定为 `空` 的赋值，并在直接写 `.`、`[]` 或 `()` 时报错；`若 (变量 != 空)` 的分支内视为非空，`变量 != 空 && ...` 的右侧和循环体在条件保证非空时也会这样处理；循环条件写成 `变量 != 空` 时，循环结束后变量被视为可能为空；`跳出` 会合并跳出时的状态，跳出前非空时不会误报为空。方法内给 `自.字段` 或局部对象的 `对象.字段` 赋 `空` 后，再对同一字段写嵌套 `.`/`[]`/`()` 也会报错；`若 (对象.字段 != 空)` 的分支里该字段视为非空，`== 空` 的否则分支同样；默认值为 `空` 的参数在函数体内也按可能为空处理；当前项目加载的文件（含 `引`）中，顶层函数或方法可能返回 `空` 时，调用结果也按可能为空处理；调用点传入 `空` 的普通参数（含方法实参）在函数体内也按可能为空处理；同名方法会保守合并；其他参数和未加载文件见[未来计划](未来计划.md)。
- 空安全访问：`对象?.成员` 在对象为 `空` 时得到 `空`；左边必须是类或接口对象，异常的结果值支持 `?.信息`/`?.类型`，结果可以是文本、类、接口、列表、表、数组、委托或异常。每个可能为空的环节都要单独写 `?.`。

文本转义：

| 写法 | 含义 |
|---|---|
| `\n` | 换行 |
| `\r` | 回车 |
| `\t` | 制表符 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |
| `\{` | 字面左花括号 |
| `\}` | 字面右花括号 |

### 2.6 字符串插值

文本中的 `{表达式}` 会替换为表达式结果。`$` 前缀可省略：

```csay
文本 名字 = "小明"
打印($"你好，{名字}")
打印("1 + 2 = {1 + 2}")
```

插值表达式内可以包含字符串和下标，例如 `{库存["苹果"]}`。

### 2.7 全角标点

全角括号、逗号、冒号、分号、比较运算符、算术运算符等会自动转换为对应的半角符号。字符串内部的字符不转换。

### 2.8 分号

语句末尾的分号可省略。`循环` 循环头部的两个分号是语法结构的一部分，必须保留。

## 3. 类型

| 类型 | 说明 |
|---|---|
| `字节` | 8 位无符号整数 |
| `有符号字节` | 8 位有符号整数 |
| `短整数` | 16 位有符号整数 |
| `无符号短整数` | 16 位无符号整数 |
| `整数` | 32 位有符号整数 |
| `无符号整数` | 32 位无符号整数 |
| `长整数` | 64 位有符号整数 |
| `无符号长整数` | 64 位无符号整数 |
| `浮点数` | 32 位 IEEE 754 浮点数 |
| `长小数` | 64 位 IEEE 754 浮点数 |
| `文本` | UTF-8 字符串，按码点取下标和长度 |
| `字符` | 16 位 UTF-16 码元，对应 C# `char` |
| `真假` | 布尔值 |
| `无` | 无返回值 |
| `T[]` | 数组，元素类型为 `T` |
| `列表<T>` | 动态列表 |
| `集合<T>` / `队列<T>` / `栈<T>` | 列表的轻量别名，分别提供去重添加、先进先出、后进先出方法 |
| `表<K, V>` | 哈希表；键支持文本、整数类型或真假，值支持整数类型、浮点数、长小数、文本、真假、列表、表和数组 |
| `枚举:名称` | 枚举类型 |
| `类:名称` | 类引用 |
| `接口:名称` | 接口引用 |
| `结构:名称` | 结构体值 |
| `异常` | 异常对象，`.信息` 是错误文本，`.类型` 是异常类型名 |
| `参数异常` / `状态异常` / `文件异常` / `越界异常` / `格式异常` | 具体异常类型，都可被 `异常` 捕获 |
| `条目` | 表遍历产生的键值对 |

浮点字面量默认是 `长小数`；赋给 `浮点数` 会转成 32 位，可能损失精度。`浮点数` 约 7 位有效十进制数字，`长小数` 约 15 到 16 位。

顶层数组当前按列表存储；`.长度` 与 `.数量` 均可用于列表。

数组变量和类/结构字段支持 `.添加(值)`、`.插入(下标, 值)`、`.删除(下标)`；这些操作把接收者替换为新数组，旧数组不会自动释放。数组作为函数参数时，函数内换数组不影响调用者的变量。局部数组变量可以用字面量、`空` 或另一个数组表达式初始化；从另一个数组表达式初始化时，变量保存的是数组指针，修改元素会共享同一份数据。数组元素也可以是数组，每一层保留自己的长度。类/结构字段可以保存数组，字段的 `.长度`、下标、传参、遍历和 JSON 序列化使用数组头长度。

`集合<T>`、`队列<T>`、`栈<T>` 与 `列表<T>` 共用同一种存储，创建后也可以使用列表的全部方法；它们只是为不同用途提供更直观的方法名。

## 4. 声明

### 4.1 变量

```csay
整数 甲 = 1
文本 名字 = "Csay"
浮点数 比例 = 0.5
长小数 半径 = 2.0
```

未初始化时使用类型默认值：整数 `0`、浮点 `0`、真假 `假`、文本空串、引用类型 `空`。

### 4.2 函数

```csay
整数 平方(整数 x) {
    返回 x * x
}
```

函数可以递归，可以先调用后定义。无返回值时写 `无` 或省略返回类型。参数可以带默认值，形式为 `整数 x = 1`；有默认值的参数必须放在参数表末尾，默认值必须是常量表达式。调用时可以用 `参数名: 值` 指定实参；位置参数必须写在命名参数之前，内建函数不支持命名参数。顶层函数、普通方法、构造器、虚拟/覆盖/抽象方法和接口方法的参数可以写 `引用` 或 `输出`，调用时实参也写同样的前缀且必须是变量；引用/输出参数不能是数组，不能带默认值。

顶层语句、函数和类型声明可以按任意顺序书写；顶层语句仍按书写顺序执行。顶层函数、类/结构体的普通方法和静态方法可以同名，但参数个数或参数类型必须不同，调用时按实参选择；重载可以使用默认参数和命名参数。虚拟、覆盖、抽象方法和接口方法的重载仍见[未来计划](未来计划.md)。

### 4.3 类与结构体

```csay
公开 类 点 {
    公开 整数 横
    公开 整数 纵

    公开 点(整数 x, 整数 y) {
        横 = x
        纵 = y
    }
}
```

结构体使用 `结构` 声明，字段按值存储：

```csay
公开 结构 坐标 {
    公开 整数 横
    公开 整数 纵

    公开 坐标(整数 x, 整数 y) {
        横 = x
        纵 = y
    }
}
```

结构体支持字段、构造器、方法和 `新`。赋值或传参时复制整个值，不会共享同一份数据。

### 4.3.1 泛型

类、结构和接口可以在名字后声明类型参数，使用时给出具体类型：

```csay
盒子<整数> 整数盒 = 新 盒子<整数>(3)
盒子<文本> 文本框 = 新 盒子<文本>("你好")
打印(整数盒.内容)      // 3
打印(文本框.内容)      // 你好

公开 类 盒子<T> {
    公开 T 内容

    公开 盒子(T v) {
        内容 = v
    }
}
```

类型参数在编译期被具体类型替换，每个 `盒子<整数>`、`盒子<文本>` 都会生成独立的类型。泛型类可以继承泛型基类，也可以实现泛型接口：

```csay
公开 类 容器<T> {
    公开 T 内容

    公开 容器(T v) {
        内容 = v
    }
}

公开 类 盒子<T> : 容器<T> {
    公开 盒子(T v) : 基(v) { }
}
```

类型实参通常显式写出；变量声明也可以省略，从 `新` 的显式类型实参推断。构造器参数直接写成类型参数时，也能从对应实参推断，例如 `盒子 盒 = 新 盒子(3)` 得到 `盒子<整数>`；类型参数嵌在 `盒子<T>`、`列表<T>` 或数组 `T[]` 里时也会逐层推断。方法级类型参数和跨函数推断见[未来计划](未来计划.md)。

类型参数可以带一个或多个名义约束，例如 `类 盒子<T: 有名字>` 或 `类 盒子<T: 有名字 & 可打印>`；实参必须同时满足所有约束。约束本身是泛型类型的支持见[未来计划](未来计划.md)。

### 4.4 委托与 Lambda

```csay
委托 变换(整数): 整数;

变换 加倍 = (整数 x) => x * 2
打印(加倍(5))
```

委托声明 `委托 名字(参数类型...): 返回类型;` 定义函数值类型。Lambda 的参数必须带类型，形式为 `(类型 参数, ...) => 表达式` 或 `(类型 参数, ...) => { ... }`。

- Lambda 按值捕获用到的外层局部变量；方法里的 `自` 捕获对象引用。数组捕获保存数组指针和当时的长度，元素与外层共享。
- 顶层函数在参数类型和返回类型完全一致时可以直接赋给委托变量、字段或参数；重载函数不能直接作为值，带数组参数的委托需要先用 Lambda。
- 闭包环境在堆上分配，当前不自动释放。
- 表达式体的返回类型由表达式推断；块体用 `返回 值;` 返回值，返回类型由 `返回` 的表达式推断，无返回值时为 `无`。
- 委托变量调用前会做空检查，为空时抛出 `状态异常`，消息为“委托为空”。

### 4.5 枚举

```csay
公开 枚举 星期 {
    一, 二, 三, 四, 五, 六, 日
}
```

枚举项从 0 开始编号，通过 `星期.一` 访问。

## 5. 表达式

### 5.1 运算符

按优先级从高到低：

1. 后缀：`()`, `[]`, `.`, `?.`, `++`, `--`
2. 前缀：`!`, `-`, `++`, `--`
3. `*`, `/`, `%`
4. `+`, `-`
5. `<`, `<=`, `>`, `>=`
6. `==`, `!=`
7. `&&`
8. `||`
9. `??`
10. `? :`

`+` 对两个文本做拼接。

### 5.2 三元表达式

```csay
文本 结果 = 年龄 >= 18 ? "成年" : "未成年"
```

`??` 左边为 `空` 时取右边，否则取左边；左边必须是类、列表或表。

### 5.3 对象创建

```csay
点 甲 = 新 点(1, 2)
列表<整数> 分数 = 新 列表<整数>()
表<文本, 整数> 库存 = 新 表<文本, 整数>()
```

类通过构造器创建；`列表` 和 `表` 使用内建创建语法。

### 5.4 数组和列表字面量

```csay
整数[] 数列 = [1, 2, 3]
列表<文本> 名字 = 新 列表<文本>()
```

数组字面量也支持类对象和接口对象，元素统一转换为列表存储。

## 6. 语句

```csay
若 (条件) { ... } 否则若 (条件) { ... } 否则 { ... }

只要 (条件) { ... }

做 { ... } 只要 (条件)

循环 (整数 i = 0; i < 10; i++) { ... }

遍历 (整数 x 在 数列) { ... }

选择 (值) {
    情况 1:
        打印("一")
        跳出
    默认:
        打印("其他")
}

返回 表达式
跳出
跳过

使用 (资源) { ... }
```

`选择` 支持整数和枚举值。`跳出` 在循环中结束循环，在 `选择` 中结束分支。

## 7. 面向对象

### 7.1 访问修饰符

`公开`、`私有`、`保护`、`内部` 用于字段、方法、属性和构造器，默认是 `公开`：

- `私有`：只有声明它的类自己能访问。
- `保护`：声明它的类和它的子类能访问。
- `内部`：同一程序集内能访问；当前单文件或一次构建内等价于公开。
- `公开`：任何位置都能访问。

同一个成员只能写一个访问修饰符。构造器也可以写访问修饰符；`私有` 构造器只能在类内部 `新`，`保护` 构造器可以在子类构造器里通过 `: 基(...)` 使用。

字段还可以加 `只读` 或 `常`。`只读` 只能用于字段或只有 `取` 访问器的属性；`常` 只能用于字段。`只读` 字段只能在构造器里赋值，构造完成后不能再改。`常` 是编译期常量，必须在声明处用常量表达式初始化，不能引用变量、字段或函数；类和结构的方法、构造器里都不能再给它赋值。常量的初始值支持字面量、括号、一元 `+`/`-`/`!` 和数字或真假运算，读取时直接使用声明处的值。

`静态` 可以与字段上的 `只读`/`常` 组合，也可以用于属性；但不能和 `虚拟`、`覆盖`、`抽象` 组合。`虚拟`、`覆盖`、`抽象` 只能用于方法；抽象方法不能是 `私有`。静态属性用类型名访问，访问器里没有 `自`。

### 7.2 继承与多态

```csay
公开 类 圆 {
    公开 虚拟 长小数 面积() { 返回 3.14159 * 半径 * 半径 }
}

公开 类 球 : 圆 {
    公开 球(长小数 半径) : 基(半径) { }
    公开 覆盖 长小数 面积() { 返回 4 * 基.面积() }
}
```

- 单继承。子类构造器通过 `: 基(...)` 调用父类构造器；没有写 `: 基(...)` 时自动调用父类无参构造器。
- 父类用 `虚拟` 开放改写，子类用 `覆盖` 改写；`覆盖` 必须在父类链上找到对应的 `虚拟` 方法，否则报错。
- 通过父类变量调用虚拟方法，会按运行时类型分派到子类实现；`基.方法()` 直接调用父类实现。
- `密封` 类不能被继承；`抽象` 类不能直接 `新`，只能由子类实例化。
- 抽象类可以声明 `抽象` 方法：只写签名、以 `;` 结尾，不写方法体；具体子类必须用 `覆盖` 实现继承来的抽象方法，否则报错。抽象方法不能是静态方法，也不能通过 `基` 直接调用。
- 方法和只读属性可以用 `=> 表达式;` 写成表达式体：有返回值的方法等价于 `{ 返回 表达式; }`，返回 `无` 的方法等价于 `{ 表达式; }`，属性等价于只写 `取` 的属性。构造器也可以这样写。
- 需要把不同实现装进同一个变量时，也可以使用接口类型。

### 7.3 接口

```csay
公开 接口 形状 {
    长小数 面积()
    文本 名字 { 取; }
}

公开 类 圆 : 形状 {
    公开 长小数 面积() { 返回 3.14159 * 半径 * 半径 }
    公开 文本 名字 { 取 { 返回 "圆" } }
}
```

接口变量可以持有不同实现类的对象，方法按运行时类型分派：

```csay
形状[] 堆 = [新 圆(2.0), 新 方(3.0)]
遍历 (形状 形 在 堆) {
    打印(形.名字)
}
```

### 7.4 属性

```csay
公开 整数 计数 {
    取 { 返回 _计数 }
    写 { _计数 = 值 }
}
```

只写 `取` 表示只读属性。接口属性使用 `取;` / `写;` 声明。

### 7.5 静态成员

```csay
公开 类 工具 {
    公开 静态 整数 计数;
    公开 静态 整数 加倍(整数 x) { 返回 x * 2; }
}

工具.计数 = 1;
打印(工具.加倍(3));
```

静态字段属于类本身，所有对象共享；静态方法不能访问实例字段。静态字段可以在声明处写初始值，初始化在程序启动、顶层语句执行前完成；没有写初始值时从零值开始。类名访问和类内直接使用字段名都支持。

## 8. 异常、区域与使用

### 8.1 异常

```csay
试 {
    抛出 文件异常("配置不存在")
} 捕获 (参数异常 错) {
    打印($"参数错误：{错.信息}")
} 捕获 (文件异常 错) {
    打印($"文件错误：{错.类型}")
} 捕获 (异常 错) {
    打印($"其他错误：{错.信息}")
} 最终 {
    打印("清理")
}
```

`捕获` 按书写顺序匹配，`异常` 匹配所有异常；具体类型只匹配同种类的异常。没有匹配的异常会在执行 `最终` 后继续向外抛出。`异常` 对象有 `.信息`（错误文本）和 `.类型`（类型名）。捕获后面可以写 `若 (条件)`，条件为真才进入该分支，否则继续匹配下一个捕获；条件必须是真假值，可以访问当前异常变量。

内建异常种类有 `异常`、`参数异常`、`状态异常`、`文件异常`、`越界异常`、`格式异常`。`抛出 "文本"` 会转换成种类为 `异常` 的异常对象。

### 8.2 区域

```csay
区域 {
    文本 临时 = "区域内"
    打印(临时)
}
```

区域结束时释放该区域内分配的内存。区域内的引用不应在区域外继续使用；需要返回时使用 `移出区域` 把文本复制到外层。

### 8.3 使用

```csay
使用 (打开的文件) {
    打开的文件.写行("内容")
}
```

`使用` 的目标必须是类对象，并且该类有可访问的无参 `关闭()` 方法。块正常结束或抛出异常时都会调用 `关闭()`；异常在关闭后继续向外抛出。

`使用` 的目标表达式只求值一次；目标为空时不会调用 `关闭()`。`使用` 块里可以写 `返回`、`跳出` 或 `跳过`。离开块前会先调用 `关闭()`；如果关闭本身抛出异常，异常继续向外传播，且不会重复调用关闭。返回表达式的值会先求值，再关闭资源。

## 10. 多文件引入

在源文件开头使用：

```csay
引 "工具.csay"
```

路径相对于**当前源文件**所在目录；不带 `.csay` 扩展名时会自动补上。也可以写不带引号的名字：

```csay
引 工具;
```

被引文件只能包含类型声明和函数，不能有顶层可执行语句。同一个文件被多次引入时只加载一次。被引文件里的函数和类型直接在主文件里使用，不额外加前缀。

```csay
// 工具.csay
整数 加一(整数 x) {
    返回 x + 1
}

// 程序.csay
引 "工具.csay"
打印(加一(2))
```

### 10.1 命名空间

`命名空间` 把一组类型声明收进一个块里，编译时展开到文件级：

```csay
命名空间 数学 {
    公开 类 复数 {
        公开 整数 实部 = 0;
    }
}
```

`命名空间` 只做声明分组，不改变名字查找规则；类型名可以省略命名空间，也可以用 `数学.复数` 这样的限定名。命名空间可以嵌套，限定名相应写成 `数学.几何.点`；枚举项也可以写完整路径，例如 `数学.几何.方向.水平`。带类型实参时写作 `容器.盒子<整数>`。需要隔离模块时，用单独的文件配合 `引`。

## 11. 编译与执行

```bat
csay 程序.csay            编译并运行
csay 程序.csay --check    检查语法、名字、成员、参数和类型
csay 程序.csay --build    只生成 exe
csay 程序.csay --fast     使用 TCC
csay 程序.csay --rebuild  强制重新编译
csay --test [目录]        递归运行测试，默认 tests
csay --project [目录]     按 项目.csayproj 的入口编译
csay 程序.csay --debug    生成 #line 源码映射并带 -g
csay 程序.csay --format   按规范格式重写源文件
```

编译器查找 C 编译器的顺序：`CSAY_CC` 环境变量、系统 clang、gcc、随包 TCC。

## 12. 自举编译器

Csay 还提供一个由 Csay 编写的自举编译器，用来验证语言能表达并编译自身。日常开发使用默认编译器即可。
