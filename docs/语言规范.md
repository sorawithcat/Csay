# Csay 语言规范

版本：1.0  
适用范围：Csay 0.1.x 编译器与自举编译器

## 1. 概述

Csay 是一门静态类型、编译型语言。关键字与常用类型名使用中文，语法结构接近 C#。源文件扩展名为 `.csay`，编译后生成 C 代码，再编译为原生可执行文件。

语言支持顶层语句、函数、类、接口、继承、属性、枚举、数组、列表、表、异常、区域分配、结构体、静态成员和简单的多文件引入。

## 2. 词法

### 2.1 编码

源文件使用 UTF-8 编码，不带 BOM。标识符、字符串和注释均允许非 ASCII 字符。

### 2.2 注释

```csay
// 单行注释
/*
   多行注释
*/
```

### 2.3 标识符

标识符由 Unicode 字母、数字和下划线组成，首字符不能是数字。关键字不能用作标识符。

### 2.4 关键字

```text
类 接口 结构 枚举 委托 公开 私有 保护 内部 静态 虚拟 覆盖 只读 抽象 密封
整数 小数 文本 真假 无 列表 表 条目 异常
若 否则 只要 做 对于 遍历 择 情形 默认 跳出 跳过 返回
试 捕获 最终 抛出 区域 使用 新 自 基 值 在 真 假 空 引
```

`值` 是上下文关键字，只在属性的 `写` 访问器中表示待赋的值。

### 2.5 字面量

- 整数：十进制数字序列，例如 `42`。
- 小数：带小数点的十进制数，例如 `3.14`。
- 文本：双引号或中文引号包围，例如 `"你好"`、`“你好”`。
- 真假：`真`、`假`。
- 空值：`空`。

文本转义：

| 写法 | 含义 |
|---|---|
| `\n` | 换行 |
| `\r` | 回车 |
| `\t` | 制表符 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |
| `\{` | 字面左花括号 |
| `\}` | 字面右花括号 |

### 2.6 字符串插值

文本中的 `{表达式}` 会替换为表达式结果。`$` 前缀可省略：

```csay
文本 名字 = "小明"
打印($"你好，{名字}")
打印("1 + 2 = {1 + 2}")
```

插值表达式内可以包含字符串和下标，例如 `{库存["苹果"]}`。

### 2.7 全角标点

全角括号、逗号、冒号、分号、比较运算符、算术运算符等会自动转换为对应的半角符号。字符串内部的字符不转换。

### 2.8 分号

语句末尾的分号可省略。`对于` 循环头部的两个分号是语法结构的一部分，必须保留。

## 3. 类型

| 类型 | 说明 |
|---|---|
| `整数` | 64 位有符号整数 |
| `小数` | 双精度浮点数 |
| `文本` | UTF-8 字符串，按码点取下标和长度 |
| `真假` | 布尔值 |
| `无` | 无返回值 |
| `T[]` | 数组，元素类型为 `T` |
| `列表<T>` | 动态列表 |
| `集合<T>` / `队列<T>` / `栈<T>` | 列表的轻量别名，分别提供去重添加、先进先出、后进先出方法 |
| `表<K, V>` | 哈希表 |
| `枚举:名称` | 枚举类型 |
| `类:名称` | 类引用 |
| `接口:名称` | 接口引用 |
| `结构:名称` | 结构体值 |
| `异常` | 异常对象，`.信息` 是错误文本，`.类型` 是异常类型名 |
| `参数异常` / `状态异常` / `文件异常` / `越界异常` / `格式异常` | 具体异常类型，都可被 `异常` 捕获 |
| `条目` | 表遍历产生的键值对 |

顶层数组当前按列表存储；`.长度` 与 `.数量` 均可用于列表。

`集合<T>`、`队列<T>`、`栈<T>` 与 `列表<T>` 共用同一种存储，创建后也可以使用列表的全部方法；它们只是为不同用途提供更直观的方法名。

## 4. 声明

### 4.1 变量

```csay
整数 甲 = 1
文本 名字 = "Csay"
小数 半径 = 2.0
```

未初始化时使用类型默认值：整数 `0`、小数 `0.0`、真假 `假`、文本空串、引用类型 `空`。

### 4.2 函数

```csay
整数 平方(整数 x) {
    返回 x * x
}
```

函数可以递归，可以先调用后定义。无返回值时写 `无` 或省略返回类型。

### 4.3 类与结构体

```csay
公开 类 点 {
    公开 整数 横
    公开 整数 纵

    公开 点(整数 x, 整数 y) {
        横 = x
        纵 = y
    }
}
```

结构体使用 `结构` 声明，字段按值存储：

```csay
公开 结构 坐标 {
    公开 整数 横
    公开 整数 纵

    公开 坐标(整数 x, 整数 y) {
        横 = x
        纵 = y
    }
}
```

结构体支持字段、构造器、方法和 `新`。赋值或传参时复制整个值，不会共享同一份数据。

### 4.3.1 泛型

类、结构和接口可以在名字后声明类型参数，使用时给出具体类型：

```csay
盒子<整数> 整数盒 = 新 盒子<整数>(3)
盒子<文本> 文本框 = 新 盒子<文本>("你好")
打印(整数盒.内容)      // 3
打印(文本框.内容)      // 你好

公开 类 盒子<T> {
    公开 T 内容

    公开 盒子(T v) {
        内容 = v
    }
}
```

类型参数在编译期被具体类型替换，每个 `盒子<整数>`、`盒子<文本>` 都会生成独立的类型。泛型类可以继承泛型基类，也可以实现泛型接口：

```csay
公开 类 容器<T> {
    公开 T 内容

    公开 容器(T v) {
        内容 = v
    }
}

公开 类 盒子<T> : 容器<T> {
    公开 盒子(T v) : 基(v) { }
}
```

类型实参必须显式写出，例如 `新 盒子(3)` 不能自动推断成 `盒子<整数>`。泛型方法（方法自己声明类型参数）暂不支持。

### 4.4 委托与 Lambda

```csay
委托 变换(整数): 整数;

变换 加倍 = (整数 x) => x * 2
打印(加倍(5))
```

委托声明 `委托 名字(参数类型...): 返回类型;` 定义函数值类型。Lambda 的参数必须带类型，形式为 `(类型 参数, ...) => 表达式` 或 `(类型 参数, ...) => { ... }`。

- Lambda 按值捕获用到的外层局部变量；方法里的 `自` 捕获对象引用。捕获数组暂不支持。
- 闭包环境在堆上分配，当前不自动释放。
- 表达式体的返回类型由表达式推断；块体只支持 `无` 返回类型。
- 委托变量调用前会做空检查，为空时抛出 `状态异常`，消息为“委托为空”。

### 4.5 枚举

```csay
公开 枚举 星期 {
    一, 二, 三, 四, 五, 六, 日
}
```

枚举项从 0 开始编号，通过 `星期.一` 访问。

## 5. 表达式

### 5.1 运算符

按优先级从高到低：

1. 后缀：`()`, `[]`, `.`, `++`, `--`
2. 前缀：`!`, `-`, `++`, `--`
3. `*`, `/`, `%`
4. `+`, `-`
5. `<`, `<=`, `>`, `>=`
6. `==`, `!=`
7. `&&`
8. `||`
9. `? :`

`+` 对两个文本做拼接。

### 5.2 三元表达式

```csay
文本 结果 = 年龄 >= 18 ? "成年" : "未成年"
```

### 5.3 对象创建

```csay
点 甲 = 新 点(1, 2)
列表<整数> 分数 = 新 列表<整数>()
表<文本, 整数> 库存 = 新 表<文本, 整数>()
```

类通过构造器创建；`列表` 和 `表` 使用内建创建语法。

### 5.4 数组和列表字面量

```csay
整数[] 数列 = [1, 2, 3]
列表<文本> 名字 = 新 列表<文本>()
```

数组字面量也支持类对象和接口对象，元素统一转换为列表存储。

## 6. 语句

```csay
若 (条件) { ... } 否则若 (条件) { ... } 否则 { ... }

只要 (条件) { ... }

做 { ... } 只要 (条件)

对于 (整数 i = 0; i < 10; i++) { ... }

遍历 (整数 x 在 数列) { ... }

择 (值) {
    情形 1:
        打印("一")
        跳出
    默认:
        打印("其他")
}

返回 表达式
跳出
跳过

使用 (资源) { ... }
```

`择` 支持整数和枚举值。`跳出` 在循环中结束循环，在 `择` 中结束分支。

## 7. 面向对象

### 7.1 访问修饰符

`公开`、`私有`、`保护`、`内部` 用于字段、方法、属性和静态成员，默认是 `公开`：

- `私有`：只有声明它的类自己能访问。
- `保护`：声明它的类和它的子类能访问。
- `内部`：同一程序集内能访问；当前单文件或一次构建内等价于公开。
- `公开`：任何位置都能访问。

字段还可以加 `只读` 或 `常`。这种字段只能在构造器里赋值，构造完成后不能再改；类外和方法里赋值都会编译失败。

### 7.2 继承与多态

```csay
公开 类 圆 {
    公开 虚拟 小数 面积() { 返回 3.14159 * 半径 * 半径 }
}

公开 类 球 : 圆 {
    公开 球(小数 半径) : 基(半径) { }
    公开 覆盖 小数 面积() { 返回 4 * 基.面积() }
}
```

- 单继承。子类构造器通过 `: 基(...)` 调用父类构造器；没有写 `: 基(...)` 时自动调用父类无参构造器。
- 父类用 `虚拟` 开放改写，子类用 `覆盖` 改写；`覆盖` 必须在父类链上找到对应的 `虚拟` 方法，否则报错。
- 通过父类变量调用虚拟方法，会按运行时类型分派到子类实现；`基.方法()` 直接调用父类实现。
- `密封` 类不能被继承；`抽象` 类不能直接 `新`，只能由子类实例化。
- 抽象类可以声明 `抽象` 方法：只写签名、以 `;` 结尾，不写方法体；具体子类必须用 `覆盖` 实现继承来的抽象方法，否则报错。抽象方法不能是静态方法，也不能通过 `基` 直接调用。
- 需要把不同实现装进同一个变量时，也可以使用接口类型。

### 7.3 接口

```csay
公开 接口 形状 {
    小数 面积()
    文本 名字 { 取; }
}

公开 类 圆 : 形状 {
    公开 小数 面积() { 返回 3.14159 * 半径 * 半径 }
    公开 文本 名字 { 取 { 返回 "圆" } }
}
```

接口变量可以持有不同实现类的对象，方法按运行时类型分派：

```csay
形状[] 堆 = [新 圆(2.0), 新 方(3.0)]
遍历 (形状 形 在 堆) {
    打印(形.名字)
}
```

### 7.4 属性

```csay
公开 整数 计数 {
    取 { 返回 _计数 }
    写 { _计数 = 值 }
}
```

只写 `取` 表示只读属性。接口属性使用 `取;` / `写;` 声明。

### 7.5 静态成员

```csay
公开 类 工具 {
    公开 静态 整数 计数;
    公开 静态 整数 加倍(整数 x) { 返回 x * 2; }
}

工具.计数 = 1;
打印(工具.加倍(3));
```

静态字段属于类本身，所有对象共享；静态方法不能访问实例字段。静态字段从零值开始，当前不支持在声明处写初始值。类名访问和类内直接使用字段名都支持。

## 8. 异常、区域与使用

### 8.1 异常

```csay
试 {
    抛出 文件异常("配置不存在")
} 捕获 (参数异常 错) {
    打印($"参数错误：{错.信息}")
} 捕获 (文件异常 错) {
    打印($"文件错误：{错.类型}")
} 捕获 (异常 错) {
    打印($"其他错误：{错.信息}")
} 最终 {
    打印("清理")
}
```

`捕获` 按书写顺序匹配，`异常` 匹配所有异常；具体类型只匹配同种类的异常。没有匹配的异常会在执行 `最终` 后继续向外抛出。`异常` 对象有 `.信息`（错误文本）和 `.类型`（类型名）。

内建异常种类有 `异常`、`参数异常`、`状态异常`、`文件异常`、`越界异常`、`格式异常`。`抛出 "文本"` 会转换成种类为 `异常` 的异常对象。

### 8.2 区域

```csay
区域 {
    文本 临时 = "区域内"
    打印(临时)
}
```

区域结束时释放该区域内分配的内存。区域内的引用不应在区域外继续使用；需要返回时使用 `保留` 把文本复制到外层。

### 8.3 使用

```csay
使用 (打开的文件) {
    打开的文件.写行("内容")
}
```

`使用` 的目标必须是类对象，并且该类有可访问的无参 `关闭()` 方法。块正常结束或抛出异常时都会调用 `关闭()`；异常在关闭后继续向外抛出。

为了保证清理一定发生，当前版本不允许在 `使用` 块里写 `返回`、`跳出` 或 `跳过`。需要提前结束时，把判断放到块外，或用函数返回值表达。

## 10. 多文件引入

在源文件开头使用：

```csay
引 "工具.csay"
```

路径相对于**当前源文件**所在目录；不带 `.csay` 扩展名时会自动补上。也可以写不带引号的名字：

```csay
引 工具;
```

被引文件只能包含类型声明和函数，不能有顶层可执行语句。同一个文件被多次引入时只加载一次。被引文件里的函数和类型直接在主文件里使用，不额外加前缀。

```csay
// 工具.csay
整数 加一(整数 x) {
    返回 x + 1
}

// 程序.csay
引 "工具.csay"
打印(加一(2))
```

### 10.1 空间

`空间` 把一组类型声明收进一个块里，编译时展开到文件级：

```csay
空间 数学 {
    公开 类 复数 {
        公开 整数 实部 = 0;
    }
}
```

`空间` 只做声明分组，不改变名字查找规则；同一个文件里仍然直接写 `复数`，不要写 `数学.复数`。需要隔离模块时，用单独的文件配合 `引`。

## 11. 编译与执行

```bat
csay 程序.csay            编译并运行
csay 程序.csay --check    只检查语法
csay 程序.csay --build    只生成 exe
csay 程序.csay --fast     使用 TCC
csay 程序.csay --rebuild  强制重新编译
csay --test [目录]        递归运行测试，默认 tests
csay --project [目录]     编译目录下的 主.csay 及 引 依赖
csay 程序.csay --debug    生成 #line 源码映射并带 -g
csay 程序.csay --format   按规范格式重写源文件
```

编译器查找 C 编译器的顺序：`CSAY_CC` 环境变量、系统 clang、gcc、随包 TCC。

## 12. 自举编译器

`selfhost/编译器.csay` 是由 Csay 编写的 Stage 1 编译器。构建命令：

```bat
node tools\自举.mjs
```

构建脚本验证 Stage 2 与 Stage 3 的 C 输出逐字节一致，并运行内置测试程序。
