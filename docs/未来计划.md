# 未来计划

## 0.3.0

### 语言与运行时

- C# 后端与 Unity 集成：生成 C# 脚本，支持 `MonoBehaviour`、Unity 生命周期和常用 Unity API。
- `任意` 类型。
- 128 位 `十进制`（定点小数，不用二进制浮点模拟）。
- 泛型方法、方法级类型参数推断和跨函数推断。
- 泛型约束本身带类型参数（例如 `T: 容器<U>`），以及约束的组合与递归检查。
- 可空流分析：普通参数、未加载文件、方法调用实参之外的别名和字段路径。
- 虚拟/覆盖/抽象方法和接口方法的重载。
- 被引文件中的顶层语句和更完整的模块边界。
- `移出区域()` 支持列表、表、类对象等非文本值。
- 正则命名分组、前后查找、Unicode 属性类和跨码点字符类。

### 编辑器

- 调试适配器：断点、单步、调用栈、变量查看。
- 补全准确率：成员过滤、泛型替换、跨文件符号和上下文判断继续补强。

### 内存管理

- 内存诊断：补充长期对象的跨过程别名、容器保存和回调捕获提示。
