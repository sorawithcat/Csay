# Csay

Csay 是一门使用中文关键字、语法接近 C# 的静态类型编程语言。源码编译为 C，再生成独立可执行文件，可在 Windows 上直接运行。

## 特性

- 中文关键字，可选分号，支持全角标点
- 数值类型含 `字节`、`短整数`、`整数`、`长整数`、`浮点数`、`长小数`，另有 `字符`、`文本`、`真假`；控制流用 `循环`、`选择`、`情况`
- 类、属性、单继承、虚拟方法与覆盖、接口与运行时分派，以及普通/静态方法重载
- 枚举、数组、`列表<T>`、`表<K,V>`，以及列表别名 `集合<T>`/`队列<T>`/`栈<T>`
- 异常类型与多捕获、`使用` 自动关闭、区域内存分配、保守垃圾回收、文件读写
- 泛型类/结构/接口、静态成员、结构体、访问控制、`密封`/抽象类与抽象方法/`只读`、`引` 多文件
- 委托类型与 Lambda（表达式体/块体，按值捕获局部变量），委托调用空检查
- `断言` 与 `csay --test` 测试运行器
- `csay --project` 多文件工程构建（入口由 `项目.csayproj` 指定，`引` 递归加载依赖）
- `--debug` 生成 `#line` 源码映射并传入 `-g`
- `--format` 按规范格式原地重写源文件
- `--tokens` / `--print` 查看词法单元与规范化的语法树，便于排查解析问题
- 时间、路径、目录操作、环境变量、系统命令与输出捕获、流式文件、文本格式化、大小写/去空白、轻量正则与 JSON 序列化/解析
- 常用数学/随机函数

## 安装

### Windows 一键安装

1. 解压发布包 `Csay-0.2.0-win64.zip`。
2. 双击 `安装Csay.bat`。
3. 打开新的终端，运行：

```bat
csay 你的程序.csay
```

安装脚本会：

- 安装到 `%LOCALAPPDATA%\Csay`，不需要管理员权限；
- 使用系统 Node.js 22+，没有时自动下载便携版；
- 把 `csay` 加入用户 PATH；
- 关联 `.csay` 文件；
- 创建开始菜单中的编辑器快捷方式。

## 快速开始

新建 `hello.csay`：

```csay
打印("你好，世界！")
```

编译并运行：

```bat
csay hello.csay
```

常用参数：

```bat
csay hello.csay --check    检查语法、名字、成员、参数和类型
csay hello.csay --build    只生成 exe
csay hello.csay --fast     使用 TCC，编译更快
csay hello.csay --rebuild  强制重新编译
csay hello.csay --debug    源码行映射 + -g
csay hello.csay --format   原地格式化
csay hello.csay --print    打印语法树还原出的源码
csay hello.csay --tokens   列出词法单元
csay --project 目录        按 项目.csayproj 的入口构建
csay --test [目录]         递归运行测试，默认 tests
```

生成的 exe 位于 `build\` 目录。

## 编辑器与文档

双击 `编辑器.bat`，或安装后运行 `csay-editor`。启动后不会自动新建文件，编辑器提供：

- 顶栏“打开”可选择打开文件或项目文件夹；关闭后再次打开会自动恢复上次的工作区、标签页和光标位置；
- 工作区文件树；右键文件、文件夹或空白处打开操作菜单，可新建、重命名、删除、复制路径、在资源管理器中显示；打开文件和文件夹使用系统选择框，不需要手输路径；
- 多标签页编辑，切换标签不会丢失未保存内容；
- 保存、运行、实时语法与语义检查、问题跳转；右键可“转到定义/查找引用/复制”，跨文件跳转；引用结果显示在独立标签页；
- 项目文件 `项目.csayproj` 和项目设置窗口，可配置资源文件、依赖项目、构建前/后命令与多个目标；一键打包到 `dist/<输出名>-<版本>.zip`；
- 输入时自动弹出关键字、内建函数和工作区函数补全；输入 `对象.` 时按对象类型列出字段和方法，并显示参数、返回值和说明；鼠标悬停候选项或代码中的标识符可查看完整说明，`///` 文档注释会显示在悬浮里；跨 `引` 文件也能识别函数和类型；方法补全会插入 `()` 并把光标放进括号；`F2` 可在当前文件及其 `引` 依赖中重命名光标下的标识符，`Shift+Alt+F` 按缩进格式化选中行；
- 文件筛选、行号、光标位置、自动缩进、注释切换；
- 文档页侧栏支持按分类和小节搜索，正文中的跨文档链接可直接跳转；
- 大文件按可视区域增量语法高亮，滚动和输入保持流畅；
- `F1` 打开文档。

常用快捷键：

| 快捷键 | 功能 |
|---|---|
| `Ctrl+S` | 保存；默认先按标准格式排版 |
| `Ctrl+Enter` / `F5` | 编译并运行 |
| `Ctrl+N` | 新建文件 |
| `Ctrl+O` | 打开文件夹 |
| `Ctrl+Shift+O` | 打开文件 |
| `Ctrl+W` | 关闭标签 |
| `Ctrl+,` | 打开编辑器设置 |
| `Ctrl+/` | 切换行注释 |
| `F12` / `Shift+F12` | 转到定义 / 查找引用（内建函数显示签名和说明） |
| `F2` | 重命名当前文件及 `引` 依赖中的符号 |
| `Shift+Alt+F` | 按缩进格式化选中行 |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进 |

## 卸载

运行安装包中的 `卸载Csay.bat`，或在 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File uninstall.ps1
```

卸载会删除安装目录、用户 PATH 中的 `csay` 路径、文件关联和开始菜单快捷方式。
